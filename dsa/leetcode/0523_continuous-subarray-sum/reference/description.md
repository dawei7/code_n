## Description

Given an integer array nums and an integer k, return `true` *if *`nums`* has a **good subarray** or *`false`* otherwise*.

A **good subarray** is a subarray where:

<ul>
	<li>its length is **at least two**, and</li>
	<li>the sum of the elements of the subarray is a multiple of `k`.</li>
</ul>

**Note** that:

<ul>
	<li>A **subarray** is a contiguous part of the array.</li>
	<li>An integer `x` is a multiple of `k` if there exists an integer `n` such that `x = n * k`. `0` is **always** a multiple of `k`.</li>
</ul>
