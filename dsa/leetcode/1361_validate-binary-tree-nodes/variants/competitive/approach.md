## General
Given You have `n` binary tree nodes numbered from `0` to $n - 1$ where node `i` has two children $\text{leftChild}[i]$ and $\text{rightChild}[i]$, return `true` if and only if **all** the given nodes form **exactly one** v..., the algorithm executes a single-pass linear scan through input elements. It utilizes binary tree node references (`val`, `left`, `right`) to traverse structural hierarchies. Edge case handling: guards against empty/null inputs via early returns.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
