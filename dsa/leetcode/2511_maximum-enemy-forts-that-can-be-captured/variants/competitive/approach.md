## General
Given a **0-indexed** integer array `forts` of length `n` representing the positions of several forts. $\text{forts}[i]$ can be `-1`, `0`, or `1` where:, the algorithm executes a two-pointer approach to shrink boundaries or maintain a sliding window. Edge case handling: guards against empty/null inputs via early returns.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
