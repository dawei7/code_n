## Description

You are given a positive integer `k` and an integer array `nums` sorted in non-descending order.

A nonempty subarray of `nums` is **good** when the sum of its elements is divisible by `k`.

Return the number of distinct good subarrays.

Distinctness is determined by the sequence of values, not by the positions from which an occurrence was taken. For example, `[1,1,1]` has exactly three distinct subarrays: `[1]`, `[1,1]`, and `[1,1,1]`.
