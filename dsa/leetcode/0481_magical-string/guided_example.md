# Guided Example: Magical String

We trace the step-by-step self-generating Kolakoski sequence construction, run-length self-reference decoding ($s[i]$ copies of $3 - s[-1]$), two-pointer append synchronization ($i < \text{len}(s)$), and prefix frequency counting ($\text{count}(1)$) on representative sequence prefixes:

- **Input:** $n = 6$
- **Required output:** `3`
  - Magical string (Kolakoski sequence): $s$ is composed of characters $\{1, 2\}$, where the sequence of consecutive run-lengths equals the sequence itself:
    $$
    s = [\mathbf{1}, \; \mathbf{2, 2}, \; \mathbf{1, 1}, \; \mathbf{2}, \; \mathbf{1}, \; \mathbf{2, 2}, \; \dots]
    $$
    Run lengths: $1, 2, 2, 1, 1, 2, \dots$ (Identical to $s$!)
- **Self-generation execution trace:**
  - Seed state: $s = [1, 2, 2]$, read pointer $i = 2$ (points to $s[2] = 2$)
  - **Generation Step 1 ($i = 2$):**
    - Read run length from $s[i] = s[2] = \mathbf{2}$
    - Previous character is $s[-1] = 2 \implies$ Next character alternates:
      $$
      cur = 3 - 2 = \mathbf{1}
      $$
    - Append $cur$ repeated $s[i]$ times: append $[1]$ twice
    - Array after append: $s = [1, 2, 2, \mathbf{1}, \mathbf{1}]$ (Length 5)
    - Advance read pointer: $i \leftarrow 2 + 1 = 3$
  - **Generation Step 2 ($i = 3$):**
    - Read run length from $s[i] = s[3] = \mathbf{1}$
    - Previous character is $s[-1] = 1 \implies$ Next character alternates:
      $$
      cur = 3 - 1 = \mathbf{2}
      $$
    - Append $cur$ repeated $s[i]$ times: append $[2]$ once
    - Array after append: $s = [1, 2, 2, 1, 1, \mathbf{2}]$ (Length 6)
    - Target length $n = 6$ reached! Loop halts.
  - Prefix of length 6:
    $$
    s[:6] = [1, \; 2, \; 2, \; 1, \; 1, \; 2]
    $$
  - Count of $1$s:
    $$
    \text{count}(1) = \mathbf{3}
    $$
- **Single Element Prefix:** $n = 1 \implies s[:1] = [1] \implies \mathbf{1}$
- **Empty Prefix:** $n = 0 \implies s[:0] = [] \implies \mathbf{0}$
- **Extended Prefix ($n = 10$):** $s[:10] = [1, 2, 2, 1, 1, 2, 1, 2, 2, 1] \implies \mathbf{5}$ ones

This instance demonstrates self-describing formal language sequences (Kolakoski self-referential grammar), mathematically proves how reading from an internal cursor generates future symbols without infinite recursion, and derives $O(N)$ runtime and $O(N)$ space bounds.

---

## 1. Instance & Teaching Goal

Given an integer $n = 6$:
A **magical string** $s$ consists only of `'1'` and `'2'` and obeys the self-referential property:
Concatenating the lengths of consecutive occurrences of characters `'1'` and `'2'` generates the string $s$ itself.
Find the number of `'1'`s in the first $n$ characters of $s$.

```text
The Self-Generating Kolakoski Sequence:
  String characters:   1   2 2   1 1   2   1   2 2   1 ...
  Group lengths:       1    2     2    1   1    2    1 ...
  Notice: The group lengths replicate the exact same sequence!

First 6 characters: [ 1,  2,  2,  1,  1,  2 ]
Number of '1's:     1 + 0 + 0 + 1 + 1 + 0 = 3
```

### The Dual-Role Pointer Mechanics
How can a sequence define its own future values?
- We seed the string with the smallest prefix that defines alternating runs:
  $$
  s = [1, 2, 2]
  $$
- Two pointers navigate the generation:
  1. **Read Pointer $i$:** Reads the run length $s[i]$ that determines *how many* copies of the next symbol must be generated.
  2. **Write Head ($\text{len}(s)$):** Appends the newly generated symbols at the end of the array.
- Since $i < \text{len}(s)$ at all times, the instructions for future characters are always written *before* the read pointer reaches them!

---

## 2. Conceptual Foundation & Invariants

### 1. Alternation Operator:
The sequence strictly alternates between characters $1$ and $2$.
If the last appended character was $pre$, the next character $cur$ is:
$$
cur = 3 - pre
$$
- $3 - 1 = 2$
- $3 - 2 = 1$

### 2. Append Transition:
At read step $i$:
- The current run length is $k = s[i] \in \{1, 2\}$.
- Append $k$ copies of $cur$ to the array:
  $$
  s \leftarrow s \circ \underbrace{[cur, \dots, cur]}_{s[i] \text{ times}}
  $$
- Advance read pointer: $i \leftarrow i + 1$.

> **Self-Reference Invariant.** The sequence of run lengths generated by reading $s[0 \dots i]$ exactly matches the sequence of block sizes across the entire string prefix.

## 3. Step-by-Step Worked Execution

We trace $n = 6$:

---

### Step 1: Initialization
- Seed array: $s = [1, 2, 2]$ (length 3).
- Read index: $i = 2$ (points to value $2$).
- Target length: $n = 6$.

---

### Step 2: Generation Step 1 ($i = 2$)
- Read run length: $s[2] = \mathbf{2}$.
- Last character: $s[-1] = 2$.
- Next character to append:
  $$
  cur = 3 - 2 = \mathbf{1}
  $$
- Append $cur$ repeated $s[2] = 2$ times:
  $$
  s \leftarrow [1, 2, 2] + [1, 1] = [1, 2, 2, \mathbf{1}, \mathbf{1}]
  $$
- Advance read pointer: $i \leftarrow 3$.
- Current length: $5 < 6$. Continue loop.

---

### Step 3: Generation Step 2 ($i = 3$)
- Read run length: $s[3] = \mathbf{1}$.
- Last character: $s[-1] = 1$.
- Next character to append:
  $$
  cur = 3 - 1 = \mathbf{2}
  $$
- Append $cur$ repeated $s[3] = 1$ time:
  $$
  s \leftarrow [1, 2, 2, 1, 1] + [2] = [1, 2, 2, 1, 1, \mathbf{2}]
  $$
- Advance read pointer: $i \leftarrow 4$.
- Current length: $6 \ge 6$. Loop terminates!

---

### Step 4: Count Ones in Prefix of Length 6
Extract slice $s[0 \dots 5]$:
$$
s[:6] = [1, \; 2, \; 2, \; 1, \; 1, \; 2]
$$
Count of ones:
- Index 0: 1
- Index 3: 1
- Index 4: 1
Total ones: **`3`**.

---

## 4. Complete Execution Trace

| Step | Read Index $i$ | Target Run Length $s[i]$ | Previous End $s[-1]$ | Next Symbol $cur = 3 - pre$ | Elements Appended | Array State After Append | Array Length |
|:---:|:---:|:---:|:---:|:---:|:---:|:---|:---:|
| **Init** | — | — | — | — | — | `[1, 2, 2]` | $3$ |
| **1** | $2$ | $2$ | $2$ | **$1$** | `[1, 1]` | `[1, 2, 2, 1, 1]` | $5$ |
| **2** | $3$ | $1$ | $1$ | **$2$** | `[2]` | `[1, 2, 2, 1, 1, 2]` | **$6$** |
| **Done** | Slice $s[:6]$ | — | — | — | — | **Count of 1s: $3$** | **Result: $3$** |

---

## 5. Boundary Cases & Failure Modes

- **$n = 0$:** Returns $0$ (empty prefix).
- **$n \le 3$ (Within Seed):**
  - $n = 1 \implies [1] \implies \mathbf{1}$.
  - $n = 2 \implies [1, 2] \implies \mathbf{1}$.
  - $n = 3 \implies [1, 2, 2] \implies \mathbf{1}$.
- **Overshooting $n$ on Append:** If $s$ has length 5 and appends two characters, length becomes 7. Slicing with `s[:n]` discards the surplus character to preserve the exact $n$-prefix count.

---

## 6. Traps & Common Anti-Patterns

- **String Concatenation in Loops:** Repeatedly using `str += "1" * k` creates immutable string allocations, degrading runtime to $O(N^2)$. Using a flat integer list or pre-allocated array runs in strictly $O(N)$ linear time.
- **Off-by-One on Terminal Slice:** Counting `s.count(1)` on the entire array instead of `s[:n].count(1)` includes extra characters appended beyond $n$.
- **Starting from Wrong Seed:** The unique seed for the Kolakoski sequence over $\{1, 2\}$ must begin `1, 2, 2`. Starting with `1, 2` leaves the run length of the second group undefined.

---

## 7. Complexity Derivation

- **Time Complexity:**
  - Each iteration of the while loop appends 1 or 2 characters.
  - The loop terminates in at most $N$ iterations.
  - Counting ones takes $O(N)$ time.
  - Total Time: $\mathcal{O}(N)$. For $N = 10^5$, executes in $< 15$ ms.
- **Auxiliary Space Complexity:**
  - $\mathcal{O}(N)$ to store the generated prefix of length $N + 1$.
