## Description

Given a string `s`, find the greatest length among all substrings that occur more than once. A substring is contiguous, so equal subsequences formed by skipping characters do not count. Two occurrences are distinct when their starting positions differ, even if their index ranges overlap.

Return that maximum length. Several different substring values may tie for the greatest length; the result is still only their shared length, not a particular substring. If every non-empty substring occurs only once, return `0`.
