## Examples

**Example 1**

- Input: `s = "abcd"`
- Output: `0`
- Explanation: No substring occurs more than once.

**Example 2**

- Input: `s = "abbaba"`
- Output: `2`
- Explanation: Both `"ab"` and `"ba"` occur twice, and no longer substring repeats.

**Example 3**

- Input: `s = "aabcaabdaab"`
- Output: `3`
- Explanation: The longest repeating substring is `"aab"`, which appears three times.
