## Description

Start with the positive integers beginning at `1` and remove every integer whose decimal representation contains the digit `9`. Removed values therefore include `9`, `19`, `29`, and every other number with `9` in any decimal position.

The retained values form the increasing sequence `[1, 2, 3, 4, 5, 6, 7, 8, 10, 11, ...]`. Given an integer `n`, return the `n`th value in this new sequence, where sequence positions are **1-indexed**.
