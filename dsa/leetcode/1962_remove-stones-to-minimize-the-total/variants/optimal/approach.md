## General
Given a **0-indexed** integer array `piles`, where $\text{piles}[i]$ represents the number of stones in the $$i^{\text{th}}$$ pile, and an integer `k`. You should apply the following operation **exactly** `k` times:, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(N+K\log N)$ — Operation count bound.
- **Space Complexity**: $O(N)$ — Auxiliary memory allocation bound.
