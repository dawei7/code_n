## General
Given a **0-indexed** 2D array `variables` where $\text{variables}[i] = [a_{i}, b_{i}, c_{i}, m_{i}]$, and an integer `target`, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(V(log B + log C))$ — Operation count bound.
- **Space Complexity**: $O(V)$ — Auxiliary memory allocation bound.
