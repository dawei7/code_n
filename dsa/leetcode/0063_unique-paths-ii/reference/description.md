## Description

A robot begins at the top-left cell `grid[0][0]` of an $m \times n$ integer grid and aims to reach `grid[m - 1][n - 1]`. It may move only one cell right or one cell down at a time.

Grid value `1` marks an obstacle, while `0` marks open space. A valid path cannot enter an obstacle cell.

Return the number of distinct valid paths to the bottom-right corner. Generated answers do not exceed $2 \times 10^9$.
