## Examples

**Example 1**

- Input: `obstacleGrid = [[0, 0, 0], [0, 1, 0], [0, 0, 0]]`
- Output: `2`
- Explanation: The center cell is blocked. The two valid move sequences are `Right → Right → Down → Down` and `Down → Down → Right → Right`.

```text
S · ·
· X ·
· · T

X = obstacle
```

**Example 2**

- Input: `obstacleGrid = [[0, 1], [0, 0]]`
- Output: `1`

```text
S X
· T

X = obstacle
```
