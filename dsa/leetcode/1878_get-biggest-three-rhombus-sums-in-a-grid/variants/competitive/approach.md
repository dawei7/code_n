## General
Uses two-pointer iteration. Maintains hash set (`set`) for $O(1)$ existence checks, priority queue (`heapq`) for dynamic minimum/maximum tracking.

## Complexity detail
- **Time Complexity**: $O(MN\min(M,N))$ — Operation count bound.
- **Space Complexity**: $O(MN)$ — Auxiliary memory allocation bound.
