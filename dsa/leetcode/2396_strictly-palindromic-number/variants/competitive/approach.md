## General
Given An integer `n` is **strictly palindromic** if, for **every** base `b` between `2` and $n - 2$ (**inclusive**), the string representation of the integer `n` in base `b` is **palindromic**, the algorithm solves **Strictly Palindromic Number** directly.

## Complexity detail
- **Time Complexity**: $O(1)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
