## General
Given two strings, `coordinate1` and `coordinate2`, representing the coordinates of a square on an `8 x 8` chessboard, the algorithm solves **Check if Two Chessboard Squares Have the Same Color** directly. Edge case handling: applies modulo arithmetic to prevent integer overflow.

## Complexity detail
- **Time Complexity**: $O(1)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
