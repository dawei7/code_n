## Examples

**Example 1**

- Input: `nums = [1,4,2,5]`
- Output: `[3]`
- Explanation: The minimum is `1` and the maximum is `5`, so the complete range is `[1,2,3,4,5]`. Only `3` is absent.

**Example 2**

- Input: `nums = [7,8,6,9]`
- Output: `[]`
- Explanation: The endpoints `6` and `9` define `[6,7,8,9]`. Every integer in that range is present, so the result is empty.

**Example 3**

- Input: `nums = [5,1]`
- Output: `[2,3,4]`
- Explanation: The endpoints define the complete range `[1,2,3,4,5]`; its missing integers are `2`, `3`, and `4`.
