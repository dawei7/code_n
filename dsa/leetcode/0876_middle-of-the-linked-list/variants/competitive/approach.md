## General
Given the `head` of a singly linked list, return *the middle node of the linked list*, the algorithm solves **Middle of the Linked List** directly. It utilizes linked list node pointers (`val`, `next`) to process sequential node chains.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
