## Description

Determine whether the positive integer `n` is a **happy number** by repeatedly applying this process:

- Replace the current number with the sum of the squares of its decimal digits.
- Continue until the value becomes `1`, where the process remains, or until the values enter a repeating cycle that excludes `1`.

A number is happy precisely when this process reaches `1`. Return `true` when `n` is happy and `false` otherwise.
