## General
Uses breadth-first search queue traversal. Maintains hash set (`set`) for $O(1)$ existence checks, double-ended queue (`deque`) for $O(1)$ operations, priority queue (`heapq`) for dynamic minimum/maximum tracking.

## Complexity detail
- **Time Complexity**: $O(T \log T + TRC)$ — Operation count bound.
- **Space Complexity**: $O(RC)$ — Auxiliary memory allocation bound.
