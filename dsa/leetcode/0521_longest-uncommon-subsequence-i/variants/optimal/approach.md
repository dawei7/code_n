## General
Given two strings `a` and `b`, return *the length of the **longest uncommon subsequence** between *`a` *and* `b`. *If no such uncommon subsequence exists, return* `-1`*.*, the algorithm solves **Longest Uncommon Subsequence I** directly.

## Complexity detail
- **Time Complexity**: $O(|a| + |b|)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
