## Examples

**Example 1**

- Input: `x = 2.00000, n = 10`
- Output: `1024.00000`

**Example 2**

- Input: `x = 2.10000, n = 3`
- Output: `9.26100`

**Example 3**

- Input: `x = 2.00000, n = -2`
- Output: `0.25000`
- Explanation: A negative exponent gives $2^{-2} = \frac{1}{2^2} = \frac{1}{4} = 0.25$.
