## Description

You are given an integer array `nums` containing `n` elements and an integer `k`. A subarray is contiguous: it consists of consecutive positions from `nums` and keeps their original order.

Consider every such subarray whose length is at least `k`, including length exactly `k` and, when possible, longer lengths through `n`. For each eligible choice, its average is its sum divided by its number of elements. Return the greatest average attained by any eligible contiguous subarray. A result is accepted when its calculation error is strictly less than $10^{-5}$.
