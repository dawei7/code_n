## General
Given a 2D integer array `edges` representing a tree with `n` nodes, numbered from `0` to $n - 1$, rooted at node `0`, where $\text{edges}[i] = [u_{i}, v_{i}]$ means there is an edge between the nodes $v_{i}$ and $u_{i}$, the algorithm executes depth-first search (DFS) recursion to explore valid decision branches.

## Complexity detail
- **Time Complexity**: $O(N)$ — Operation count bound.
- **Space Complexity**: $O(N)$ — Auxiliary memory allocation bound.
