## General
Given Fruits are available at some positions on an infinite x-axis. You are given a 2D integer array `fruits` where $\text{fruits}[i] = [\text{position}_{i}, \text{amount}_{i}]$ depicts $\text{amount}_{i}$ fruits at the pos..., the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
