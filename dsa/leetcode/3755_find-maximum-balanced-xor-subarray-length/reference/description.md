## Description

You are given an integer array `nums`.

Find a nonempty contiguous subarray satisfying both requirements: the bitwise XOR of all its elements is zero, and it contains the same number of even and odd elements.

The selected range may begin and end at any valid indices, but its elements must remain consecutive and the original array is not changed.

Return the greatest length among all subarrays meeting both conditions. If none exists, return `0`.
