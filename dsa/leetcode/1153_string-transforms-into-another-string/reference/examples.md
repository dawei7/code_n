## Examples

**Example 1**

- Input: `str1 = "aabcc", str2 = "ccdee"`
- Output: `true`
- Explanation: Convert every `c` to `e`, then every `b` to `d`, and finally every `a` to `c`. This order matters.

**Example 2**

- Input: `str1 = "leetcode", str2 = "codeleet"`
- Output: `false`
- Explanation: No sequence of the allowed conversions can transform `str1` into `str2`.
