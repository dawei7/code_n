## General
Given a positive integer `n`, you can do the following operation **any** number of times:, the algorithm solves **Minimum Operations to Reduce an Integer to 0** directly. Key operations include bitwise operators (`&`, `|`, `^`, `<<`, `>>`) for fast bitmask state updates.

## Complexity detail
- **Time Complexity**: $O(log n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
