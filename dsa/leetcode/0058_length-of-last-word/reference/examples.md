## Examples

**Example 1**

- Input: `s = "Hello World"`
- Output: `5`
- Explanation: The final word is `"World"`, which contains five characters.

**Example 2**

- Input: `s = "   fly me   to   the moon  "`
- Output: `4`
- Explanation: Ignoring the trailing spaces, the final word is `"moon"`, whose length is four.

**Example 3**

- Input: `s = "luffy is still joyboy"`
- Output: `6`
- Explanation: The last word is `"joyboy"`, which has six characters.
