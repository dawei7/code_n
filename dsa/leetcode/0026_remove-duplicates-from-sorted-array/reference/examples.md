## Examples

**Example 1**

- Input: `nums = [1, 1, 2]`
- Output: `2, nums = [1, 2, _]`
- Explanation: Return $k=2$ and place `1` and `2` in the first two positions. The underscore denotes an ignored position whose value does not matter.

**Example 2**

- Input: `nums = [0, 0, 1, 1, 1, 2, 2, 3, 3, 4]`
- Output: `5, nums = [0, 1, 2, 3, 4, _, _, _, _, _]`
- Explanation: Return $k=5$ and store `0`, `1`, `2`, `3`, and `4` in the first five positions. Everything after that prefix is ignored.
