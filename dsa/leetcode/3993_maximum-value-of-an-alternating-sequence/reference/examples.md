## Examples

**Example 1**

- Input: `n = 4, s = 3, m = 5`
- Output: `12`
- **Explanation:** The sequence `[3, 8, 7, 12]` alternates as $3 < 8 > 7 < 12$, and every adjacent absolute difference is at most `5`. Its maximum element is `12`, which is the largest possible value.

**Example 2**

- Input: `n = 2, s = 4, m = 3`
- Output: `7`
- **Explanation:** The sequence `[4, 7]` is alternating, respects the difference limit, and reaches the greatest possible value, `7`.
