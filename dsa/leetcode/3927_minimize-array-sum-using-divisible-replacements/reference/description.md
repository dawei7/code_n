## Description

You receive an integer array `nums`. An operation chooses two positions `a` and `b` when the current value at `b` divides the current value at `a`, then copies `nums[b]` into position `a`. The operation may be applied any number of times.

Find the smallest sum that the array can have after any valid sequence of these replacements. A copied value may subsequently be used in another operation, but replacement never creates a number that was absent from the original array.
