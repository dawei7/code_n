## General
Given a string `s`, return *the longest* *palindromic* *substring* in `s`, the algorithm executes binary search over the search space to achieve logarithmic reduction. Key operations include bitwise operators (`&`, `|`, `^`, `<<`, `>>`) for fast bitmask state updates. Edge case handling: guards against empty/null inputs via early returns.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
