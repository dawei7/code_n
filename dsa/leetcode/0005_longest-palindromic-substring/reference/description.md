## Description

Given a non-empty string `s`, return a longest substring that is palindromic. A substring occupies one contiguous interval of `s`; a palindrome reads identically from left to right and from right to left.

The answer may have an odd or even number of characters. A single character is itself a palindrome, so every legal input has at least one valid result.

If several palindromic substrings share the maximum length, any one of them is acceptable. Characters are compared exactly as written, and the input contains only English letters and digits.
