## General
Given a **zero-based permutation** `nums` (**0-indexed**), build an array `ans` of the **same length** where $\text{ans}[i] = nums[\text{nums}[i]]$ for each $0 \le i < \text{nums.length}$ and return it, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(N)$ — Operation count bound.
- **Space Complexity**: $O(N)$ — Auxiliary memory allocation bound.
