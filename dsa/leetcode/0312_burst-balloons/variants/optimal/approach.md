## General
Given `n` balloons, indexed from `0` to $n - 1$. Each balloon is painted with a number on it represented by an array `nums`. You are asked to burst all the balloons, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n^3)$ — Operation count bound.
- **Space Complexity**: $O(n^2)$ — Auxiliary memory allocation bound.
