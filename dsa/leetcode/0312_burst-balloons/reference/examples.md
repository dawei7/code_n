## Examples

**Example 1**

- Input: `nums = [3,1,5,8]`
- Output: `167`
- Explanation: One optimal removal order changes the remaining values as `[3,1,5,8] -> [3,5,8] -> [3,8] -> [8] -> []`. Its rewards are `3*1*5 + 3*5*8 + 1*3*8 + 1*8*1 = 167`.

**Example 2**

- Input: `nums = [1,5]`
- Output: `10`
