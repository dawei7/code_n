## Examples

**Example 1**

- Input: `n = 12, primes = [2,7,13,19]`
- Output: `32`
- Explanation: The first twelve values are `[1,2,4,7,8,13,14,16,19,26,28,32]`, so the twelfth is `32`.

**Example 2**

- Input: `n = 1, primes = [2,3,5]`
- Output: `1`
- Explanation: The number `1` has no prime factors, so all of its prime factors vacuously belong to `primes`.
