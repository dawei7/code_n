## General
Given an asynchronous function `fn` and a time `t` in milliseconds, return a new **time limited** version of the input function. `fn` takes arguments provided to the **time limited **function, the JavaScript algorithm implements the solution for **Promise Time Limit**.

## Complexity detail
- **Time Complexity**: $O(a)$ — Operation count bound.
- **Space Complexity**: $O(a)$ — Auxiliary memory allocation bound.
