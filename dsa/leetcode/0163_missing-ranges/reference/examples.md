## Examples

**Example 1**

- Input: `nums = [0,1,3,50,75], lower = 0, upper = 99`
- Output: `[[2,2],[4,49],[51,74],[76,99]]`
- Explanation: The four missing intervals are `[2,2]`, `[4,49]`, `[51,74]`, and `[76,99]`.

**Example 2**

- Input: `nums = [-1], lower = -1, upper = -1`
- Output: `[]`
- Explanation: The only integer in the bounded interval is present, so no value and therefore no range is missing.
