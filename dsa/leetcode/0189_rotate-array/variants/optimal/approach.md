## General
Given an integer array `nums`, rotate the array to the right by `k` steps, where `k` is non-negative, the algorithm solves **Rotate Array** directly. Edge case handling: applies modulo arithmetic to prevent integer overflow.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
