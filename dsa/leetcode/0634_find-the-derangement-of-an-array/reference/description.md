## Description

In combinatorial mathematics, a **derangement** is a permutation in which no element remains in its original position. A permutation with even one fixed element is therefore not a derangement.

Given an integer `n`, begin with the ascending array containing every integer from `1` through `n`. Count how many permutations of that array are derangements. Because this count can be very large, return it modulo $10^9 + 7$.
