## General
Given A **boolean expression** is an expression that evaluates to either `true` or `false`. It can be in one of the following shapes:, the algorithm solves **Parsing A Boolean Expression** directly. Key operations include bitwise operators (`&`, `|`, `^`, `<<`, `>>`) for fast bitmask state updates.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
