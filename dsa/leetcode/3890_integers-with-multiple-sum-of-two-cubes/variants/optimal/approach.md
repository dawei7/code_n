## General
Given an integer `n`, the algorithm executes a single-pass linear scan through input elements. It utilizes a hash map (`dict`) to store element values and their indices/frequencies for $O(1)$ fast access.

## Complexity detail
- **Time Complexity**: $O(B^2 + G log G)$ — Operation count bound.
- **Space Complexity**: $O(B^2)$ — Auxiliary memory allocation bound.
