## General
Given a string `s` consisting of lowercase English letters, and an integer `k`, the algorithm solves **Minimum Deletions for At Most K Distinct Characters** directly. It utilizes a hash map (`dict`) to store element values and their indices/frequencies for $O(1)$ fast access.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
