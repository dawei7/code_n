## General
Given a **positive** integer `n`, return *the smallest positive integer that is a multiple of **both** *`2`* and *`n`, the algorithm solves **Smallest Even Multiple** directly. Edge case handling: applies modulo arithmetic to prevent integer overflow.

## Complexity detail
- **Time Complexity**: $O(1)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
