## General
Given an integer `num`, return *the number of steps to reduce it to zero*, the algorithm solves **Number of Steps to Reduce a Number to Zero** directly. Edge case handling: applies modulo arithmetic to prevent integer overflow.

## Complexity detail
- **Time Complexity**: $O(\log \texttt{num})$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
