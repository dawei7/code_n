## General
Given You have two soups, **A** and **B**, each starting with `n` mL. On every turn, one of the following four serving operations is chosen *at random*, each with probability `0.25` **independent** of all previous turns:, the algorithm solves **Soup Servings** directly. It utilizes a hash map (`dict`) to store element values and their indices/frequencies for $O(1)$ fast access, a dynamic programming memoization table to cache intermediate subproblem states.

## Complexity detail
- **Time Complexity**: $O(s^2)$ — Operation count bound.
- **Space Complexity**: $O(s^2)$ — Auxiliary memory allocation bound.
