## General
Given two strings `a` and `b` of the same length. Choose an index and split both strings **at the same index**, splitting `a` into two strings: $a_{prefix}$ and $a_{suffix}$ where $a = a_{prefix} + a_{suffix}$, and splittin..., the algorithm solves **Split Two Strings to Make Palindrome** directly.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
