## Examples

**Example 1**

- Input: `s = "III"`
- Output: `3`
- Explanation: `III` is the sum $1+1+1=3$.

**Example 2**

- Input: `s = "LVIII"`
- Output: `58`
- Explanation: `L = 50`, `V = 5`, and `III = 3`, for a total of 58.

**Example 3**

- Input: `s = "MCMXCIV"`
- Output: `1994`
- Explanation: `M = 1000`, `CM = 900`, `XC = 90`, and `IV = 4`, which sum to 1994.
