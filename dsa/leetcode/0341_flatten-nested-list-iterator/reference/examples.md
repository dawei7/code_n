## Examples

**Example 1**

- Input: `nestedList = [[1,1],2,[1,1]]`
- Output: `[1,1,2,1,1]`
- Explanation: Repeated calls to `next()` until `hasNext()` becomes `false` return the integers in the order `[1,1,2,1,1]`.

**Example 2**

- Input: `nestedList = [1,[4,[6]]]`
- Output: `[1,4,6]`
- Explanation: Repeated calls to `next()` until `hasNext()` becomes `false` return the integers in the order `[1,4,6]`.
