## General
Given We have `n` buildings numbered from `0` to $n - 1$. Each building has a number of employees. It's transfer season, and some employees want to change the building they reside in, the algorithm executes a single-pass linear scan through input elements. Key operations include bitwise operators (`&`, `|`, `^`, `<<`, `>>`) for fast bitmask state updates.

## Complexity detail
- **Time Complexity**: $O(n2^m)$ — Operation count bound.
- **Space Complexity**: $O(n+m)$ — Auxiliary memory allocation bound.
