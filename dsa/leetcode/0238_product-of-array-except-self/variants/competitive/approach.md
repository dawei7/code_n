## General
Given an integer array `nums`, return *an array* `answer` *such that* $\text{answer}[i]$ *is equal to the product of all the elements of* `nums` *except* $\text{nums}[i]$, the algorithm executes a single-pass linear scan through input elements. Edge case handling: guards against empty/null inputs via early returns.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
