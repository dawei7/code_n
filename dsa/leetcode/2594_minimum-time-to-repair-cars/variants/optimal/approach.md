## General
Given an integer array `ranks` representing the **ranks** of some mechanics. ranks_i is the rank of the $i^{\text{th}}$ mechanic. A mechanic with a rank `r` can repair n cars in $r * n^{2}$ minutes, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(m log c)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
