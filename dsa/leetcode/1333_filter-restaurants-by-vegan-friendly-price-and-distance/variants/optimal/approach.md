## General
Given the array `restaurants` where  $\text{restaurants}[i] = [\text{id}_{i}, \text{rating}_{i}, \text{veganFriendly}_{i}, \text{price}_{i}, \text{distance}_{i}]$. You have to filter the restaurants using three filters, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n\log n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
