## General
Given two strings `s1` and `s2`, both of length `n`, consisting of **lowercase** English letters, the algorithm solves **Check if Strings Can be Made Equal With Operations II** directly. It utilizes a hash map (`dict`) to store element values and their indices/frequencies for $O(1)$ fast access.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
