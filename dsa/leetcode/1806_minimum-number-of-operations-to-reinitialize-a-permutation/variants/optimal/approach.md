## General
Given an **even** integer `n`​​​​​​. You initially have a permutation `perm` of size `n`​​ where $\text{perm}[i] = i$​ **(0-indexed)**​​​​, the algorithm solves **Minimum Number of Operations to Reinitialize a Permutation** directly. Key operations include bitwise operators (`&`, `|`, `^`, `<<`, `>>`) for fast bitmask state updates.

## Complexity detail
- **Time Complexity**: $O(k)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
