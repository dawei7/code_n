## General
Given an integer array `nums` of size `n`. You are asked to solve `n` queries for each integer `i` in the range $0 \le i < n$, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(N)$ — Operation count bound.
- **Space Complexity**: $O(N)$ — Auxiliary memory allocation bound.
