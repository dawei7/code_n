## General
Given You are playing a game with integers. You start with the integer `1` and you want to reach the integer `target`, the algorithm solves **Minimum Moves to Reach Target Score** directly. Key operations include bitwise operators (`&`, `|`, `^`, `<<`, `>>`) for fast bitmask state updates. Edge case handling: applies modulo arithmetic to prevent integer overflow.

## Complexity detail
- **Time Complexity**: $O(log target)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
