## General
Given a string `s` and an integer `k`, the algorithm executes depth-first search (DFS) recursion to explore valid decision branches. It utilizes a hash map (`dict`) to store element values and their indices/frequencies for $O(1)$ fast access.

## Complexity detail
- **Time Complexity**: $O(n^2 * k)$ — Operation count bound.
- **Space Complexity**: $O(n * k)$ — Auxiliary memory allocation bound.
