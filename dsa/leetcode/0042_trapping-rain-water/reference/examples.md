## Examples

**Example 1**

- Input: `height = [0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1]`
- Output: `6`
- Explanation: The bars in this elevation map retain six unit squares of water in total. The independent diagram follows the input from left to right; `#` is elevation and `~` is retained water.

```text
              #
      # ~ ~ ~ # # ~ #
  # ~ # # ~ # # # # # #
------------------------
```

**Example 2**

- Input: `height = [4, 2, 0, 3, 2, 5]`
- Output: `9`
