## Description

You receive a nonempty array `nums` of positive integers. The **digit range** of one integer is the difference between its largest decimal digit and its smallest decimal digit. Every occurrence in the array is considered independently, including repeated values. For instance, the decimal digits of `5724` have largest digit $7$ and smallest digit $2$, so that value's digit range is $5$.

Determine the maximum digit range attained by any array element. Return the sum of all integers in `nums` whose own digit range equals that maximum. If several equal values occupy different positions and have the maximum range, each occurrence contributes to the sum.
