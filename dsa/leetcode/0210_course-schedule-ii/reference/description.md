## Description

You must take `numCourses` courses, labeled from `0` through `numCourses - 1`. Each pair `prerequisites[i] = [a_i, b_i]` requires course `b_i` to be taken before course `a_i`. For example, `[0,1]` means course `1` must precede course `0`.

Return an ordering in which all courses can be finished. When several valid orderings exist, any one is acceptable. If completing every course is impossible, return an empty array.
