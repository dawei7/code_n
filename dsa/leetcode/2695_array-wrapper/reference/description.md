## Description

Create a class `ArrayWrapper` that accepts an array of integers in its constructor. This class should have two features:

<ul>
	<li>When two instances of this class are added together with the `+` operator, the resulting value is the sum of all the elements in both arrays.</li>
	<li>When the `String()` function is called on the instance, it will return a comma separated string surrounded by brackets. For example, `[1,2,3]`.</li>
</ul>
