## Examples

**Example 1**

- Input: `s = "12"`
- Output: `2`
- Explanation: Grouping as `(1, 2)` gives `"AB"`, while grouping as `(12)` gives `"L"`.

**Example 2**

- Input: `s = "226"`
- Output: `3`
- Explanation: The valid groupings decode as `"BZ"` from `(2, 26)`, `"VF"` from `(22, 6)`, and `"BBF"` from `(2, 2, 6)`.

**Example 3**

- Input: `s = "06"`
- Output: `0`
- Explanation: `"06"` cannot stand for `F` because a code cannot have a leading zero. Therefore the whole string has no valid decoding.
