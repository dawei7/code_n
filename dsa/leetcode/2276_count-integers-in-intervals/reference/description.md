## Description

Given an **empty** set of intervals, implement a data structure that can:

<ul>
	<li>**Add** an interval to the set of intervals.</li>
	<li>**Count** the number of integers that are present in **at least one** interval.</li>
</ul>

Implement the `CountIntervals` class:

<ul>
	<li>`CountIntervals()` Initializes the object with an empty set of intervals.</li>
	<li>`void add(int left, int right)` Adds the interval `[left, right]` to the set of intervals.</li>
	<li>`int count()` Returns the number of integers that are present in **at least one** interval.</li>
</ul>

**Note** that an interval `[left, right]` denotes all the integers `x` where `left <= x <= right`.
