## General
Given an `n x n` array of integers `matrix`, return *the **minimum sum** of any **falling path** through* `matrix`, the algorithm executes a two-pointer approach to shrink boundaries or maintain a sliding window.

## Complexity detail
- **Time Complexity**: $O(n^2)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
