## Examples

**Example 1**

- Input: `nums = [1,4,2,5,3]`
- Output: `11`
- Explanation: The complete set of valid subarrays is `[1]`, `[4]`, `[2]`, `[5]`, `[3]`, `[1,4]`, `[2,5]`, `[1,4,2]`, `[2,5,3]`, `[1,4,2,5]`, and `[1,4,2,5,3]`.

**Example 2**

- Input: `nums = [3,2,1]`
- Output: `3`
- Explanation: The valid subarrays are `[3]`, `[2]`, and `[1]`.

**Example 3**

- Input: `nums = [2,2,2]`
- Output: `6`
- Explanation: The valid subarrays are `[2]`, `[2]`, `[2]`, `[2,2]`, `[2,2]`, and `[2,2,2]`. Equal-looking entries with different boundaries count separately.
