## General
Given two strings of the same length `s` and `t`. In one step you can choose **any character** of `t` and replace it with **another character**, the algorithm solves **Minimum Number of Steps to Make Two Strings Anagram** directly. It utilizes a hash map (`dict`) to store element values and their indices/frequencies for $O(1)$ fast access.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
