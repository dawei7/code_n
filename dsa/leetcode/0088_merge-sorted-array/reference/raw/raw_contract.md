## Function Contract

**Inputs**

- `nums1`: The first sorted sequence followed by enough placeholder capacity for the merge.
- `m`: The number of meaningful values initially stored in `nums1`.
- `nums2`: The second sorted sequence.
- `n`: The number of values in `nums2`.

**Return value**

Return `None`; merge the two non-decreasing sequences in place into `nums1`, using its trailing capacity for the final $m+n$ values.
