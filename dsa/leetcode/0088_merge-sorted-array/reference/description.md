## Description

You receive integer arrays `nums1` and `nums2`, both sorted in non-decreasing order, plus integers `m` and `n` giving their respective counts of meaningful elements.

Merge those meaningful elements into one non-decreasing sequence. Store the result directly in `nums1` rather than returning a separate array.

Array `nums1` has length `m + n`: its first `m` positions hold the values to merge, and its final `n` positions contain placeholder zeros that must be ignored as input. Array `nums2` has length `n`.
