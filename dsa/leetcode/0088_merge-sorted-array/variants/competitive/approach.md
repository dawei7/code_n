## General
Given two integer arrays `nums1` and `nums2`, sorted in **non-decreasing order**, and two integers `m` and `n`, representing the number of elements in `nums1` and `nums2` respectively, the algorithm solves **Merge Sorted Array** directly.

## Complexity detail
- **Time Complexity**: $O(m+n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
