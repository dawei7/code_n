## Examples

**Example 1**

- Input: `lists = [[1, 4, 5], [1, 3, 4], [2, 6]]`
- Output: `[1, 1, 2, 3, 4, 4, 5, 6]`
- Explanation: The three input lists and their merged order are:

```text
1 -> 4 -> 5
1 -> 3 -> 4    =>    1 -> 1 -> 2 -> 3 -> 4 -> 4 -> 5 -> 6
2 -> 6
```
