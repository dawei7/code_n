## General
Given `m x n` grid `image` which represents a grayscale image, where $\text{image}[i][j]$ represents a pixel with intensity in the range `[0..255]`. You are also given a **non-negative** integer `threshold`, the algorithm executes a single-pass linear scan through input elements. Edge case handling: guards against empty/null inputs via early returns.

## Complexity detail
- **Time Complexity**: $O(MN)$ — Operation count bound.
- **Space Complexity**: $O(MN)$ — Auxiliary memory allocation bound.
