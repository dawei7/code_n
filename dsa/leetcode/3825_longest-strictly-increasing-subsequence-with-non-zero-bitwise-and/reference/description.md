## Description

You are given an integer array `nums`.

A subsequence is formed by deleting any number of elements while retaining the relative order of those that remain. It is strictly increasing when each selected value after the first is greater than the preceding selected value.

Among the strictly increasing subsequences of `nums`, find the greatest length whose selected values have a non-zero bitwise AND. Return that length. If every possible subsequence has bitwise AND equal to zero, return `0`.
