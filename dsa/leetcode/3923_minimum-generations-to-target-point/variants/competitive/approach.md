## General
Given a 2D integer array `points` where $\text{points}[i] = [x_{i}, y_{i}, z_{i}]$ represents a point in 3D space, and an integer array `target` representing a target point, the algorithm executes breadth-first search (BFS) level-order traversal using a queue. Key operations include bitwise operators (`&`, `|`, `^`, `<<`, `>>`) for fast bitmask state updates.

## Complexity detail
- **Time Complexity**: $O(n + U^2)$ — Operation count bound.
- **Space Complexity**: $O(U)$ — Auxiliary memory allocation bound.
