## General
Given the `head` of a singly linked list, reverse the list, and return *the reversed list*, the algorithm executes a single-pass linear scan through input elements. It utilizes linked list node pointers (`val`, `next`) to process sequential node chains.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
