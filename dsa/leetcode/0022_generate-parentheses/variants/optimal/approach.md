## General
Given `n` pairs of parentheses, write a function to *generate all combinations of well-formed parentheses*, the algorithm executes depth-first search (DFS) recursion to explore valid decision branches.

## Complexity detail
- **Time Complexity**: $O(n \cdot C_n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
