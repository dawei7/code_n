## Examples

**Example 1**

- Input: `nums = [4,2,3,1]`
- Output: `9`
- Explanation:
  - The triplet `(4,2,3)` is valid because `4 + 2 + 3 = 9`, which is divisible by three.
  - The other valid triplet is `(2,3,1)`, whose sum is `2 + 3 + 1 = 6`.
  - The larger of those valid sums is `9`.

**Example 2**

- Input: `nums = [2,1,5]`
- Output: `0`
- Explanation:
  - The array contains only one possible three-element selection, and its sum is not divisible by three.
  - No valid triplet exists, so the result is `0`.
