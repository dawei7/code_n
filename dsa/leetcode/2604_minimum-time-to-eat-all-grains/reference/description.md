## Description

There are `n` hens and `m` grains on a line. You are given the initial positions of the hens and the grains in two integer arrays `hens` and `grains` respectively.

Any hen can eat any grain if they are on the same position. The time taken for a hen to move one unit is `1`. A hen can move in any direction and can eat any number of grains.

Return *the minimum time needed for the hens to eat all the grains*.
