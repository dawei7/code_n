## Constraints

- $1 \leq \texttt{s.length} \leq 10^5$
- `s` contains only lowercase English letters and space characters `' '`.
- `s` has no leading or trailing spaces.
- Every pair of adjacent words in `s` is separated by exactly one space.
- $0 \leq k < \texttt{t.length}$, so `k` is always a valid index of `t`.
