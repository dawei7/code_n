## Examples

**Example 1**

- Input: `s = "hello world", k = 0`
- Output: `"h"`
- Explanation: The expanded string is `t = "heelllllllooooo woorrrllllddddd"`. Therefore, `t[0] = "h"`.

**Example 2**

- Input: `s = "hello world", k = 15`
- Output: `" "`
- Explanation: The expanded string is `t = "heelllllllooooo woorrrllllddddd"`. Therefore, `t[15] = " "`, the separator between the expanded words.
