## General
Given There is a row of `m` houses in a small city, each house must be painted with one of the `n` colors (labeled from `1` to `n`), some houses that have been painted last summer should not be painted again, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(mtn)$ — Operation count bound.
- **Space Complexity**: $O(tn)$ — Auxiliary memory allocation bound.
