## General
Given a $n * n$ matrix `grid` of `0's` and `1's` only. We want to represent `grid` with a Quad-Tree, the algorithm executes depth-first search (DFS) recursion to explore valid decision branches.

## Complexity detail
- **Time Complexity**: $O(n^2)$ — Operation count bound.
- **Space Complexity**: $O(\log n)$ — Auxiliary memory allocation bound.
