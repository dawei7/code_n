## General
Given Alice has `n` balloons arranged on a rope. You are given a **0-indexed** string `colors` where $\text{colors}[i]$ is the color of the $$i^{\text{th}}$$ balloon, the algorithm solves **Minimum Time to Make Rope Colorful** directly.

## Complexity detail
- **Time Complexity**: $O(N)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
