## General
Given Design a hit counter which counts the number of hits received in the past `5` minutes (i.e., the past `300` seconds), the algorithm solves **Design Hit Counter** directly. It utilizes a hash map (`dict`) to store element values and their indices/frequencies for $O(1)$ fast access.

## Complexity detail
- **Time Complexity**: $O(1)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
