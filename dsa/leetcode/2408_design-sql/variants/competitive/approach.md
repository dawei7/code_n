## General
Given two string arrays, `names` and `columns`, both of size `n`. The $$i^{\text{th}}$$ table is represented by the name $\text{names}[i]$ and contains $\text{columns}[i]$ number of columns, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n + q + E)$ — Operation count bound.
- **Space Complexity**: $O(n + S)$ — Auxiliary memory allocation bound.
