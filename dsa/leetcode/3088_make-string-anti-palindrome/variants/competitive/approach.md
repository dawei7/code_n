## General
Given We call a string `s` of **even** length `n` an **anti-palindrome** if for each index $0 \le i < n$, $s[i] \neq s[n - i - 1]$, the algorithm executes a two-pointer approach to shrink boundaries or maintain a sliding window.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
