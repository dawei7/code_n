## Examples

**Example 1**

- Input: `s = "ab", t = "acb"`
- Output: `true`
- Explanation: Inserting `'c'` into `s` produces `t`.

**Example 2**

- Input: `s = "", t = ""`
- Output: `false`
- Explanation: The two strings are already equal, so producing `t` from `s` takes zero edits rather than exactly one.
