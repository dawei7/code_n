## General
Given A **row-sorted binary matrix** means that all elements are `0` or `1` and each row of the matrix is sorted in non-decreasing order, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(m+n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
