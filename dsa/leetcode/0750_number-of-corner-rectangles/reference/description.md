## Description

You are given an $m \times n$ integer matrix `grid` in which every entry is either `0` or `1`. Return the number of corner rectangles in the matrix.

A corner rectangle is determined by four distinct cells containing `1`: two cells in one row and two cells in another row, with the same two columns used in both rows. Those four positions form the corners of an axis-aligned rectangle. Only the corner values matter; cells on the rectangle's edges or in its interior may have either value.
