## Description

Given an integer `num`, return *a string of its **base 7** representation*.
### Function Contract

- `n`: Input parameter.
- Returns expected result.

### Examples
#### Example 1

- **Input:** $num = 100$
- **Output:** `"202"`
#### Example 2

- **Input:** $num = -7$
- **Output:** `"-10"`
### Constraints

- $-10^{7} \le num \le 10^{7}$
