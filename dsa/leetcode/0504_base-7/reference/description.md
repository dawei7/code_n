### 1. Description

Given an integer `num`, return *a string of its **base 7** representation*.

### 2. Function Contract

**Inputs**

- `num`: Input parameter (`int`).

**Return value**

- Returns `str`.

### 3. Examples

#### Example 1

- **Input:** $num = 100$
- **Output:** `"202"`

#### Example 2

- **Input:** $num = -7$
- **Output:** `"-10"`

### 4. Constraints

- $-10^{7} \le num \le 10^{7}$
