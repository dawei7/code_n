## General
Given a string `s`, return `true`* if *`s`* is a **good** string, or *`false`* otherwise*, the algorithm solves **Check if All Characters Have Equal Number of Occurrences** directly. It utilizes a hash map (`dict`) to store element values and their indices/frequencies for $O(1)$ fast access.

## Complexity detail
- **Time Complexity**: $O(N)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
