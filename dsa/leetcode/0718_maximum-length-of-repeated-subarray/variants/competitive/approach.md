## General
Uses binary search over search space. Maintains hash map (`dict`) for $O(1)$ average lookup, dynamic programming memoization store. Applies bitwise operations (`&`, `|`, `^`, `<<`, `>>`).

## Complexity detail

- **Space Complexity**: $O(\min(m, n))$ — Auxiliary memory allocation bound.
