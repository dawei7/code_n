## Function Contract

**Inputs**

- `root`: The non-null root of a complete binary tree containing $n$ nodes. Each node has an integer value and optional `left` and `right` children.

The level-order arrays shown in the examples serialize the tree from top to bottom and left to right.

**Return value**

Return the number of nodes whose value is equal to the maximum value in the subtree rooted at that same node.
