## Examples

**Example 1**

- **Input:** `NPV = [[1,2018,100],[7,2020,30],[13,2019,40],[1,2019,113],[2,2008,121],[3,2009,12],[11,2020,99],[7,2019,0]], Queries = [[1,2019],[2,2008],[3,2009],[7,2018],[7,2019],[7,2020],[13,2019]]`

`NPV`:

| id | year | npv |
|---:|---:|---:|
| 1 | 2018 | 100 |
| 7 | 2020 | 30 |
| 13 | 2019 | 40 |
| 1 | 2019 | 113 |
| 2 | 2008 | 121 |
| 3 | 2009 | 12 |
| 11 | 2020 | 99 |
| 7 | 2019 | 0 |

`Queries`:

| id | year |
|---:|---:|
| 1 | 2019 |
| 2 | 2008 |
| 3 | 2009 |
| 7 | 2018 |
| 7 | 2019 |
| 7 | 2020 |
| 13 | 2019 |

- **Output:** `[[1,2019,113],[2,2008,121],[3,2009,12],[7,2018,0],[7,2019,0],[7,2020,30],[13,2019,40]]`

| id | year | npv |
|---:|---:|---:|
| 1 | 2019 | 113 |
| 2 | 2008 | 121 |
| 3 | 2009 | 12 |
| 7 | 2018 | 0 |
| 7 | 2019 | 0 |
| 7 | 2020 | 30 |
| 13 | 2019 | 40 |

- **Explanation:** The pair `(7, 2018)` has no row in `NPV`, so its value is reported as `0`. Every other requested pair has a matching stored value, including the stored zero for `(7, 2019)`.
