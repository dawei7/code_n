## General
Executes a SQL query for **Seasonal Sales Analysis** using Common Table Expressions (CTEs), relational JOINs, window ranking functions, GROUP BY aggregations.

## Complexity detail
- **Time Complexity**: $O(S log S + P log P + G log G)$ — Operation count bound.
- **Space Complexity**: $O(S + P + G)$ — Auxiliary memory allocation bound.
