## General
Given An array `A` is larger than some array `B` if for the first index `i` where $A[i] \neq B[i]$, $A[i] > B[i]$, the algorithm executes a two-pointer approach to shrink boundaries or maintain a sliding window.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(k)$ — Auxiliary memory allocation bound.
