## General
Given We stack glasses in a pyramid, where the **first** row has `1` glass, the **second** row has `2` glasses, and so on until the 100^th row.  Each glass holds one cup of champagne, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(r^2)$ — Operation count bound.
- **Space Complexity**: $O(r)$ — Auxiliary memory allocation bound.
