## Constraints

- The number of nodes in the tree is in the range $[3, 10^4]$.
- $-10^9 \le \text{Node.val} \le 10^9$.
- All `Node.val` in the tree are unique.
- Exactly one node `from_node` has an invalid `right` pointer to `to_node`.
- `from_node` and `to_node` are at the same depth level, and `to_node` is strictly to the right of `from_node`.
