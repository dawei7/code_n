## Examples

**Example 1**

- Input: `Person = [[1,"a@b.com"],[2,"c@d.com"],[3,"a@b.com"]]`

| id | email |
|---:|---|
| 1 | a@b.com |
| 2 | c@d.com |
| 3 | a@b.com |

- Output: `Email = ["a@b.com"]`

| Email |
|---|
| a@b.com |

- Explanation: `a@b.com` occurs twice, so it is the only duplicate address.
