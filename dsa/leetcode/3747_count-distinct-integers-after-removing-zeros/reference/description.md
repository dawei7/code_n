## Description

You are given a positive integer `n` and consider every integer `x` in the inclusive range from `1` through `n`.

For each such `x`, take its ordinary decimal representation, delete every digit equal to zero, and write down the integer represented by the digits that remain. The nonzero digits keep their original relative order; different source integers may consequently produce the same written value.

Return how many distinct integers appear among all the values written down for the complete range.
