## Examples

**Example 1**

- Input: `n = 10`
- Output: `9`
- Explanation: Processing the ten source integers writes the sequence `1, 2, 3, 4, 5, 6, 7, 8, 9, 1`. Its distinct values are `1` through `9`, for a total of `9`.

**Example 2**

- Input: `n = 3`
- Output: `3`
- Explanation: The written values are `1, 2, 3`, and all three are distinct.
