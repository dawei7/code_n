## General
Given an integer array `nums` and an integer `k`, return *the number of **subarrays** of *`nums`* where the greatest common divisor of the subarray's elements is *`k`, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n log^2 V)$ — Operation count bound.
- **Space Complexity**: $O(log V)$ — Auxiliary memory allocation bound.
