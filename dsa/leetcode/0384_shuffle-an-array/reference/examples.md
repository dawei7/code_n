## Examples

**Example 1**

- Input: `operations = ["Solution","shuffle","reset","shuffle"], arguments = [[[1,2,3]],[],[],[]]`
- Output: `[null,[3,1,2],[1,2,3],[1,3,2]]`
- Explanation: Construct the object with `[1,2,3]`. The first shuffle may return any of its six permutations; the displayed run returns `[3,1,2]`. `reset()` returns the original `[1,2,3]`, and the next independent shuffle happens to return `[1,3,2]`.
