# Guided Example: Shuffle an Array

We trace the step-by-step Fisher–Yates (Knuth) in-place shuffling algorithm (`random.randrange(i, n)`), the mathematical proof of uniform permutation probability ($\frac{1}{N!}$), the contrast with naive biased shuffling ($N^N$ paths), and deep copy snapshot restoration (`reset()`) on representative array instances:

- **Input:** $nums = [1, 2, 3]$, command stream: `shuffle()`, `reset()`, `shuffle()`
- **Required output:** `[[2, 3, 1], [1, 2, 3], [3, 1, 2]]` (permutations may vary uniformly)
  - Trace of one valid `shuffle()` execution on $[1, 2, 3]$:
    - Step 1 ($i = 0$): Pick random $j \in [0, 2]$ (3 choices). Suppose $j = 1$:
      - Swap $nums[0] \leftrightarrow nums[1] \implies [2, 1, 3]$
      - Position 0 is finalized with value $2$
    - Step 2 ($i = 1$): Pick random $j \in [1, 2]$ (2 choices). Suppose $j = 2$:
      - Swap $nums[1] \leftrightarrow nums[2] \implies [2, 3, 1]$
      - Position 1 is finalized with value $3$
    - Step 3 ($i = 2$): Pick random $j \in [2, 2]$ (1 choice). $j = 2$:
      - Swap $nums[2] \leftrightarrow nums[2] \implies [2, 3, 1]$
    - Resulting permutation: $[2, 3, 1]$
  - Trace of `reset()`:
    - Restores working list from `self.original.copy()`
    - Returns exact pristine configuration: $[1, 2, 3]$
- **Total Permutations:** For $N = 3$, exactly $3! = 6$ permutations exist; each occurs with probability $\frac{1}{6}$
- **Single Element Array:** $nums = [1] \implies$ trivially returns $[1]$

This instance demonstrates in-place uniform permutation generation, mathematically proves why the random selection window must shrink ($[i, N - 1]$ instead of $[0, N - 1]$), avoids $O(N^2)$ element shifting, and achieves $O(N)$ linear time and $O(N)$ auxiliary space.

## 1. Instance & Teaching Goal

Given an integer array $nums = [1, 2, 3]$:
Implement the `Solution` class:
- `Solution(int[] nums)`: Initializes the object with the integer array `nums`.
- `reset()`: Resets the array to its original configuration and returns it.
- `shuffle()`: Returns a random shuffling of the array such that all $N!$ permutations are **equally likely** ($P = \frac{1}{N!}$).

```text
Input: nums = [1, 2, 3] (N = 3 -> 3! = 6 Permutations)

Permutation Space:
1. [1, 2, 3]  (Prob = 1/6)
2. [1, 3, 2]  (Prob = 1/6)
3. [2, 1, 3]  (Prob = 1/6)
4. [2, 3, 1]  (Prob = 1/6)
5. [3, 1, 2]  (Prob = 1/6)
6. [3, 2, 1]  (Prob = 1/6)

Fisher-Yates Process:
  i = 0: pick j in [0..2] -> swap nums[0], nums[j]
  i = 1: pick j in [1..2] -> swap nums[1], nums[j]
  i = 2: pick j in [2..2] -> swap nums[2], nums[j]
```

### The Naive Shuffling Bias Fallacy
A common intuitive attempt is:
```text
for i in range(n):
    j = random.randrange(0, n)   # BUGGY! Picks from the ENTIRE array!
    swap(nums[i], nums[j])
```
Why is this mathematically biased?
- The loop performs $N$ steps, each with $N$ choices $\implies N^N$ possible decision trees.
- For $N = 3$, $N^N = 3^3 = 27$ outcomes.
- But there are $3! = 6$ distinct permutations.
- Notice that $27$ is **not divisible by 6** ($27 / 6 = 4.5$). By the Pigeonhole Principle, some permutations will be generated by 5 paths, and others by only 4 paths!
- The distribution is non-uniform and biased.
- **The Fisher-Yates Fix:** By picking $j \in [i, N - 1]$, the total number of choices is $N \times (N - 1) \times \dots \times 1 = N!$, which divides evenly into $N!$ with ratio exactly $1$.

## 2. Conceptual Foundation & Invariants

### 1. State Maintenance:
- `self.nums`: The mutable active working array.
- `self.original = nums.copy()`: An immutable deep snapshot of the initial array.
- `reset()` copies `self.original` back into `self.nums`.

### 2. The Fisher–Yates Shuffle Protocol:
For $i = 0, 1, \dots, N - 1$:
1. Sample index $j$ uniformly from the **unplaced suffix**:
   $$
   j \sim \text{Uniform}(\{i, \; i + 1, \; \dots, \; N - 1\})
   $$
2. Swap elements at indices $i$ and $j$:
   $$
   nums[i], \; nums[j] \leftarrow nums[j], \; nums[i]
   $$
3. Index $i$ is now frozen into the finalized prefix.

### 3. Probability Proof of Uniformity:
- Probability that a specific element ends up at index $0$: $\frac{1}{N}$.
- Probability that a remaining element ends up at index $1$: $\left(1 - \frac{1}{N}\right) \times \frac{1}{N - 1} = \frac{N - 1}{N} \times \frac{1}{N - 1} = \frac{1}{N}$.
- By induction, every element has probability exactly $\frac{1}{N}$ of landing in any position.
- The probability of generating any specific permutation of length $N$ is:
  $$
  P = \frac{1}{N} \times \frac{1}{N - 1} \times \dots \times \frac{1}{1} = \frac{1}{N!}
  $$

> **Invariant.** After iteration $i$, prefix $nums[0 \dots i]$ contains a uniformly random sample of $i + 1$ distinct elements chosen without replacement from the original array.

## 3. Step-by-Step Worked Execution

We trace one shuffle pass on $nums = [1, 2, 3]$:
Initial: $nums = [1, 2, 3], N = 3$.

---

### Step 1: Iteration $i = 0$
- Active suffix: indices $[0, 2]$ containing $\{1, 2, 3\}$.
- Number of choices: $3 - 0 = 3$.
- Generate random index:
  $$
  j \in [0, 2] \implies \text{Suppose } j = 1
  $$
- Swap $nums[0]$ and $nums[1]$:
  $$
  nums[0] \leftrightarrow nums[1] \implies nums = [\mathbf{2}, \; \mathbf{1}, \; 3]
  $$
- Slot $0$ is finalized with value $2$.

---

### Step 2: Iteration $i = 1$
- Active suffix: indices $[1, 2]$ containing $\{1, 3\}$.
- Number of choices: $3 - 1 = 2$.
- Generate random index:
  $$
  j \in [1, 2] \implies \text{Suppose } j = 2
  $$
- Swap $nums[1]$ and $nums[2]$:
  $$
  nums[1] \leftrightarrow nums[2] \implies nums = [2, \; \mathbf{3}, \; \mathbf{1}]
  $$
- Slot $1$ is finalized with value $3$.

---

### Step 3: Iteration $i = 2$
- Active suffix: index $[2, 2]$ containing $\{1\}$.
- Number of choices: $3 - 2 = 1$.
- Generate random index:
  $$
  j \in [2, 2] \implies j = 2
  $$
- Swap $nums[2] \leftrightarrow nums[2]$ (Self-swap):
  $$
  nums = [2, 3, \mathbf{1}]
  $$
- All slots finalized!

---

### Step 4: `reset()` Invocation
- Caller requests `reset()`.
- Copy original snapshot:
  $$
  nums \leftarrow original.\text{copy}() \implies [\mathbf{1, 2, 3}]
  $$
- Pristine initial ordering restored!

## 4. Complete Execution Trace

```text
Initial Array: [1, 2, 3], original = [1, 2, 3]

shuffle() Execution:
i = 0: pick j in [0, 2] -> pick j=1 -> swap(nums[0], nums[1]) -> [2, 1, 3]
i = 1: pick j in [1, 2] -> pick j=2 -> swap(nums[1], nums[2]) -> [2, 3, 1]
i = 2: pick j in [2, 2] -> pick j=2 -> swap(nums[2], nums[2]) -> [2, 3, 1]
Returns: [2, 3, 1]

reset() Execution:
nums = original.copy() -> [1, 2, 3]
Returns: [1, 2, 3]
```

| Iteration $i$ | Finalized Index | Candidate Range for $j$ | Choice $j$ Picked | Swap Action | Array State After Step | Branch Probability |
|:---:|:---:|:---:|:---:|:---|:---:|:---:|
| Init | - | - | - | Snapshot copy | `[1, 2, 3]` | - |
| 0 | Slot 0 | $[0, 2]$ | $1$ | $nums[0] \leftrightarrow nums[1]$ | `[2, 1, 3]` | $\frac{1}{3}$ |
| 1 | Slot 1 | $[1, 2]$ | $2$ | $nums[1] \leftrightarrow nums[2]$ | `[2, 3, 1]` | $\frac{1}{2}$ |
| **2** | **Slot 2** | **$[2, 2]$** | **$2$** | **$nums[2] \leftrightarrow nums[2]$** | **`[2, 3, 1]`** | **$\frac{1}{1}$** |
| **`reset()`** | All | - | - | `original.copy()` | **`[1, 2, 3]`** | **$1$** |

## 5. Algorithmic Correctness

**Soundness.** The total number of execution branches is $\prod_{i=0}^{N-1} (N - i) = N!$. Because each choice at step $i$ is made with uniform probability $1 / (N - i)$, every branch has probability exactly $\prod \frac{1}{N - i} = \frac{1}{N!}$. Furthermore, each of the $N!$ branches leads to a distinct permutation. Thus, every permutation has probability exactly $1 / N!$.

**Completeness.** Every element in the array has an equal opportunity to be swapped into any slot $0 \dots N - 1$. The snapshot `self.original` is never mutated, ensuring that calling `reset()` restores the identical starting configuration regardless of how many times `shuffle()` was invoked.

---

## 6. Traps This Instance Exposes

- **Reference Aliasing Bug:** Writing `self.original = nums` without `.copy()` stores a reference to the same list. Subsequent swaps in `shuffle()` would mutate `self.original`, permanently destroying the initial order.
- **Off-by-One in `random.randrange`:** `random.randrange(i, n)` selects integers in $[i, n - 1]$. Using `random.randint(i, n)` would include $n$, causing an index out-of-range error.
- **Biased Shuffling ($[0, n-1]$):** Choosing $j \in [0, n - 1]$ at every step produces $N^N$ outcomes, which cannot distribute uniformly across $N!$ permutations, violating the problem's mathematical requirement.

---

## 7. Complexity Derivation

- **Time Complexity:**
  - `__init__(nums)`: $O(N)$ time to create the defensive copy of the array.
  - `reset()`: $O(N)$ time to copy `self.original` back into `self.nums`.
  - `shuffle()`: $O(N)$ time, performing exactly $N$ random number generations and $N$ array swaps.
- **Auxiliary Space Complexity:** $O(N)$ auxiliary space to store the original array snapshot `self.original`.
