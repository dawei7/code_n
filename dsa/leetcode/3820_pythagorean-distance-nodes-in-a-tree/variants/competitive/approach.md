## General
Given an integer `n` and an undirected tree with `n` nodes numbered from 0 to $n - 1$. The tree is represented by a 2D array `edges` of length $n - 1$, where $\text{edges}[i] = [u_{i}, v_{i}]$ indicates an undirected edge b..., the algorithm executes breadth-first search (BFS) level-order traversal using a queue.

## Complexity detail
- **Time Complexity**: $O(N)$ — Operation count bound.
- **Space Complexity**: $O(N)$ — Auxiliary memory allocation bound.
