## Examples

**Example 1**

- Input: `time = "19:34"`
- Output: `"19:39"`
- Explanation: Using the available digits `1`, `9`, `3`, and `4`, the closest next display is `19:39`, five minutes later. Although `19:33` also uses only those digits, it is reached after `23` hours and `59` minutes, so it is not the closest result.

**Example 2**

- Input: `time = "23:59"`
- Output: `"22:22"`
- Explanation: Using the available digits `2`, `3`, `5`, and `9`, the next closest display is `22:22`. Because it is numerically earlier than the input time, this occurrence is on the following day.
