## Examples

**Example 1**

- Input: `strs = ["eat", "tea", "tan", "ate", "nat", "bat"]`
- Output: `[["bat"], ["nat", "tan"], ["ate", "eat", "tea"]]`
- Explanation: No other input string can be rearranged into `"bat"`. Strings `"nat"` and `"tan"` can be rearranged into one another, as can `"ate"`, `"eat"`, and `"tea"`.

**Example 2**

- Input: `strs = [""]`
- Output: `[[""]]`

**Example 3**

- Input: `strs = ["a"]`
- Output: `[["a"]]`
