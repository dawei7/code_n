## Description

You are given an `n x n` square matrix of integers `grid`. Return the matrix such that:

<ul>
	<li>The diagonals in the **bottom-left triangle** (including the middle diagonal) are sorted in **non-increasing order**.</li>
	<li>The diagonals in the **top-right triangle** are sorted in **non-decreasing order**.</li>
</ul>
