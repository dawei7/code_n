## Examples

**Example 1**

- **Input:** `arr = [1,2,3]`
- **Output:** `2`
- **Explanation:** The values `1` and `2` qualify because their successors `2` and `3` occur in the array. The value `3` does not qualify because `4` is absent.

**Example 2**

- **Input:** `arr = [1,1,3,3,5,5,7,7]`
- **Output:** `0`
- **Explanation:** None of the values qualifies because the required successors `2`, `4`, `6`, and `8` are all absent.
