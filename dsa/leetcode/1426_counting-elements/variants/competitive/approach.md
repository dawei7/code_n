## General
Given an integer array `arr`, count how many elements `x` there are, such that $x + 1$ is also in `arr`. If there are duplicates in `arr`, count them separately, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
