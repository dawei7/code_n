## Description

You are given $n$ distinct points in the plane, where `points[i] = [x_i, y_i]`.

A boomerang is an ordered tuple `(i, j, k)` in which the distance from pivot point `i` to point `j` equals the distance from `i` to a different endpoint `k`. Because order matters, exchanging `j` and `k` produces another boomerang.

Return the total number of boomerangs.
