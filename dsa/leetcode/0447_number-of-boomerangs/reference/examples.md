## Examples

**Example 1**

- Input: `points = [[0,0],[1,0],[2,0]]`
- Output: `2`
- Explanation: The two ordered boomerangs are `[[1,0],[0,0],[2,0]]` and `[[1,0],[2,0],[0,0]]`.

**Example 2**

- Input: `points = [[1,1],[2,2],[3,3]]`
- Output: `2`

**Example 3**

- Input: `points = [[1,1]]`
- Output: `0`
