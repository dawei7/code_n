## General
Given There are `n` projects numbered from `0` to $n - 1$. You are given an integer array `milestones` where each $\text{milestones}[i]$ denotes the number of milestones the $$i^{\text{th}}$$ project has, the algorithm solves **Maximum Number of Weeks for Which You Can Work** directly.

## Complexity detail
- **Time Complexity**: $O(N)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
