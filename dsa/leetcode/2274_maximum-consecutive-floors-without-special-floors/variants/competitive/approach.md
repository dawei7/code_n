## General
Given Alice manages a company and has rented some floors of a building as office space. Alice has decided some of these floors should be **special floors**, used for relaxation only, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(m log m)$ — Operation count bound.
- **Space Complexity**: $O(log m)$ — Auxiliary memory allocation bound.
