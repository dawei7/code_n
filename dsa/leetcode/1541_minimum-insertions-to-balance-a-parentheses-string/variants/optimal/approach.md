## General
Given a parentheses string `s` containing only the characters `'('` and `')'`. A parentheses string is **balanced** if:, the algorithm solves **Minimum Insertions to Balance a Parentheses String** directly. Key operations include bitwise operators (`&`, `|`, `^`, `<<`, `>>`) for fast bitmask state updates.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
