## General
Given two integers `a` and `b`, return *the sum of the two integers without using the operators* `+` *and* `-`, the algorithm solves **Sum of Two Integers** directly. Key operations include bitwise operators (`&`, `|`, `^`, `<<`, `>>`) for fast bitmask state updates.

## Complexity detail
- **Time Complexity**: $O(w)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
