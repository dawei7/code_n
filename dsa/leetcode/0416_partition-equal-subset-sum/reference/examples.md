## Examples

**Example 1**

- Input: `nums = [1, 5, 11, 5]`
- Output: `true`
- Explanation: One valid partition is `[1, 5, 5]` and `[11]`; both subsets sum to $11$.

**Example 2**

- Input: `nums = [1, 2, 3, 5]`
- Output: `false`
- Explanation: No division of these element occurrences produces two subsets with equal sums.
