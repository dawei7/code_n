## Examples

**Example 1**

- Input: `head = [1,2,3,4,5]`
- Output: `[1,3,5,2,4]`

```text
Input positions:  1 -> 2 -> 3 -> 4 -> 5
Reordered list:   1 -> 3 -> 5 -> 2 -> 4
```

**Example 2**

- Input: `head = [2,1,3,5,6,4,7]`
- Output: `[2,3,6,7,1,5,4]`

```text
Input positions:  2 -> 1 -> 3 -> 5 -> 6 -> 4 -> 7
Reordered list:   2 -> 3 -> 6 -> 7 -> 1 -> 5 -> 4
```
