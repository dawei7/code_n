## Examples

**Example 1**

- **Input:** `postfix = ["3","4","+","2","*","7","/"]`
- **Output:** `2`
- **Explanation:** The tree represents `((3 + 4) * 2) / 7 = 14 / 7 = 2`.

**Example 2**

- **Input:** `postfix = ["4","5","2","7","+","-","*"]`
- **Output:** `-16`
- **Explanation:** The tree represents `4 * (5 - (7 + 2)) = 4 * (5 - 9) = 4 * -4 = -16`.

**Example 3**

- **Input:** `postfix = ["42"]`
- **Output:** `42`
- **Explanation:** A single operand becomes a leaf node evaluating to 42.
