## Constraints

- $1 \le \text{postfix.length} < 100$.
- `postfix.length` is odd.
- Operands consist of non-negative integers up to $10^5$.
- Operators consist of `"+"`, `"-"`, `"*"`, and `"/"`.
- `postfix` is guaranteed to be a valid postfix expression.
- All intermediate and final values are within $[-10^9, 10^9]$.
- Division truncates toward zero.
