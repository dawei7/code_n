## General
Given There is a restaurant with a single chef. You are given an array `customers`, where $\text{customers}[i] = [\text{arrival}_{i}, \text{time}_{i}]:$, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
