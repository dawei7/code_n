## General
Given You are implementing a program to use as your calendar. We can add a new event if adding the event will not cause a **double booking**, the algorithm solves **My Calendar I** directly. It utilizes a hash map (`dict`) to store element values and their indices/frequencies for $O(1)$ fast access.

## Complexity detail
- **Time Complexity**: $O(q \log C)$ — Operation count bound.
- **Space Complexity**: $O(q \log C)$ — Auxiliary memory allocation bound.
