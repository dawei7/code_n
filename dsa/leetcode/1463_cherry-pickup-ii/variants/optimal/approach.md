## General
Given a `rows x cols` matrix `grid` representing a field of cherries where $\text{grid}[i][j]$ represents the number of cherries that you can collect from the `(i, j)` cell, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(RC^2)$ — Operation count bound.
- **Space Complexity**: $O(C^2)$ — Auxiliary memory allocation bound.
