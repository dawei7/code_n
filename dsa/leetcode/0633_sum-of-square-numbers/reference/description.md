## Description

Given a non-negative integer `c`, decide whether there're two integers `a` and `b` such that $a^{2} + b^{2} = c$.
### Function Contract

- `n`: Input parameter.
- Returns expected result.

### Examples

#### Example 1

- **Input:** $c = 5$
- **Output:** `true`
- **Explanation:** 1 * 1 + 2 * 2 = 5
#### Example 2

- **Input:** $c = 3$
- **Output:** `false`
### Constraints

- $0 \le c \le 2^{31} - 1$
