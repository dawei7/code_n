## Description

An even number of people, given by `numPeople`, stand around a circle. Each person shakes hands with exactly one other person, so a complete arrangement contains `numPeople / 2` handshakes.

View each handshake as the connection between its two participants. An arrangement is valid only when every person is paired and no two of those connections cross.

Count all valid complete handshake arrangements. Because the count may be large, return it modulo $10^9+7$.
