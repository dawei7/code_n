## General
Given two positive integers `n` and `k`. A factor of an integer `n` is defined as an integer `i` where $n \% i = 0$, the algorithm executes a single-pass linear scan through input elements. Edge case handling: applies modulo arithmetic to prevent integer overflow.

## Complexity detail
- **Time Complexity**: $O(\sqrt{n})$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
