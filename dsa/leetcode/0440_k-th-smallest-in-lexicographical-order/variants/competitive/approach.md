## General
Given two integers `n` and `k`, return *the* $$k^{\text{th}}$$ *lexicographically smallest integer in the range* `[1, n]`, the algorithm executes a single-pass linear scan through input elements. Edge case handling: applies modulo arithmetic to prevent integer overflow.

## Complexity detail
- **Time Complexity**: $O(d^2)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
