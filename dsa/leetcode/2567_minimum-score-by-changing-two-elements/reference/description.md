## Description

You are given an integer array `nums`.

<ul>
	<li>The **low** score of `nums` is the **minimum** absolute difference between any two integers.</li>
	<li>The **high** score of `nums` is the **maximum** absolute difference between any two integers.</li>
	<li>The **score** of `nums` is the sum of the **high** and **low** scores.</li>
</ul>

Return the **minimum score** after **changing two elements** of `nums`.
