## Examples

**Example 1**

- Input: `s = "324"`
- Output: `324`
- Explanation: Return a `NestedInteger` that contains the single integer value `324`.

**Example 2**

- Input: `s = "[123,[456,[789]]]"`
- Output: `[123,[456,[789]]]`
- Explanation: The outer list has two members: integer `123` and a nested list. That nested list contains integer `456` and another one-element list containing integer `789`.
