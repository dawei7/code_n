## General
Given two integer arrays `nums1` and `nums2`. You are tasked to implement a data structure that supports queries of two types:, the algorithm executes a single-pass linear scan through input elements. It utilizes a hash map (`dict`) to store element values and their indices/frequencies for $O(1)$ fast access.

## Complexity detail
- **Time Complexity**: $O(n_2+a+cn_1)$ — Operation count bound.
- **Space Complexity**: $O(n_1+n_2)$ — Auxiliary memory allocation bound.
