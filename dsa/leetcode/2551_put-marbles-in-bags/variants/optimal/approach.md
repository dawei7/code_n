## General
Given You have `k` bags. You are given a **0-indexed** integer array `weights` where $\text{weights}[i]$ is the weight of the $$i^{\text{th}}$$ marble. You are also given the integer `k.`, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n log n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
