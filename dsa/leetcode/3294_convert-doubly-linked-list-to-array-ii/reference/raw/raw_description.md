## Description

You are given an **arbitrary** `node` from a **doubly linked list**, which contains nodes that have a next pointer and a previous pointer.

Return an integer array which contains the elements of the linked list **in order**.

**Example 1:**

<div class="example-block">
**Input:** <span class="example-io">head = [1,2,3,4,5], node = 5</span>

**Output:** <span class="example-io">[1,2,3,4,5]</span>

</div>

**Example 2:**

<div class="example-block">
**Input:** <span class="example-io">head = [4,5,6,7,8], node = 8</span>

**Output:** <span class="example-io">[4,5,6,7,8]</span>

</div>

**Constraints:**

	- The number of nodes in the given list is in the range `[1, 500]`.

	- `1 <= Node.val <= 1000`

	- All nodes have unique `Node.val`.
