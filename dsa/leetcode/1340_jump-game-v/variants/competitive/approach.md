## General
Uses two-pointer iteration. Maintains double-ended queue (`deque`) for $O(1)$ operations, dynamic programming memoization store. Applies bitwise operations (`&`, `|`, `^`, `<<`, `>>`).

## Complexity detail
- **Time Complexity**: $O(n\log n+nd)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
