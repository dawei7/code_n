## General
Given an array of integers `arr` and an integer `d`. In one step you can jump from index `i` to index:, the algorithm executes depth-first search (DFS) recursion to explore valid decision branches.

## Complexity detail
- **Time Complexity**: $O(n\log n+nd)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
