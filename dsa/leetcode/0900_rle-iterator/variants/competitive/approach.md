## General
Given We can use run-length encoding (i.e., **RLE**) to encode a sequence of integers. In a run-length encoded array of even length `encoding` (**0-indexed**), for all even `i`, $\text{encoding}[i]$ tells us the number of t..., the algorithm solves **RLE Iterator** directly.

## Complexity detail
- **Time Complexity**: $O(m+q)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
