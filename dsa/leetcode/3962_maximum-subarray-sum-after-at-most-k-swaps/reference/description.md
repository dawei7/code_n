## Description

You are given an integer array `nums` and a nonnegative integer `k`. In one operation, choose two distinct array positions and exchange the values stored at those positions. You may perform this operation at most `k` times, so using fewer swaps—or none at all—is permitted.

After the chosen swaps, select a nonempty subarray: a contiguous sequence of one or more elements in the resulting array. Return the largest subarray sum that can be obtained by choosing both the swaps and the final subarray optimally.
