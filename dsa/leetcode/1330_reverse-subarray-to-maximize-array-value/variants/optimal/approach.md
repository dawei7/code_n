## General
Given an integer array `nums`. The *value* of this array is defined as the sum of $|\text{nums}[i] - nums[i + 1]|$ for all $0 \le i < \text{nums.length} - 1$, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
