## General
Given a **1-indexed** integer array `prices`, where $\text{prices}[i]$ is the price of a particular stock on the $$i^{\text{th}}$$ day, your task is to select some of the elements of `prices` such that your selection is **l..., the algorithm executes a single-pass linear scan through input elements. It utilizes a hash map (`dict`) to store element values and their indices/frequencies for $O(1)$ fast access.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
