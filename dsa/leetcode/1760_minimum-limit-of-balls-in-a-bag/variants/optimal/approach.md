## General
Given an integer array `nums` where the $$i^{\text{th}}$$ bag contains $\text{nums}[i]$ balls. You are also given an integer `maxOperations`, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n\log M)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
