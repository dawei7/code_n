## Description

You are given a string `word`, and an integer `numFriends`.

Alice is organizing a game for her `numFriends` friends. There are multiple rounds in the game, where in each round:

<ul>
	<li>`word` is split into `numFriends` **non-empty** strings, such that no previous round has had the **exact** same split.</li>
	<li>All the split words are put into a box.</li>
</ul>

Find the <span data-keyword="lexicographically-smaller-string">lexicographically largest</span> string from the box after all the rounds are finished.
