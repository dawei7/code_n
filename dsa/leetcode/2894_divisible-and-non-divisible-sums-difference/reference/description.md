## Description

You are given positive integers `n` and `m`.

Define two integers as follows:

<ul>
	<li>`num1`: The sum of all integers in the range `[1, n]` (both **inclusive**) that are **not divisible** by `m`.</li>
	<li>`num2`: The sum of all integers in the range `[1, n]` (both **inclusive**) that are **divisible** by `m`.</li>
</ul>

Return *the integer* `num1 - num2`.
