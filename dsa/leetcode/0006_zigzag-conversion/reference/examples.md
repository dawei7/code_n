## Examples

**Example 1**

- Input: `s = "PAYPALISHIRING", numRows = 3`
- Output: `"PAHNAPLSIIGYIR"`

**Example 2**

- Input: `s = "PAYPALISHIRING", numRows = 4`
- Output: `"PINALSIGYAHRPI"`
- Explanation: With four rows, the zigzag placement is:

```text
P     I    N
A   L S  I G
Y A   H R
P     I
```

**Example 3**

- Input: `s = "A", numRows = 1`
- Output: `"A"`
