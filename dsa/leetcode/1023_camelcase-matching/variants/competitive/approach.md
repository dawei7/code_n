## General
Given an array of strings `queries` and a string `pattern`, return a boolean array `answer` where $\text{answer}[i]$ is `true` if $\text{queries}[i]$ matches `pattern`, and `false` otherwise, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(S)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
