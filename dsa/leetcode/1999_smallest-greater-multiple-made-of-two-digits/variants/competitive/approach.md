## General
Given three integers, `k`, `digit1`, and `digit2`, you want to find the **smallest** integer that is:, the algorithm executes a single-pass linear scan through input elements. Key operations include bitwise operators (`&`, `|`, `^`, `<<`, `>>`) for fast bitmask state updates. Edge case handling: applies modulo arithmetic to prevent integer overflow.

## Complexity detail
- **Time Complexity**: $O(2^D)$ — Operation count bound.
- **Space Complexity**: $O(2^D)$ — Auxiliary memory allocation bound.
