## General
Given three integers `x`, `y`, and `bound`, return *a list of all the **powerful integers** that have a value less than or equal to* `bound`, the algorithm solves **Powerful Integers** directly. It utilizes a hash set (`set`) to track unique elements and prevent duplicate processing in $O(1)$ time.

## Complexity detail
- **Time Complexity**: $O(AB)$ — Operation count bound.
- **Space Complexity**: $O(A+B+R)$ — Auxiliary memory allocation bound.
