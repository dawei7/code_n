## Description

Write a bash script to calculate the <span data-keyword="frequency-textfile">frequency</span> of each word in a text file `words.txt`.

For simplicity sake, you may assume:

<ul>
	<li>`words.txt` contains only lowercase characters and space `' '` characters.</li>
	<li>Each word must consist of lowercase characters only.</li>
	<li>Words are separated by one or more whitespace characters.</li>
</ul>
