## General
Given an integer `length` and an array `updates` where $\text{updates}[i] = [\text{startIdx}_{i}, \text{endIdx}_{i}, \text{inc}_{i}]$, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(length + q)$ — Operation count bound.
- **Space Complexity**: $O(length)$ — Auxiliary memory allocation bound.
