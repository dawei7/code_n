## General
Given a wooden stick of length `n` units. The stick is labelled from `0` to `n`. For example, a stick of length **6** is labelled as follows:, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(c^3)$ — Operation count bound.
- **Space Complexity**: $O(c^2)$ — Auxiliary memory allocation bound.
