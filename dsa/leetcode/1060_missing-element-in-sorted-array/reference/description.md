## Description

An integer array `nums` contains unique values in **ascending order**. Starting from its leftmost value, consider every integer that does not appear in the array and list those missing values in ascending order.

Given a positive integer `k`, return the $k$th value in that missing sequence. Values below `nums[0]` are not counted. After all gaps inside the array have been exhausted, the sequence continues with consecutive integers beyond the last array value.
