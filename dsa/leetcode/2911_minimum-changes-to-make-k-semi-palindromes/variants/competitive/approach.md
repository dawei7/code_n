## General
Uses two-pointer iteration. Maintains hash map (`dict`) for $O(1)$ average lookup, dynamic programming memoization store. Applies bitwise operations (`&`, `|`, `^`, `<<`, `>>`).

## Complexity detail
- **Time Complexity**: $O(n^3 log(n) + k n^2)$ — Operation count bound.
- **Space Complexity**: $O(n^2 + k n)$ — Auxiliary memory allocation bound.
