## Description

A string is a **`k`-palindrome** when deleting no more than `k` of its characters can leave a palindrome. Deletions may occur at any positions; every character that remains keeps its original relative order.

Given a string `s` and an integer `k`, determine whether `s` is a `k`-palindrome. The deletion allowance is an upper bound, so using fewer than `k` deletions is permitted.
