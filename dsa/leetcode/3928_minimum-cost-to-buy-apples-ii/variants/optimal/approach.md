## General
Uses two-pointer iteration. Maintains double-ended queue (`deque`) for $O(1)$ operations, priority queue (`heapq`) for dynamic minimum/maximum tracking.

## Complexity detail
- **Time Complexity**: $O(n log n (n + m))$ — Operation count bound.
- **Space Complexity**: $O(n + m)$ — Auxiliary memory allocation bound.
