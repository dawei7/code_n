## Constraints

- $1 \le n \le 1000$
- `prices.length == n`
- $1 \le \texttt{prices}[i] \le 10^9$
- $0 \le \texttt{roads.length} \le \min(n(n-1)/2, 2000)$
- `roads[i] = [u_i, v_i, cost_i, tax_i]`
- $0 \le u_i, v_i \le n-1$
- $u_i \ne v_i$
- $1 \le cost_i \le 10^9$
- $1 \le tax_i \le 100$
- No undirected edge is repeated.
