## General
Given a **0-indexed** 2D integer array `questions` where $\text{questions}[i] = [\text{points}_{i}, \text{brainpower}_{i}]$, the algorithm executes a single-pass linear scan through input elements. It utilizes a dynamic programming memoization table to cache intermediate subproblem states.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
