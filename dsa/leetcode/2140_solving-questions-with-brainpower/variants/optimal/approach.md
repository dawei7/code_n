## General
Given a **0-indexed** 2D integer array `questions` where $\text{questions}[i] = [\text{points}_{i}, \text{brainpower}_{i}]$, the algorithm executes depth-first search (DFS) recursion to explore valid decision branches.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
