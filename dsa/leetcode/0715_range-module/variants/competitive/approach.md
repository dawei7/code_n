## General
Given A Range Module is a module that tracks ranges of numbers. Design a data structure to track the ranges represented as **half-open intervals** and query about them, the algorithm executes binary search over the search space to achieve logarithmic reduction.

## Complexity detail
- **Time Complexity**: $O(q \log C)$ — Operation count bound.
- **Space Complexity**: $O(q \log C)$ — Auxiliary memory allocation bound.
