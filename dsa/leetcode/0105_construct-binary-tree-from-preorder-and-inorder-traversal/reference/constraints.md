## Constraints

- `1 <= preorder.length <= 3000`
- `inorder.length == preorder.length`
- Each value in `preorder` and `inorder` is between `-3000` and `3000`, inclusive.
- Both arrays contain only unique values.
- Every value in `inorder` also occurs in `preorder`.
- `preorder` is guaranteed to be the tree's preorder traversal.
- `inorder` is guaranteed to be the tree's inorder traversal.
