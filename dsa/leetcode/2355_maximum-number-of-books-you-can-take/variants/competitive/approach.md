## General
Given a **0-indexed** integer array `books` of length `n` where $\text{books}[i]$ denotes the number of books on the $$i^{\text{th}}$$ shelf of a bookshelf, the algorithm executes a two-pointer approach to shrink boundaries or maintain a sliding window.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
