### 1. Description

Given an integer `n`, add a dot (".") as the thousands separator and return it in string format.

### 2. Function Contract

- `n`: Input parameter.
- Returns expected result.

### 3. Examples

#### Example 1

- **Input:** $n = 987$
- **Output:** `"987"`
#### Example 2

- **Input:** $n = 1234$
- **Output:** `"1.234"`

### 4. Constraints

- $0 \le n \le 2^{31} - 1$
