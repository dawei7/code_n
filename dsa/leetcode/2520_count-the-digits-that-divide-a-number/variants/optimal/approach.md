## General
Given an integer `num`, return *the number of digits in `num` that divide *`num`, the algorithm solves **Count the Digits That Divide a Number** directly. Edge case handling: applies modulo arithmetic to prevent integer overflow.

## Complexity detail
- **Time Complexity**: $O(d)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
