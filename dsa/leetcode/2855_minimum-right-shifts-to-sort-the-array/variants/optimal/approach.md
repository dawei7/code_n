## General
Given a **0-indexed** array `nums` of length `n` containing **distinct** positive integers. Return *the **minimum** number of **right shifts** required to sort *`nums`* and *`-1`* if this is not possible.*, the algorithm solves **Minimum Right Shifts to Sort the Array** directly.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
