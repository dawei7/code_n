## Description

In a playoff contest, stronger teams should meet weaker teams in early rounds. Given `n` teams ranked from `1`
through `n`, with rank `1` strongest and rank `n` weakest, return the complete contest pairing as a string.

Write a match as `(left,right)`, using parentheses for each pairing and a comma between its two participants. In every
round, pair the strongest remaining team or bracket group with the weakest, then the second strongest with the second
weakest, and continue inward.
