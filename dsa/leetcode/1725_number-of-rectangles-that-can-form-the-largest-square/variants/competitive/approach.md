## General
Given an array `rectangles` where $\text{rectangles}[i] = [l_{i}, w_{i}]$ represents the $$i^{\text{th}}$$ rectangle of length $l_{i}$ and width $w_{i}$, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
