## General
Given **Run-length encoding** is a compression algorithm that allows for an integer array `nums` with many segments of **consecutive repeated** numbers to be represented by a (generally smaller) 2D array `encoded`. Each $\t..., the algorithm solves **Product of Two Run-Length Encoded Arrays** directly. Edge case handling: guards against empty/null inputs via early returns.

## Complexity detail
- **Time Complexity**: $O(M + N)$ — Operation count bound.
- **Space Complexity**: $O(M + N)$ — Auxiliary memory allocation bound.
