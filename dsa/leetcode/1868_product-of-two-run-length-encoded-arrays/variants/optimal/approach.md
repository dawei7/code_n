## General
Given **Run-length encoding** is a compression algorithm that allows for an integer array `nums` with many segments of **consecutive repeated** numbers to be represented by a (generally smaller) 2D array `encoded`. Each $\t..., the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(M + N)$ — Operation count bound.
- **Space Complexity**: $O(M + N)$ — Auxiliary memory allocation bound.
