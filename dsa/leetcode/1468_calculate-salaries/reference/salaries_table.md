## Salaries Table

`Salaries` records each employee's company, identity, name, and salary.

| Column Name | Type |
|---|---|
| `company_id` | `int` |
| `employee_id` | `int` |
| `employee_name` | `varchar` |
| `salary` | `int` |

In SQL, `(company_id, employee_id)` is the table's composite primary key.
