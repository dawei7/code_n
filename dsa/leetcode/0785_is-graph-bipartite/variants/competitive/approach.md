## General
Given There is an **undirected** graph with `n` nodes, where each node is numbered between `0` and $n - 1$. You are given a 2D array `graph`, where $\text{graph}[u]$ is an array of nodes that node `u` is adjacent to. More f..., the algorithm executes a single-pass linear scan through input elements. It utilizes a hash map (`dict`) to store element values and their indices/frequencies for $O(1)$ fast access. Key operations include bitwise operators (`&`, `|`, `^`, `<<`, `>>`) for fast bitmask state updates.

## Complexity detail
- **Time Complexity**: $O(V + E)$ — Operation count bound.
- **Space Complexity**: $O(V)$ — Auxiliary memory allocation bound.
