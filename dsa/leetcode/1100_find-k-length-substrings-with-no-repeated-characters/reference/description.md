## Description

Given a string `s` and an integer `k`, inspect every contiguous substring whose length is exactly `k`. A substring is determined by consecutive positions, so different starting positions are counted independently even when their text happens to match.

A length-`k` substring qualifies only when none of its characters is repeated within that substring. Return the number of qualifying substrings. When `k` is greater than the length of `s`, no complete length-`k` substring exists and the count is zero.
