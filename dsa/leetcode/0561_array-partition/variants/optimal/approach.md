## General
Given an integer array `nums` of `2n` integers, group these integers into `n` pairs $(a_{1}, b_{1}), (a_{2}, b_{2}), ..., (a_{n}, b_{n})$ such that the sum of $min(a_{i}, b_{i})$ for all `i` is **maximized**. Return* the ma..., the algorithm solves **Array Partition** directly.

## Complexity detail
- **Time Complexity**: $O(n \log n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
