## Constraints

- $m = \lvert \texttt{room} \rvert$
- $n = \lvert \texttt{room[i]} \rvert$
- $1 \le m \le 100$
- $1 \le n \le 200$
- Every `room[i][j]` is either `0` or `1`.
- $0 \le \texttt{row} < m$
- $0 \le \texttt{col} < n$
- `room[row][col] == 1`.
- Every empty cell is reachable from the starting position.
