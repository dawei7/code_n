## Examples

**Example 1**

- Input: `n = 7`
- Output: `0`
- Explanation: The binary representation of `7` is `"111"`. Reversing it also gives `"111"`, so the strings already match and no bit needs to be flipped.

**Example 2**

- Input: `n = 10`
- Output: `4`
- Explanation: The binary representation of `10` is `"1010"`, whose reverse is `"0101"`. Every one of the four positions differs from its target bit, so all four bits must be flipped. The minimum is therefore `4`.
