## General
Given an integer array `nums` of length `n`, you want to create an array `ans` of length `2n` where $\text{ans}[i] = \text{nums}[i]$ and $ans[i + n] = \text{nums}[i]$ for $0 \le i < n$ (**0-indexed**), the algorithm solves **Concatenation of Array** directly.

## Complexity detail
- **Time Complexity**: $O(N)$ — Operation count bound.
- **Space Complexity**: $O(N)$ — Auxiliary memory allocation bound.
