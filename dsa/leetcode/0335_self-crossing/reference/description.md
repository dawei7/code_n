## Description

You are given an integer array `distance`. Begin at the point $(0,0)$ in the Cartesian plane.

Move `distance[0]` meters north, `distance[1]` meters west, `distance[2]` meters south, and `distance[3]` meters east. Continue cycling through those directions; equivalently, turn counter-clockwise after every move.

Return `true` if the resulting path crosses itself, or `false` if it never does.
