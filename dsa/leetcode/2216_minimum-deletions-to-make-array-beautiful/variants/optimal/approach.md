## General
Given a **0-indexed** integer array `nums`. The array `nums` is **beautiful** if:, the algorithm solves **Minimum Deletions to Make Array Beautiful** directly. Edge case handling: applies modulo arithmetic to prevent integer overflow.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
