## General
Given two integer arrays of size 2: $d = [d_{1}, d_{2}]$ and $r = [r_{1}, r_{2}]$, the algorithm solves **Minimum Time to Complete All Deliveries** directly. It utilizes a hash map (`dict`) to store element values and their indices/frequencies for $O(1)$ fast access.

## Complexity detail
- **Time Complexity**: $O(1)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
