## General
Given A **value-equal** string is a string where **all** characters are the same, the algorithm solves **Check if String Is Decomposable Into Value-Equal Substrings** directly. Edge case handling: applies modulo arithmetic to prevent integer overflow.

## Complexity detail
- **Time Complexity**: $O(N)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
