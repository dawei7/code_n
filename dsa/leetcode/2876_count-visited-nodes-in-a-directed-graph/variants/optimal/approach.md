## General
Given There is a **directed** graph consisting of `n` nodes numbered from `0` to $n - 1$ and `n` directed edges, the algorithm executes a single-pass linear scan through input elements. Edge case handling: guards against empty/null inputs via early returns.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
