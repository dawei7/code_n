## General
Given a collection of numbers, `nums`, that might contain duplicates, return *all possible unique permutations **in any order**.*, the algorithm executes depth-first search (DFS) recursion to explore valid decision branches.

## Complexity detail
- **Time Complexity**: $O(n \cdot n!)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
