## Constraints

- $1 \le \lvert\texttt{nums1}\rvert \le 5$
- $1 \le \lvert\texttt{nums2}\rvert \le 5\cdot10^4$
- $1 \le \texttt{nums1[i]},\texttt{nums2[i]} \le 10^5$
- $1 \le \lvert\texttt{queries}\rvert \le 5\cdot10^4$
- Every `queries[i]` has length `2` or `4`.
- A four-value query has the form `[1, x, y, val]`.
- A two-value query has the form `[2, tot]`.
- $0 \le x \le y < \lvert\texttt{nums2}\rvert$
- $1 \le \texttt{val} \le 10^5$
- $1 \le \texttt{tot} \le 10^9$
