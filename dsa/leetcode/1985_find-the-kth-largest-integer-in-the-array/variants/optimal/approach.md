## General
Given an array of strings `nums` and an integer `k`. Each string in `nums` represents an integer without leading zeros, the algorithm solves **Find the Kth Largest Integer in the Array** directly.

## Complexity detail
- **Time Complexity**: $O(N\log N \cdot L)$ — Operation count bound.
- **Space Complexity**: $O(N)$ — Auxiliary memory allocation bound.
