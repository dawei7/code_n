## General
Given an array of strings `chunks`. Concatenate all strings in `chunks` in order to form a string `s`, the algorithm executes a single-pass linear scan through input elements. It utilizes a hash map (`dict`) to store element values and their indices/frequencies for $O(1)$ fast access.

## Complexity detail
- **Time Complexity**: $O(C + Q)$ — Operation count bound.
- **Space Complexity**: $O(C + Q)$ — Auxiliary memory allocation bound.
