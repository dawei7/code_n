## Description

You are given two strings `s` and `t`.

String `t` is generated by random shuffling string `s` and then add one more letter at a random position.

Return the letter that was added to `t`.
### Function Contract

**Inputs**

- `s`: The original lowercase string, which may be empty.
- `t`: A shuffled copy of `s` plus exactly one additional lowercase letter.

**Return value**

Return the extra character occurrence found in `t`.

### Examples

#### Example 1

- **Input:** `s = "abcd", t = "abcde"`
- **Output:** `"e"`
- **Explanation:** 'e' is the letter that was added.
#### Example 2

- **Input:** `s = "", t = "y"`
- **Output:** `"y"`
### Constraints

- $0 \le \text{s.length} \le 1000$

- $\text{t.length} = \text{s.length} + 1$

- `s` and `t` consist of lowercase English letters.
