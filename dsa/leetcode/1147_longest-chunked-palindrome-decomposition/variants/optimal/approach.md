## General
Given a string `text`. You should split it to k substrings $(\text{subtext}_{1}, \text{subtext}_{2}, ..., \text{subtext}_{k})$ such that:, the algorithm solves **Longest Chunked Palindrome Decomposition** directly. Edge case handling: guards against empty/null inputs via early returns.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
