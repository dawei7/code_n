## Examples

**Example 1**

- Input: `s = "abcabcbb"`
- Output: `3`
- Explanation: `"abc"` is one longest valid substring and has length 3. `"bca"` and `"cab"` are valid longest answers as well.

**Example 2**

- Input: `s = "bbbbb"`
- Output: `1`
- Explanation: A single `"b"` is the longest substring without a repeated character, so the answer is 1.

**Example 3**

- Input: `s = "pwwkew"`
- Output: `3`
- Explanation: `"wke"` is a valid longest substring of length 3. Although `"pwke"` has no repeated character, it is a subsequence rather than a substring because its characters are not contiguous.
