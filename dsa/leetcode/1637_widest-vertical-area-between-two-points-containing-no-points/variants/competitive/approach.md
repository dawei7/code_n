## General
Given `n` `points` on a 2D plane where $\text{points}[i] = [x_{i}, y_{i}]$, Return* the **widest vertical area** between two points such that no points are inside the area.*, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n\log n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
