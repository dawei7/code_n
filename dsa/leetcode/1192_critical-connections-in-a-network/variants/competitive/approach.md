## General
Given There are `n` servers numbered from `0` to $n - 1$ connected by undirected server-to-server `connections` forming a network where $\text{connections}[i] = [a_{i}, b_{i}]$ represents a connection between servers $a_{i}..., the algorithm executes depth-first search (DFS) recursion to explore valid decision branches. Key operations include bitwise operators (`&`, `|`, `^`, `<<`, `>>`) for fast bitmask state updates.

## Complexity detail
- **Time Complexity**: $O(n+m)$ — Operation count bound.
- **Space Complexity**: $O(n+m)$ — Auxiliary memory allocation bound.
