## Description

Design a max stack: a data structure that retains ordinary last-in-first-out stack behavior while also supporting direct access to the greatest stored value.

The structure must support construction, insertion, ordinary top removal and inspection, maximum inspection, and maximum removal. Inspecting the top or maximum does not change the stack. When the maximum value occurs more than once, maximum removal must delete only its top-most occurrence; all surviving elements remain in their existing stack order.
