## General
Given We run a preorder depth-first search (DFS) on the `root` of a binary tree, the algorithm solves **Recover a Tree From Preorder Traversal** directly. It utilizes binary tree node references (`val`, `left`, `right`) to traverse structural hierarchies.

## Complexity detail
- **Time Complexity**: $O(L)$ — Operation count bound.
- **Space Complexity**: $O(H)$ — Auxiliary memory allocation bound.
