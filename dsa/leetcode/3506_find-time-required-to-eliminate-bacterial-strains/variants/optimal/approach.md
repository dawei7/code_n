## General
Given an integer array `timeReq` and an integer `splitTime`, the algorithm solves **Find Time Required to Eliminate Bacterial Strains** directly. It utilizes a priority queue (`heapq`) to maintain dynamic minimum/maximum element ordering.

## Complexity detail
- **Time Complexity**: $O(n log n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
