## Examples

**Example 1**

- Input: `intervals = [[1, 3], [6, 9]], newInterval = [2, 5]`
- Output: `[[1, 5], [6, 9]]`

**Example 2**

- Input: `intervals = [[1, 2], [3, 5], [6, 7], [8, 10], [12, 16]], newInterval = [4, 8]`
- Output: `[[1, 2], [3, 10], [12, 16]]`
- Explanation: New interval `[4, 8]` overlaps `[3, 5]`, `[6, 7]`, and `[8, 10]`, so those four intervals combine as `[3, 10]`.
