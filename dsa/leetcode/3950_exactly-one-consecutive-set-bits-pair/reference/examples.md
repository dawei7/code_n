## Examples

**Example 1**

- Input: `n = 6`
- Output: `true`
- Explanation:
  - The binary representation of `6` is `110`.
  - It contains exactly one adjacent `11` pair, so the result is `true`.

**Example 2**

- Input: `n = 5`
- Output: `false`
- Explanation:
  - The binary representation of `5` is `101`.
  - No adjacent positions are both set, so the result is `false`.
