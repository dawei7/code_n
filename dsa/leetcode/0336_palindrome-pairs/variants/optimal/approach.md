## General
Given a **0-indexed** array of **unique** strings `words`, the algorithm executes a single-pass linear scan through input elements. It utilizes a hash map (`dict`) to store element values and their indices/frequencies for $O(1)$ fast access.

## Complexity detail
- **Time Complexity**: $O(S + P)$ — Operation count bound.
- **Space Complexity**: $O(S + P)$ — Auxiliary memory allocation bound.
