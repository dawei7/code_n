## General
Executes a SQL query for **Longest Winning Streak** using Common Table Expressions (CTEs), relational JOINs, window ranking functions, GROUP BY aggregations. Edge cases: replaces NULL values using `COALESCE` guard.

## Complexity detail
- **Time Complexity**: $O(n \log n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
