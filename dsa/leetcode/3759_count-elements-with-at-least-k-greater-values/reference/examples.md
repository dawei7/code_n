## Examples

**Example 1**

- Input: `nums = [3,1,2], k = 1`
- Output: `2`
- Explanation: Both `1` and `2` have at least one array element greater than themselves. Nothing is greater than `3`, so exactly two elements qualify.

**Example 2**

- Input: `nums = [5,5,5], k = 2`
- Output: `0`
- Explanation: Every value equals `5`, so no occurrence has any strictly greater element. Consequently, none can meet the requirement of two greater values.
