## General
Given A cell `(r, c)` of an excel sheet is represented as a string `"<col><row>"` where:, the algorithm executes a single-pass linear scan through input elements. Key operations include bitwise operators (`&`, `|`, `^`, `<<`, `>>`) for fast bitmask state updates.

## Complexity detail
- **Time Complexity**: $O(A)$ — Operation count bound.
