## Description

A player's install date is the date of that player's first login. Players whose install date is the same form one install cohort.

For every install date $x$, report the cohort size and its day-one retention. The retained players are precisely those cohort members who logged in again on the calendar day immediately after $x$. Divide that count by the cohort size and round the result to two decimal places. Return one row per install date in any order.
