## General
Given an integer `mass`, which represents the original mass of a planet. You are further given an integer array `asteroids`, where $\text{asteroids}[i]$ is the mass of the $$i^{\text{th}}$$ asteroid, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n log n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
