## General
Given the array `queries` of positive integers between `1` and `m`, you have to process all $\text{queries}[i]$ (from `i=0` to `i=queries.length-1`) according to the following rules:, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O((m+q)\log(m+q))$ — Operation count bound.
- **Space Complexity**: $O(m+q)$ — Auxiliary memory allocation bound.
