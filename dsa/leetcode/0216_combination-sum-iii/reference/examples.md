## Examples

**Example 1**

- Input: `k = 3, n = 7`
- Output: `[[1,2,4]]`
- Explanation: `1 + 2 + 4 = 7`, and there is no other valid combination.

**Example 2**

- Input: `k = 3, n = 9`
- Output: `[[1,2,6],[1,3,5],[2,3,4]]`
- Explanation: The three sums are `1 + 2 + 6 = 9`, `1 + 3 + 5 = 9`, and `2 + 3 + 4 = 9`; no other valid combination exists.

**Example 3**

- Input: `k = 4, n = 1`
- Output: `[]`
- Explanation: Four different values from `1` through `9` have a minimum possible sum of `1 + 2 + 3 + 4 = 10`. Since `10 > 1`, no valid combination exists.
