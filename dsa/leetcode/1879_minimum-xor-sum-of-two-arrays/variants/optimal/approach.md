## General
Given two integer arrays `nums1` and `nums2` of length `n`, the algorithm executes a single-pass linear scan through input elements. Key operations include bitwise operators (`&`, `|`, `^`, `<<`, `>>`) for fast bitmask state updates.

## Complexity detail
- **Time Complexity**: $O(N2^N)$ — Operation count bound.
- **Space Complexity**: $O(2^N)$ — Auxiliary memory allocation bound.
