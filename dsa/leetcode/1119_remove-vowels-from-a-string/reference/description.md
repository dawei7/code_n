## Description

Given a string `s`, create and return a new string after removing every occurrence of the lowercase vowels `a`, `e`, `i`, `o`, and `u`.

All other lowercase English letters remain in their original relative order. Deletion closes each gap; it does not insert whitespace or another marker. Consequently, an input made entirely of vowels produces the empty string, while an input containing no vowels is returned unchanged in value. The letter `y` is not in the specified vowel set and remains.
