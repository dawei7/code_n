## General
Given an elevation map represents as an integer array `heights` where $\text{heights}[i]$ representing the height of the terrain at index `i`. The width at each index is `1`. You are also given two integers `volume` and `k`..., the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(vn)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
