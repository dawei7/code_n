## General
Given an integer `n`. We reorder the digits in any order (including the original order) such that the leading digit is not zero, the algorithm solves **Reordered Power of 2** directly. Key operations include bitwise operators (`&`, `|`, `^`, `<<`, `>>`) for fast bitmask state updates.

## Complexity detail
- **Time Complexity**: $O(d)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
