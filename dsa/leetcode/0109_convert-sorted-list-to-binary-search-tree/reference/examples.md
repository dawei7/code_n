## Examples

**Example 1**

- Input: `head = [-10, -3, 0, 5, 9]`
- Output: `[0, -3, 9, -10, null, 5]`

- Explanation: One possible result is the following height-balanced binary search tree:

```text
-10 -> -3 -> 0 -> 5 -> 9

              0
             / \
           -3   9
           /   /
        -10   5
```

**Example 2**

- Input: `head = []`
- Output: `[]`
