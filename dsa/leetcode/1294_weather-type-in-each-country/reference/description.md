## Description

Determine the weather type for every country that has recorded weather during November 2019. For each such country, use only that month's rows to calculate its average `weather_state`.

Classify an average of at most $15$ as `Cold`, an average of at least $25$ as `Hot`, and every average strictly between those boundaries as `Warm`.

Return each qualifying `country_name` together with its `weather_type`. The rows may appear in any order.
