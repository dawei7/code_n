## General
Given an array `time` where $\text{time}[i]$ denotes the time taken by the $$i^{\text{th}}$$ bus to complete **one trip**, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n log U)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
