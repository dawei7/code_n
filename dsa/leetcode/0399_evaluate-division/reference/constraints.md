## Constraints

- $1 \le \texttt{equations.length} \le 20$
- `equations[i].length == 2`
- $1 \le \lvert A_i\rvert,\lvert B_i\rvert \le 5$
- `values.length == equations.length`
- $0.0 < \texttt{values[i]} \le 20.0$
- $1 \le \texttt{queries.length} \le 20$
- `queries[i].length == 2`
- $1 \le \lvert C_j\rvert,\lvert D_j\rvert \le 5$
- $A_i$, $B_i$, $C_j$, and $D_j$ contain lowercase English letters and digits.
