## General
Given an integer array `nums` of **even** length. You have to split the array into two parts `nums1` and `nums2` such that:, the algorithm solves **Split the Array** directly. It utilizes a hash map (`dict`) to store element values and their indices/frequencies for $O(1)$ fast access.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
