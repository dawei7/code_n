## Examples

**Example 1**

- Input: `nums = [1,2,3,1,2]`
- Output: `4`
- Explanation:

  Replacing `nums[3] = 1` with `3` changes the array to `[1,2,3,3,2]`.

  Its longest non-decreasing subarray is `[1,2,3,3]`, whose length is `4`.

**Example 2**

- Input: `nums = [2,2,2,2,2]`
- Output: `5`
- Explanation: All values in `nums` are equal, so the array is already non-decreasing. The entire array is a subarray of length `5`, and no replacement is needed.
