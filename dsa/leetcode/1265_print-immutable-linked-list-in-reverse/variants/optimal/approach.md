## General
Given an immutable linked list, print out all values of each node in reverse with the help of the following interface:, the algorithm solves **Print Immutable Linked List in Reverse** directly. It utilizes linked list node pointers (`val`, `next`) to process sequential node chains.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
