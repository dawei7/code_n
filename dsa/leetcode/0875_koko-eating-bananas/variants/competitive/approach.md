## General
Given Koko loves to eat bananas. There are `n` piles of bananas, the $$i^{\text{th}}$$ pile has $\text{piles}[i]$ bananas. The guards have gone and will come back in `h` hours, the algorithm executes binary search over the search space to achieve logarithmic reduction. It utilizes a hash map (`dict`) to store element values and their indices/frequencies for $O(1)$ fast access.

## Complexity detail
- **Time Complexity**: $O(n\log M)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
