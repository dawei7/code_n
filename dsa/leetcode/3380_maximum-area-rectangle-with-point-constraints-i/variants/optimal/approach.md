## General
Given an array `points` where $\text{points}[i] = [x_{i}, y_{i}]$ represents the coordinates of a point on an infinite plane, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n^3)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
