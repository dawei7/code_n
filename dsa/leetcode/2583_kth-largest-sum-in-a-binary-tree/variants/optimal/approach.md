## General
Uses two-pointer iteration. Maintains double-ended queue (`deque`) for $O(1)$ operations, tree traversal nodes (`val`, `left`, `right`).

## Complexity detail
- **Time Complexity**: $O(n log k)$ — Operation count bound.
- **Space Complexity**: $O(n + k)$ — Auxiliary memory allocation bound.
