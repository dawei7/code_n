## Description

You are given the roots `root1` and `root2` of two binary search trees, together with an integer `target`.

A valid pair must use one node from the first tree and one node from the second tree. A pair drawn entirely from one tree does not qualify, even when its values sum to `target`. Return `true` if and only if some cross-tree pair has values whose sum equals `target`; otherwise, return `false`.
