## General
Given On a **single-threaded** CPU, we execute a program containing `n` functions. Each function has a unique ID between 0 and $n - 1$, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(L)$ — Operation count bound.
- **Space Complexity**: $O(n + D)$ — Auxiliary memory allocation bound.
