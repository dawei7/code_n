## Examples

**Example 1**

- Input: `s = "abccccdd"`
- Output: `7`
- Explanation: One maximum-length construction is `"dccaccd"`, which is a palindrome of length $7$ formed from
  the available letters.

**Example 2**

- Input: `s = "a"`
- Output: `1`
- Explanation: The single character `"a"` is itself the longest palindrome that can be built.
