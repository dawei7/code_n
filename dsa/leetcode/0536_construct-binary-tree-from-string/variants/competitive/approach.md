## General
Given You need to construct a binary tree from a string consisting of parenthesis and integers, the algorithm solves **Construct Binary Tree from String** directly. It utilizes binary tree node references (`val`, `left`, `right`) to traverse structural hierarchies.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(h)$ — Auxiliary memory allocation bound.
