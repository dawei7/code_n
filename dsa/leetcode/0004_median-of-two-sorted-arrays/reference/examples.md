## Examples

**Example 1**

- Input: `nums1 = [1, 3], nums2 = [2]`
- Output: `2.00000`
- Explanation: In sorted order the combined values are `[1, 2, 3]`, whose middle value is 2.

**Example 2**

- Input: `nums1 = [1, 2], nums2 = [3, 4]`
- Output: `2.50000`
- Explanation: The combined sorted values are `[1, 2, 3, 4]`; averaging the two middle values gives $(2+3)/2 = 2.5$.
