## Description

An alien language uses the English alphabet, but its letter order is unknown.

The array `words` contains entries from an alien-language dictionary. The supplied order is claimed to be lexicographically sorted according to that language's rules.

If no possible ordering of the letters could make the claim valid, return `""`.

Otherwise, return a string containing every distinct letter that appears in the alien language, arranged in lexicographically increasing order under its rules. When more than one valid ordering exists, any one of them is acceptable.
