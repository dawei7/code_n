## Examples

**Example 1**

- Input: `words = ["wrt","wrf","er","ett","rftt"]`
- Output: `"wertf"`

**Example 2**

- Input: `words = ["z","x"]`
- Output: `"zx"`

**Example 3**

- Input: `words = ["z","x","z"]`
- Output: `""`
- Explanation: These words imply an invalid letter order, so the result is the empty string.
