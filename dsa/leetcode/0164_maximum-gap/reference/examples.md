## Examples

**Example 1**

- Input: `nums = [3, 6, 9, 1]`
- Output: `3`
- Explanation: The sorted array is `[1, 3, 6, 9]`. Both successive pairs `(3, 6)` and `(6, 9)` have the maximum difference, `3`.

**Example 2**

- Input: `nums = [10]`
- Output: `0`
- Explanation: The array has fewer than two elements, so the result is `0`.
