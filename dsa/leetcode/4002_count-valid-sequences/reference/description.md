## Description

You are given two positive integers, `n` and `k`. Count the ordered sequences that contain exactly `k` positive integers, have total sum `n`, and have an even product.

Order is significant: two sequences are different whenever at least one position contains a different value, even if they contain the same multiset of integers. For example, `[1,1,2]` and `[1,2,1]` are distinct.

Return the number of valid sequences modulo $10^9+7$.
