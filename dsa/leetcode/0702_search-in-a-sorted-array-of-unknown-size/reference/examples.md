## Examples

**Example 1**

- Input: `secret = [-1,0,3,5,9,12], target = 9`
- Output: `4`
- Explanation: The value `9` occurs in `secret` at index `4`.

**Example 2**

- Input: `secret = [-1,0,3,5,9,12], target = 2`
- Output: `-1`
- Explanation: The value `2` does not occur in `secret`, so the result is `-1`.
