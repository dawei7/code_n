## Examples

**Example 1**

- Input: `nums = [12,54,32,22], digit = 2`
- Output: `4`
- Explanation: The digit $2$ occurs once in `12`, once in `32`, and twice in `22`. It does not occur in `54`, so the combined count is $1+1+2=4$.

**Example 2**

- Input: `nums = [1,34,7], digit = 9`
- Output: `0`
- Explanation: None of the decimal representations `1`, `34`, or `7` contains the digit $9$, so the total is $0$.
