## Examples

**Example 1**

- Input: `costs = [[1,5,3],[2,9,4]]`
- Output: `5`
- Explanation: One optimal plan uses color `0` for house `0` and color `2` for house `1`, costing `1 + 4 = 5`. Another uses color `2` for house `0` and color `0` for house `1`, costing `3 + 2 = 5`.

**Example 2**

- Input: `costs = [[1,3],[2,4]]`
- Output: `5`
