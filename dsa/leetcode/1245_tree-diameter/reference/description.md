## Description

The **diameter** of a tree is the number of edges in the longest path contained in that tree.

The input describes an undirected tree with $n$ nodes labeled from $0$ through $n-1$. Each row `edges[i] = [a_i, b_i]` represents one undirected edge between nodes $a_i$ and $b_i$, and the array contains exactly $n-1$ edges.

Return the diameter of the tree.
