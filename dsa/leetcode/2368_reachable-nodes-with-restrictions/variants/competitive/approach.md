## General
Given There is an undirected tree with `n` nodes labeled from `0` to $n - 1$ and $n - 1$ edges, the algorithm executes breadth-first search (BFS) level-order traversal using a queue.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
