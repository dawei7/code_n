## Description

You are given the `root` of a binary tree in which every node has a unique value, together with a target integer `k`. Return the value of a leaf nearest to the node whose value is `k`.

Distance to a leaf is the minimum number of tree edges that must be traversed from the target to reach that leaf. A node is a leaf when it has no children. Paths may move through children or parents, and if several leaves have the same minimum distance, any one of their values is valid.
