## Examples

**Example 1**

- Input: `n = 1`
- Output: `2`
- Explanation: The range `[0, 1]` contains binary representations `"0"` and `"1"`. Each one consists of a single repeated bit, so both integers are Monobit and the count is `2`.

**Example 2**

- Input: `n = 4`
- Output: `3`
- Explanation: The integers from `0` through `4` have binary representations `"0"`, `"1"`, `"10"`, `"11"`, and `"100"`. Only decimal `0`, `1`, and `3` use one identical bit throughout their representations, giving a count of `3`.
