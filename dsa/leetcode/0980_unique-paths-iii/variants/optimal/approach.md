## General
Given an `m x n` integer array `grid` where $\text{grid}[i][j]$ could be:, the algorithm executes depth-first search (DFS) recursion to explore valid decision branches.

## Complexity detail
- **Time Complexity**: $O(V2^V)$ — Operation count bound.
- **Space Complexity**: $O(V2^V)$ — Auxiliary memory allocation bound.
