## Constraints

- $2 \le \texttt{regions.length} \le 10^4$
- $2 \le \texttt{regions[i].length} \le 20$
- $1 \le \texttt{regions[i][j].length}, \texttt{region1.length}, \texttt{region2.length} \le 20$
- `region1 != region2`
- `regions[i][j]`, `region1`, and `region2` consist of English letters.
- The input contains a region that directly or indirectly contains every other region.
- No region is directly contained in more than one region.
