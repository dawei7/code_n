## General
Given You have `n` coins and you want to build a staircase with these coins. The staircase consists of `k` rows where the $$i^{\text{th}}$$ row has exactly `i` coins. The last row of the staircase **may be** incomplete, the algorithm solves **Arranging Coins** directly.

## Complexity detail
- **Time Complexity**: $O(1)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
