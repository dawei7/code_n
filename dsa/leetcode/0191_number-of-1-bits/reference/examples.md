## Examples

**Example 1**

- Input: `n = 11`
- Output: `3`
- Explanation: Binary `1011` contains three set bits.

**Example 2**

- Input: `n = 128`
- Output: `1`
- Explanation: Binary `10000000` contains one set bit.

**Example 3**

- Input: `n = 2147483645`
- Output: `30`
- Explanation: Binary `1111111111111111111111111111101` contains thirty set bits.
