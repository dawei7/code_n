## Examples

**Example 1**

- Input: `s = "abab"`
- Output: `true`
- **Explanation:** The substring `"ab"` repeated twice produces the string.

**Example 2**

- Input: `s = "aba"`
- Output: `false`

**Example 3**

- Input: `s = "abcabcabcabc"`
- Output: `true`
- **Explanation:** Either `"abc"` repeated four times or `"abcabc"` repeated twice produces the string.
