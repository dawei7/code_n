## General
Given an integer array `cost` of size `n`. You are currently at position `n` (at the end of the line) in a line of $n + 1$ people (numbered from 0 to `n`), the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
