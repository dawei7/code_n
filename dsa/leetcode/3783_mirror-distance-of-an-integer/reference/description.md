## Description

For a positive integer `n`, let `reverse(n)` be the integer obtained by writing the decimal digits of `n` in the opposite order.

The **mirror distance** of `n` is

$$
\left\lvert n - \operatorname{reverse}(n) \right\rvert.
$$

Return this mirror distance. Here, the absolute-value operation makes the result nonnegative regardless of which of the two integers is larger.
