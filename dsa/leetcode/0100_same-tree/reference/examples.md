## Examples

**Example 1**

- Input: `p = [1, 2, 3], q = [1, 2, 3]`
- Output: `true`

```text
  1       1
 / \     / \
2   3   2   3
```

**Example 2**

- Input: `p = [1, 2], q = [1, null, 2]`
- Output: `false`

```text
  1       1
 /         \
2           2
```

**Example 3**

- Input: `p = [1, 2, 1], q = [1, 1, 2]`
- Output: `false`

```text
  1       1
 / \     / \
2   1   1   2
```
