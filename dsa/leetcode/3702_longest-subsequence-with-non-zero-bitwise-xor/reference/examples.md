## Examples

**Example 1**

- Input: `nums = [1,2,3]`
- Output: `2`
- Explanation: One longest valid subsequence is `[2, 3]`. Its XOR is `2 XOR 3 = 1`, which is non-zero.

**Example 2**

- Input: `nums = [2,3,4]`
- Output: `3`
- Explanation: The complete array is the longest possible subsequence. Its XOR is `2 XOR 3 XOR 4 = 5`, which is non-zero.
