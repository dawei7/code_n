## General
Given An `n x n` matrix is **valid** if every row and every column contains **all** the integers from `1` to `n` (**inclusive**), the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n^2)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
