## Examples

**Example 1**

- Input: `n = 4, k = 2`
- Output: `[[1, 2], [1, 3], [1, 4], [2, 3], [2, 4], [3, 4]]`
- Explanation: There are $\binom{4}{2}=6$ combinations. Order within a combination does not create a new result, so `[1, 2]` and `[2, 1]` represent the same choice.

**Example 2**

- Input: `n = 1, k = 1`
- Output: `[[1]]`
- Explanation: There is $\binom{1}{1}=1$ possible combination.
