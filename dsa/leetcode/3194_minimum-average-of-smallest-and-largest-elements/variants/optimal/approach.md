## General
Given You have an array of floating point numbers `averages` which is initially empty. You are given an array `nums` of `n` integers where `n` is even, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n log n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
