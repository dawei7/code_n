## Examples

**Example 1**

- Input: `s = "idea"`
- Output: `"id"`
- Explanation: The final characters `'e'` and `'a'` are both vowels. Removing that suffix from `"idea"` leaves `"id"`.

**Example 2**

- Input: `s = "day"`
- Output: `"day"`
- Explanation: The last character is `'y'`, which is not a vowel, so `"day"` has no trailing vowels to remove.

**Example 3**

- Input: `s = "aeiou"`
- Output: `""`
- Explanation: Every character in `"aeiou"` is a vowel and belongs to the trailing suffix. Removing all five produces the empty string.
