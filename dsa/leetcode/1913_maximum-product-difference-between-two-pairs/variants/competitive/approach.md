## General
Given The **product difference** between two pairs `(a, b)` and `(c, d)` is defined as $(a * b) - (c * d)$, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(N)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
