## General
Given an integer array `nums` of length `n` and an integer `k`, return *the *$$k^{\text{th}}$$ ***smallest subarray sum**.*, the algorithm executes a two-pointer approach to shrink boundaries or maintain a sliding window.

## Complexity detail
- **Time Complexity**: $O(N \log S)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
