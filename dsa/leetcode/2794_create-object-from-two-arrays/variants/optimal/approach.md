## General
Given two arrays `keysArr` and `valuesArr`, return a new object `obj`. Each key-value pair in `obj` should come from $\text{keysArr}[i]$ and $\text{valuesArr}[i]$, the JavaScript algorithm implements the solution for **Create Object from Two Arrays**. Edge case handling: guards against empty inputs using array/string length checks.

## Complexity detail
- **Time Complexity**: $O(n + K)$ — Operation count bound.
- **Space Complexity**: $O(n + K)$ — Auxiliary memory allocation bound.
