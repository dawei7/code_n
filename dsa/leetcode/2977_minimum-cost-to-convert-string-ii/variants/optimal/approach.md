## General
Algorithm uses depth-first search recursion. Applies bitwise operations (`&`, `|`, `^`, `<<`, `>>`) for fast bitmask state updates.

## Complexity detail
- **Time Complexity**: $O(M^3 + N^2 + S)$ — Operation count bound.
- **Space Complexity**: $O(M^2 + N + S)$ — Auxiliary memory allocation bound.
