## Description

You are given an integer array `nums` and an integer `k`.

Your task is to partition `nums` into `k`** **non-empty **<span data-keyword="subarray-nonempty">subarrays</span>**. For each subarray, compute the bitwise **XOR** of all its elements.

Return the **minimum** possible value of the **maximum XOR** among these `k` subarrays.
