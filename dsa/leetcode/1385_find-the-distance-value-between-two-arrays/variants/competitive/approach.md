## General
Given two integer arrays `arr1` and `arr2`, and the integer `d`, *return the distance value between the two arrays*, the algorithm executes binary search over the search space to achieve logarithmic reduction.

## Complexity detail
- **Time Complexity**: $O(m log m + n log m)$ — Operation count bound.
- **Space Complexity**: $O(m)$ — Auxiliary memory allocation bound.
