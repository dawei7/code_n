## Description

You are given a 1-indexed integer array `numbers` sorted in non-decreasing order. Find two entries whose sum equals `target`, at indices `index1` and `index2`, where $1 \le \texttt{index1} < \texttt{index2} \le \texttt{numbers.length}$.

Return the two 1-based indices as the length-two array `[index1, index2]`. Every test has exactly one solution, and the same element may not be used twice.

Your solution must use only constant extra space.
