## Examples

**Example 1**

- Input: `numbers = [2, 7, 11, 15], target = 9`
- Output: `[1, 2]`
- Explanation: Values `2` and `7` sum to `9`. Their 1-based indices are `1` and `2`, so the result is `[1, 2]`.

**Example 2**

- Input: `numbers = [2, 3, 4], target = 6`
- Output: `[1, 3]`
- Explanation: Values `2` and `4` sum to `6`. Their 1-based indices are `1` and `3`, so the result is `[1, 3]`.

**Example 3**

- Input: `numbers = [-1, 0], target = -1`
- Output: `[1, 2]`
- Explanation: Values `-1` and `0` sum to `-1`. Their 1-based indices are `1` and `2`, so the result is `[1, 2]`.
