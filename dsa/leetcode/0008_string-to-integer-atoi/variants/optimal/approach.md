## General
Given Implement the `myAtoi(string s)` function, which converts a string to a 32-bit signed integer, the algorithm solves **String to Integer (atoi)** directly. Edge case handling: guards against empty/null inputs via early returns.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
