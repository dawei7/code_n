## General
Given a 2D `grid` of size `m x n`, you should find the matrix `answer` of size `m x n`, the algorithm executes a single-pass linear scan through input elements. It utilizes a hash set (`set`) to track unique elements and prevent duplicate processing in $O(1)$ time.

## Complexity detail
- **Time Complexity**: $O(m*n)$ — Operation count bound.
- **Space Complexity**: $O(m*n)$ — Auxiliary memory allocation bound.
