## General
Given a **multi-dimensional array** of integers, return a generator object which yields integers in the same order as **inorder traversal**, the JavaScript algorithm implements the solution for **Nested Array Generator**. Edge case handling: guards against empty inputs using array/string length checks.

## Complexity detail
- **Time Complexity**: $O(N)$ — Operation count bound.
- **Space Complexity**: $O(d)$ — Auxiliary memory allocation bound.
