## Description

The string `s` is a compact representation of a list of words. Each position in a represented word has one or more lowercase-letter options. A position with only one option is written as that letter. When a position has multiple options, its distinct letters are separated by commas and enclosed in curly braces. The input is valid, and brace groups are never nested.

Construct every word described by `s`: retain each fixed letter and independently select exactly one letter from every brace group. Return the complete list of resulting words in lexicographical order.
