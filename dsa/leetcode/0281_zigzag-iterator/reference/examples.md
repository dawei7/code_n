## Examples

**Example 1**

- Input: `v1 = [1,2], v2 = [3,4,5,6]`
- Output: `[1,3,2,4,5,6]`
- Explanation: Calling `next()` until `hasNext()` becomes false yields the values in the order `[1,3,2,4,5,6]`.

**Example 2**

- Input: `v1 = [1], v2 = []`
- Output: `[1]`

**Example 3**

- Input: `v1 = [], v2 = [1]`
- Output: `[1]`
