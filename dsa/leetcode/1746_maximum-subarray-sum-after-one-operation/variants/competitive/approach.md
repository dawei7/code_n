## General
Given an integer array `nums`. You must perform **exactly one** operation where you can **replace** one element $\text{nums}[i]$ with $\text{nums}[i] * \text{nums}[i]$, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
