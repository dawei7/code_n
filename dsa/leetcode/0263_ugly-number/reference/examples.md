## Examples

**Example 1**

- Input: `n = 6`
- Output: `true`
- Explanation: $6 = 2 \times 3$, so every prime factor is permitted.

**Example 2**

- Input: `n = 1`
- Output: `true`
- Explanation: The number `1` has no prime factors, so it satisfies the definition.

**Example 3**

- Input: `n = 14`
- Output: `false`
- Explanation: The prime factorization of `14` includes `7`, which is outside the permitted set.
