## Examples

**Example 1**

- Input: `n = 4`
- Output: `"1211"`
- Explanation: The terms are `countAndSay(1) = "1"`, `countAndSay(2) = RLE("1") = "11"`, `countAndSay(3) = RLE("11") = "21"`, and `countAndSay(4) = RLE("21") = "1211"`.

**Example 2**

- Input: `n = 1`
- Output: `"1"`
- Explanation: This is the sequence's base case.
