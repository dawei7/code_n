## Examples

**Example 1**

- Input: `arr = [6,2,3,4]`
- Output: `[6,3,3,4]`
- Explanation: On day one, `[6,2,3,4]` becomes `[6,3,3,4]`. No operation applies after that first change, so this is the final array.

**Example 2**

- Input: `arr = [1,6,3,4,3,5]`
- Output: `[1,4,4,4,4,5]`
- Explanation: Day one changes `[1,6,3,4,3,5]` to `[1,5,4,3,4,5]`. Day two changes that array to `[1,4,4,4,4,5]`, after which no further operation applies.
