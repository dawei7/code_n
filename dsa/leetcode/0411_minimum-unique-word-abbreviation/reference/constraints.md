## Constraints

- $m = \lvert\texttt{target}\rvert$
- $n = \lvert\texttt{dictionary}\rvert$
- $1 \le m \le 21$
- $0 \le n \le 1000$
- $1 \le \lvert\texttt{dictionary[i]}\rvert \le 100$
- If $n > 0$, then $\log_2(n) + m \le 21$.
- `target` and every `dictionary[i]` contain only lowercase English letters.
- `dictionary` does not contain `target`.
