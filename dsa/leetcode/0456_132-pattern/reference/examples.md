## Examples

**Example 1**

- Input: `nums = [1,2,3,4]`
- Output: `false`
- **Explanation:** This increasing sequence contains no 132 pattern.

**Example 2**

- Input: `nums = [3,1,4,2]`
- Output: `true`
- **Explanation:** The subsequence `[1, 4, 2]` is a 132 pattern.

**Example 3**

- Input: `nums = [-1,3,2,0]`
- Output: `true`
- **Explanation:** The sequence contains three 132 patterns: `[-1, 3, 2]`, `[-1, 3, 0]`, and `[-1, 2, 0]`.
