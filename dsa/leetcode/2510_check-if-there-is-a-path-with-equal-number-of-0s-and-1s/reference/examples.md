## Examples

**Example 1**

- **Input:** `grid = [[0, 1, 0, 0], [0, 1, 0, 0], [1, 0, 1, 0]]`
- **Output:** `true`
- **Explanation:** A valid path from `(0, 0)` to `(2, 3)` visits 6 cells with three `0`s and three `1`s (e.g. `(0,0) -> (0,1) -> (0,2) -> (1,2) -> (2,2) -> (2,3)`).

**Example 2**

- **Input:** `grid = [[1, 1, 0], [0, 0, 1], [1, 0, 0]]`
- **Output:** `false`
- **Explanation:** No path from `(0, 0)` to `(2, 2)` visits equal numbers of `0`s and `1`s.
