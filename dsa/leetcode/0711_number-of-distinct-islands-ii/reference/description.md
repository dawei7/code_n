## Description

You are given an $m \times n$ binary matrix `grid`. Each `1` represents land, and an island is a group of land cells connected 4-directionally: horizontally or vertically. Water surrounds all four outside edges of the matrix.

Two islands belong to the same shape class when their occupied-cell patterns already match or can be made to match by a rotation of exactly 90, 180, or 270 degrees, or by a left/right or up/down reflection. Their positions in the matrix do not create different shapes. Return the number of distinct island shape classes.
