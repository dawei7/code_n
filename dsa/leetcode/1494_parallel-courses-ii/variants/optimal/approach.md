## General
Uses breadth-first search queue traversal. Maintains hash map (`dict`) for $O(1)$ average lookup, double-ended queue (`deque`) for $O(1)$ operations. Applies bitwise operations (`&`, `|`, `^`, `<<`, `>>`).

## Complexity detail
- **Time Complexity**: $O(N3^N)$ — Operation count bound.
- **Space Complexity**: $O(2^N + N)$ — Auxiliary memory allocation bound.
