## Description

You are given two strings, `str1` and `str2`, of lengths `n` and `m`, respectively.

A string `word` of length `n + m - 1` is defined to be **generated** by `str1` and `str2` if it satisfies the following conditions for **each** index `0 <= i <= n - 1`:

	- If `str1[i] == 'T'`, the **<span data-keyword="substring-nonempty">substring</span>** of `word` with size `m` starting at index `i` is **equal** to `str2`, i.e., `word[i..(i + m - 1)] == str2`.

	- If `str1[i] == 'F'`, the **<span data-keyword="substring-nonempty">substring</span>** of `word` with size `m` starting at index `i` is **not equal** to `str2`, i.e., `word[i..(i + m - 1)] != str2`.

Return the **<span data-keyword="lexicographically-smaller-string">lexicographically smallest</span>** possible string that can be **generated** by `str1` and `str2`. If no string can be generated, return an empty string `""`.

**Example 1:**

<div class="example-block">
**Input:** <span class="example-io">str1 = "TFTF", str2 = "ab"</span>

**Output:** <span class="example-io">"ababa"</span>

**Explanation:**

#### The table below represents the string `"ababa"`

<table>
	<tbody>
		<tr>
			<th style="border: 1px solid black;">Index</th>
			<th style="border: 1px solid black;">T/F</th>
			<th style="border: 1px solid black;">Substring of length `m`</th>
		</tr>
		<tr>
			<td style="border: 1px solid black;">0</td>
			<td style="border: 1px solid black;">`'T'`</td>
			<td style="border: 1px solid black;">"ab"</td>
		</tr>
		<tr>
			<td style="border: 1px solid black;">1</td>
			<td style="border: 1px solid black;">`'F'`</td>
			<td style="border: 1px solid black;">"ba"</td>
		</tr>
		<tr>
			<td style="border: 1px solid black;">2</td>
			<td style="border: 1px solid black;">`'T'`</td>
			<td style="border: 1px solid black;">"ab"</td>
		</tr>
		<tr>
			<td style="border: 1px solid black;">3</td>
			<td style="border: 1px solid black;">`'F'`</td>
			<td style="border: 1px solid black;">"ba"</td>
		</tr>
	</tbody>
</table>

The strings `"ababa"` and `"ababb"` can be generated by `str1` and `str2`.

Return `"ababa"` since it is the lexicographically smaller string.

</div>

**Example 2:**

<div class="example-block">
**Input:** <span class="example-io">str1 = "TFTF", str2 = "abc"</span>

**Output:** <span class="example-io">""</span>

**Explanation:**

No string that satisfies the conditions can be generated.

</div>

**Example 3:**

<div class="example-block">
**Input:** <span class="example-io">str1 = "F", str2 = "d"</span>

**Output:** <span class="example-io">"a"</span>

</div>

**Constraints:**

	- `1 <= n == str1.length <= 10^4`

	- `1 <= m == str2.length <= 500`

	- `str1` consists only of `'T'` or `'F'`.

	- `str2` consists only of lowercase English characters.
