## General
Given a **0-indexed** array of integers `nums`, and an integer `target`, the algorithm executes a single-pass linear scan through input elements. It utilizes a dynamic programming memoization table to cache intermediate subproblem states.

## Complexity detail
- **Time Complexity**: $O(n target)$ — Operation count bound.
- **Space Complexity**: $O(target)$ — Auxiliary memory allocation bound.
