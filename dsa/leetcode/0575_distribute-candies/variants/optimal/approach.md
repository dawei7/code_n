## General
Given Alice has `n` candies, where the $$i^{\text{th}}$$ candy is of type $\text{candyType}[i]$. Alice noticed that she started to gain weight, so she visited a doctor, the algorithm solves **Distribute Candies** directly. Key operations include bitwise operators (`&`, `|`, `^`, `<<`, `>>`) for fast bitmask state updates.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
