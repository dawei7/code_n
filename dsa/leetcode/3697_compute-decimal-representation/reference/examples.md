## Examples

**Example 1**

- Input: `n = 537`
- Output: `[500,30,7]`
- Explanation: The equality `537 = 500 + 30 + 7` uses three base-10 components. No representation with fewer than three such components exists.

**Example 2**

- Input: `n = 102`
- Output: `[100,2]`
- Explanation: The number decomposes as `100 + 2`. Because `102` itself is not a base-10 component, two components are necessary.

**Example 3**

- Input: `n = 6`
- Output: `[6]`
- Explanation: The number `6` already is a base-10 component, so it forms the complete one-element result.
