## Description

For this problem, a **base-10 component** is a positive integer formed by multiplying one digit from $1$ through $9$ by a non-negative power of ten. Thus `500`, `30`, and `7` qualify, whereas numbers such as `537`, `102`, and `11` do not.

Given a positive integer `n`, write it as a sum containing only base-10 components. The representation must use the smallest possible number of components.

Return those components as an array arranged in descending numerical order.
