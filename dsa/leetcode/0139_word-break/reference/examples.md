## Examples

**Example 1**

- Input: `s = "leetcode", wordDict = ["leet", "code"]`
- Output: `true`
- Explanation: Return `true` because the string can be segmented as `"leet code"`.

**Example 2**

- Input: `s = "applepenapple", wordDict = ["apple", "pen"]`
- Output: `true`
- Explanation: The valid segmentation is `"apple pen apple"`; reusing the dictionary word `"apple"` is allowed.

**Example 3**

- Input: `s = "catsandog", wordDict = ["cats", "dog", "sand", "and", "cat"]`
- Output: `false`
