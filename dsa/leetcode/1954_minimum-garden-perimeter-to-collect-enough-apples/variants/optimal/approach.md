## General
Given In a garden represented as an infinite 2D grid, there is an apple tree planted at **every** integer coordinate. The apple tree planted at an integer coordinate `(i, j)` has $|i| + |j|$ apples growing on it, the algorithm solves **Minimum Garden Perimeter to Collect Enough Apples** directly.

## Complexity detail
- **Time Complexity**: $O(\log A)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
