## General
Given There is a directed graph of `n` nodes with each node labeled from `0` to $n - 1$. The graph is represented by a **0-indexed** 2D integer array `graph` where $\text{graph}[i]$ is an integer array of nodes adjacent to ..., the algorithm executes depth-first search (DFS) recursion to explore valid decision branches. Key operations include bitwise operators (`&`, `|`, `^`, `<<`, `>>`) for fast bitmask state updates.

## Complexity detail
- **Time Complexity**: $O(V + E)$ — Operation count bound.
- **Space Complexity**: $O(V + E)$ — Auxiliary memory allocation bound.
