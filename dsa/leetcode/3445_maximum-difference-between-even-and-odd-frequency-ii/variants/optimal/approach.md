## General
Given a string `s` and an integer `k`. Your task is to find the **maximum** difference between the frequency of **two** characters, $\text{freq}[a] - \text{freq}[b]$, in a substring `subs` of `s`, such that:, the algorithm executes a single-pass linear scan through input elements. Key operations include bitwise operators (`&`, `|`, `^`, `<<`, `>>`) for fast bitmask state updates.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
