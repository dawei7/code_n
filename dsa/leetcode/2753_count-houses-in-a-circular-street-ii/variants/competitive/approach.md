## General
Given an object `street` of class `Street` that represents a **circular** street and a positive integer `k` which represents a maximum bound for the number of houses in that street (in other words, the number of houses is l..., the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(k)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
