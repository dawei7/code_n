## General
Given `row x col` `grid` representing a map where $\text{grid}[i][j] = 1$ represents land and $\text{grid}[i][j] = 0$ represents water, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(rows \cdot cols)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
