## General
Given two strings `s` and `t`, return `true` *if they are equal when both are typed into empty text editors*. `'#'` means a backspace character, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(\lvert s \rvert+\lvert t \rvert)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
