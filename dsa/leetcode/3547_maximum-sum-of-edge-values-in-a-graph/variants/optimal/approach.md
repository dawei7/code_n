## General
Given an **undirected connected** graph of `n` nodes, numbered from `0` to $n - 1$. Each node is connected to **at most** 2 other nodes, the algorithm solves **Maximum Sum of Edge Values in a Graph** directly. Edge case handling: guards against empty/null inputs via early returns.

## Complexity detail
- **Time Complexity**: $O(1)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
