## Problem Description

### Goal

You are given a 0-indexed integer array `nums` whose length is even. While values remain, remove one current minimum and one current maximum, then calculate their average. If a minimum or maximum is tied, any occurrence of that value may be removed.

Continue until the array is empty and return the number of distinct averages produced. The average of values $a$ and $b$ is $(a+b)/2$ and may therefore be fractional.

### Function Contract

**Inputs**

- `nums`: An even-length list of integers.

The array length is between $2$ and $100$, inclusive, and every value lies between $0$ and $100$.

**Return value**

- The number of different averages generated by repeatedly removing the current minimum and maximum.

### Examples

**Example 1**

- Input: `nums = [4, 1, 4, 0, 3, 5]`
- Output: `2`
- Explanation: The extreme pairs have sums `5`, `5`, and `7`, corresponding to averages `2.5`, `2.5`, and `3.5`.

**Example 2**

- Input: `nums = [1, 100]`
- Output: `1`
- Explanation: The only removed pair has average `50.5`.
