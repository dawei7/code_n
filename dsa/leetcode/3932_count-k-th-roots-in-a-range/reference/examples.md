## Examples

**Example 1**

- Input: `l = 1, r = 9, k = 3`
- Output: `2`
- Explanation: The perfect cubes in `[1, 9]` are $1=1^3$ and $8=2^3$. These are the only two qualifying values, so the answer is `2`.

**Example 2**

- Input: `l = 8, r = 30, k = 2`
- Output: `3`
- Explanation: The perfect squares in `[8, 30]` are $9=3^2$, $16=4^2$, and $25=5^2$. Therefore the range contains three qualifying values.
