### 1. Description

Given a string `s`, return *the string after replacing every uppercase letter with the same lowercase letter*.

### 2. Function Contract

**Inputs**

- `s`: Input parameter (`str`).

**Return value**

- Returns `str`.

### 3. Examples

#### Example 1

- **Input:** `s = "Hello"`
- **Output:** `"hello"`

#### Example 2

- **Input:** `s = "here"`
- **Output:** `"here"`

#### Example 3

- **Input:** `s = "LOVELY"`
- **Output:** `"lovely"`

### 4. Constraints

- $1 \le \text{s.length} \le 100$

- `s` consists of printable ASCII characters.
