## General
Given an `m x n` matrix `matrix` and an integer `k`, return *the max sum of a rectangle in the matrix such that its sum is no larger than* `k`, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(s^2 l \log l)$ — Operation count bound.
- **Space Complexity**: $O(l)$ — Auxiliary memory allocation bound.
