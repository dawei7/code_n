## General
Given a callable function `f(x, y)` **with a hidden formula** and a value `z`, reverse engineer the formula and return *all positive integer pairs *`x`* and *`y`* where *$f(x,y) = z$. You may return the pairs in any order, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(z)$ — Operation count bound.
- **Space Complexity**: $O(r)$ — Auxiliary memory allocation bound.
