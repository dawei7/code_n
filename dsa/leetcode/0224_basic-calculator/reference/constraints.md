## Constraints

- $1 \le \texttt{s.length} \le 3 \times 10^5$
- `s` contains digits, `'+'`, `'-'`, `'('`, `')'`, and spaces.
- `s` represents a valid expression.
- `'+'` is never unary, so `"+1"` and `"+(2 + 3)"` are invalid.
- `'-'` may be unary, so `"-1"` and `"-(2 + 3)"` are valid.
- The input never contains two consecutive operators.
- Every number and intermediate calculation fits in a signed 32-bit integer.
