## Description

Given an integer array `nums` sorted in non-decreasing order, remove duplicates in place until every distinct value occurs at most twice. Preserve the relative order of all retained elements.

Because some languages cannot resize the array, place the retained result in its first `k` positions. After the operation, `nums[0]` through `nums[k - 1]` must contain the final sequence; values at later positions do not matter.

Return `k`. Do not allocate another array: modify `nums` in place using $O(1)$ extra memory.
