## Examples

**Example 1**

- Input: `root = [1, 2, 3]`
- Output: `6`
- Explanation: The best path is `2 -> 1 -> 3`, whose values sum to `2 + 1 + 3 = 6`.

```text
    [1]
    / \
  [2] [3]
```

**Example 2**

- Input: `root = [-10, 9, 20, null, null, 15, 7]`
- Output: `42`
- Explanation: The best path is `15 -> 20 -> 7`, with sum `15 + 20 + 7 = 42`.

```text
       -10
       / \
      9  [20]
         / \
       [15] [7]
```
