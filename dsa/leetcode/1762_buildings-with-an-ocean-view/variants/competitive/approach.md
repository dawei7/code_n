## General
Given There are `n` buildings in a line. You are given an integer array `heights` of size `n` that represents the heights of the buildings in the line, the algorithm executes a single-pass linear scan through input elements. Edge case handling: guards against empty/null inputs via early returns.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
