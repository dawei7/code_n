## Description

Given a positive-integer array `nums` and a decimal digit `x`, examine every nonempty contiguous subarray `nums[l..r]`. Add its elements and write the positive sum in ordinary decimal notation. The subarray is valid when the first digit of that sum equals `x` and its last digit also equals `x`.

Return the total number of valid index intervals. The digit conditions apply to the subarray **sum**, not to the first and last array elements. Intervals are counted independently, so overlapping subarrays and distinct intervals having the same sum each contribute separately.
