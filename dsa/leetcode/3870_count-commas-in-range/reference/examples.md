## Examples

**Example 1**

- Input: `n = 1002`
- Output: `3`

- **Explanation:** The values `1000`, `1001`, and `1002` are written as `"1,000"`, `"1,001"`, and `"1,002"`. Each contributes one comma, while every earlier value contributes none, so the total is `3`.

**Example 2**

- Input: `n = 998`
- Output: `0`

- **Explanation:** Every integer from `1` through `998` has at most three digits. None of their standard representations contains a comma.
