## General
Given an integer `n` (in base `10`) and a base `k`, return *the **sum** of the digits of *`n`* **after** converting *`n`* from base *`10`* to base *`k`, the algorithm solves **Sum of Digits in Base K** directly.

## Complexity detail
- **Time Complexity**: $O(\log_k n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
