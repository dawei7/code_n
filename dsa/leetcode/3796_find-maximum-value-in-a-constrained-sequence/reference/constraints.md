## Constraints

- $2 \leq \texttt{n} \leq 10^5$
- $1 \leq \lvert\texttt{restrictions}\rvert \leq \texttt{n}-1$
- `restrictions[i].length == 2`
- `restrictions[i] = [idx, maxVal]`
- $1 \leq \texttt{idx} < \texttt{n}$
- $1 \leq \texttt{maxVal} \leq 10^6$
- `diff.length == n - 1`
- $1 \leq \texttt{diff[i]} \leq 10$
- All `idx` values in `restrictions` are unique.
