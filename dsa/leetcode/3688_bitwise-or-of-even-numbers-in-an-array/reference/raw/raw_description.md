## Description

You are given an integer array `nums`.

Return the bitwise **OR** of all **even** numbers in the array.

If there are no even numbers in `nums`, return 0.

**Example 1:**

<div class="example-block">
**Input:** <span class="example-io">nums = [1,2,3,4,5,6]</span>

**Output:** <span class="example-io">6</span>

**Explanation:**

The even numbers are 2, 4, and 6. Their bitwise OR equals 6.

</div>

**Example 2:**

<div class="example-block">
**Input:** <span class="example-io">nums = [7,9,11]</span>

**Output:** <span class="example-io">0</span>

**Explanation:**

There are no even numbers, so the result is 0.

</div>

**Example 3:**

<div class="example-block">
**Input:** <span class="example-io">nums = [1,8,16]</span>

**Output:** <span class="example-io">24</span>

**Explanation:**

The even numbers are 8 and 16. Their bitwise OR equals 24.

</div>

**Constraints:**

	- `1 <= nums.length <= 100`

	- `1 <= nums[i] <= 100`
