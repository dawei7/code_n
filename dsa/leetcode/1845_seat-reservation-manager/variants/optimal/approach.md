## General
Given Design a system that manages the reservation state of `n` seats that are numbered from `1` to `n`, the algorithm solves **Seat Reservation Manager** directly. It utilizes a priority queue (`heapq`) to maintain dynamic minimum/maximum element ordering.

## Complexity detail
- **Time Complexity**: $O(q\log n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
