## General
Given Your friend is typing his `name` into a keyboard. Sometimes, when typing a character `c`, the key might get *long pressed*, and the character will be typed 1 or more times, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(m+t)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
