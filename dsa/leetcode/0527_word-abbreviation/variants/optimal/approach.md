## General

**Partition exactly the words that can collide**

Equal abbreviations must have the same original length, first character, and last character: equality fixes the
letter prefix, decimal omitted count, and final character. Group words by that three-part signature. Abbreviations
from different groups therefore cannot match.

**Count shared prefixes in one trie per group**

Insert every word into its group's trie. Incrementing `count` on each traversed node records how many words share the
prefix represented by that node. Across all groups, construction visits each input character once.

**Stop at the first unique prefix**

For each word, traverse its trie path until the first node whose count is one. Every shorter prefix is shared by
another word in the same collision group, while this prefix distinguishes the word. A singleton group therefore
needs only its first character. This one traversal is equivalent to the source's repeated simultaneous prefix
extension without rebuilding abbreviations after every round.

For a retained prefix of length `prefix_length`, the omitted middle contains
`len(word) - prefix_length - 1` characters. The abbreviation is shorter only when this value exceeds one; otherwise
the code returns the original word. Original words contain no digits, so an unchanged word cannot collide with a
genuine counted abbreviation. Trie uniqueness handles collisions within a group, and the signature handles all
cross-group comparisons, proving the complete output is unique and minimal.

## Complexity detail

Let

$$
S = \sum_{w \in \texttt{words}} \lvert w \rvert.
$$

Signature grouping, trie insertion, prefix lookup, abbreviation construction, and output copying take $O(S)$ total
time. The group roots, trie nodes, and returned strings use $O(S)$ space.

## Alternatives and edge cases

- **Sort each signature group:** only adjacent sorted words are needed to determine maximum common-prefix lengths,
  but sorting adds comparison cost and more bookkeeping.
- **Compare every pair in a group:** directly derives each required prefix but can take quadratic work in the number
  of mutually conflicting words.
- **Repeatedly rebuild colliding abbreviations:** follows the source procedure literally but may revisit the same
  prefixes over many rounds.
- **Words of length three or less:** cannot become shorter under this format and remain unchanged.
- **Long common prefix:** may force the original word when no abbreviation saves at least one character.
- **Different lengths or endpoints:** cannot collide and belong to separate trie groups.
- **Input order:** grouping may change internal processing order, but answers are generated by a second pass over the
  original list.
