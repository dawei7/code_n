## Examples

**Example 1**

- Input: `s = "I"`
- Output: `[1,2]`
- **Explanation:** The two values form the required increasing relationship, and this is the only permutation that
  represents the pattern.

**Example 2**

- Input: `s = "DI"`
- Output: `[2,1,3]`
- **Explanation:** Both `[2,1,3]` and `[3,1,2]` have a decrease followed by an increase. The displayed output is
  returned because it is lexicographically smaller.
