## General
Given an integer `n`, return *the number of ways you can write *`n`* as the sum of consecutive positive integers.*, the algorithm solves **Consecutive Numbers Sum** directly. Key operations include bitwise operators (`&`, `|`, `^`, `<<`, `>>`) for fast bitmask state updates. Edge case handling: applies modulo arithmetic to prevent integer overflow.

## Complexity detail
- **Time Complexity**: $O(\sqrt{n})$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
