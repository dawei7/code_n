## Examples

**Example 1**

- Input: `s = "egg", t = "add"`
- Output: `true`
- Explanation: The strings become identical by mapping `'e'` to `'a'` and `'g'` to `'d'`.

**Example 2**

- Input: `s = "f11", t = "b23"`
- Output: `false`
- Explanation: The repeated source character `'1'` would have to map to both `'2'` and `'3'`, so no consistent mapping exists.

**Example 3**

- Input: `s = "paper", t = "title"`
- Output: `true`
