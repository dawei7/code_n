## Examples

**Example 1**

- Input: `arr = [5,7,11,13]`
- Output: `9`
- Explanation: Before the removal, the array was `[5,7,9,11,13]`.

**Example 2**

- Input: `arr = [15,13,12]`
- Output: `14`
- Explanation: Before the removal, the array was `[15,14,13,12]`.

### Additional Example

**Constant progression**

- Input: `arr = [0,0,0,0,0]`
- Output: `0`

Removing an interior zero from a constant progression leaves no visible gap, but the removed value is still zero.
