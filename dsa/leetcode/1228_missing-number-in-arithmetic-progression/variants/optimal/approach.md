## General
Given In some array `arr`, the values were in arithmetic progression: the values $arr[i + 1] - \text{arr}[i]$ are all equal for every $0 \le i < \text{arr.length} - 1$, the algorithm solves **Missing Number In Arithmetic Progression** directly.

## Complexity detail
- **Time Complexity**: $O(\log n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
