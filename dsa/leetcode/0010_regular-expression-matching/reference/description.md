## Description

Given an input string `s` and a pattern `p`, implement matching for lowercase letters together with two special pattern symbols:

- `.` matches any one character.
- `*` matches zero or more occurrences of the immediately preceding pattern element.

These are the only special operators: every lowercase letter in `p` represents that literal character, and no other regular-expression syntax is available.

Return whether the pattern matches the entire input string. A match that covers only part of `s` is insufficient.
