## Examples

**Example 1**

- Input: `intervals = [[1,2],[2,3],[3,4],[1,3]]`
- Output: `1`
- Explanation: Removing `[1,3]` leaves the other intervals non-overlapping.

**Example 2**

- Input: `intervals = [[1,2],[1,2],[1,2]]`
- Output: `2`
- Explanation: Two copies of `[1,2]` must be removed so that only one overlapping copy remains.

**Example 3**

- Input: `intervals = [[1,2],[2,3]]`
- Output: `0`
- Explanation: The two intervals are already non-overlapping because they only touch at an endpoint.
