## General
Given a function `fn`, return a new function that is identical to the original function except that it ensures `fn` is called at most once, the JavaScript algorithm implements the solution for **Allow One Function Call**. Edge case handling: guards against empty inputs using array/string length checks.

## Complexity detail
- **Time Complexity**: $O(1)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
