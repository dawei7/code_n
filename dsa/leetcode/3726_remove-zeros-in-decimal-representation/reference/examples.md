## Examples

**Example 1**

- Input: `n = 1020030`
- Output: `123`
- Explanation: In `1`<u>`0`</u>`2`<u>`00`</u>`3`<u>`0`</u>, the underlined digits are removed. The remaining digits form `123`.

**Example 2**

- Input: `n = 1`
- Output: `1`
- Explanation: The decimal representation of `1` contains no zero, so it remains unchanged.
