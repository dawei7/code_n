## General
Given a 2D integer array `intervals` where $\text{intervals}[i] = [\text{start}_{i}, \text{end}_{i}]$ represents all the integers from $\text{start}_{i}$ to $\text{end}_{i}$ inclusively, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n \log n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
