## Examples

**Example 1**

- Input: `s1 = "abcdebdde", s2 = "bde"`
- Output: `"bcde"`
- Explanation: Both `"bcde"` and `"bdde"` have the minimum qualifying length, so the earlier window `"bcde"` is returned. The shorter substring `"deb"` does not qualify because its characters do not contain `b`, `d`, and `e` in that order.

**Example 2**

- Input: `s1 = "jmeqksfrsdcmsiwvaovztaqenprpvnbstl", s2 = "u"`
- Output: `""`
