## Description

Given strings `s1` and `s2`, select a contiguous substring of `s1` in which `s2` appears as a subsequence. The matched characters of `s2` must keep their original order, although other characters may occur between them inside the selected window.

Return the shortest qualifying window. If several minimum-length windows exist, choose the one with the left-most starting index. Return the empty string when no substring of `s1` can contain all of `s2` in the required order.
