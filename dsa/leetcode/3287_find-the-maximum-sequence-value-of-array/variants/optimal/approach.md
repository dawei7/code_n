## General
Given an integer array `nums` and a **positive** integer `k`, the algorithm executes a single-pass linear scan through input elements. Key operations include bitwise operators (`&`, `|`, `^`, `<<`, `>>`) for fast bitmask state updates.

## Complexity detail
- **Time Complexity**: $O(n(kB + B^2))$ — Operation count bound.
- **Space Complexity**: $O((n + k)B)$ — Auxiliary memory allocation bound.
