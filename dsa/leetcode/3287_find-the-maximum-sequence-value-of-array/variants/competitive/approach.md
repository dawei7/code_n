## General
Uses two-pointer iteration. Maintains hash set (`set`) for $O(1)$ existence checks, dynamic programming memoization store. Applies bitwise operations (`&`, `|`, `^`, `<<`, `>>`).

## Complexity detail
- **Time Complexity**: $O(n(kB + B^2))$ — Operation count bound.
- **Space Complexity**: $O((n + k)B)$ — Auxiliary memory allocation bound.
