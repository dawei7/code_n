## General
Given the head of a linked list `head`, in which each node contains an integer value, the algorithm solves **Insert Greatest Common Divisors in Linked List** directly. It utilizes linked list node pointers (`val`, `next`) to process sequential node chains. Edge case handling: applies modulo arithmetic to prevent integer overflow.

## Complexity detail
- **Time Complexity**: $O(n \log V)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
