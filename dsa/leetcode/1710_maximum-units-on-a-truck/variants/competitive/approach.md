## General
Given You are assigned to put some amount of boxes onto **one truck**. You are given a 2D array `boxTypes`, where $\text{boxTypes}[i] = [\text{numberOfBoxes}_{i}, \text{numberOfUnitsPerBox}_{i}]$:, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(t\log t)$ — Operation count bound.
- **Space Complexity**: $O(t)$ — Auxiliary memory allocation bound.
