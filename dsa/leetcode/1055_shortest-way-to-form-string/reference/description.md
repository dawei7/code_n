## Description

A **subsequence** of a string is produced by deleting any number of its characters, possibly none, without changing the relative order of those that remain. Thus `"ace"` is a subsequence of `"abcde"`, whereas `"aec"` is not.

Given `source` and `target`, concatenate subsequences of `source` until the result equals `target`. Return the minimum number of subsequences required. If no such concatenation can form `target`, return `-1`.
