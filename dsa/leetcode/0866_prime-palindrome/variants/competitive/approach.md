## General
Given an integer n, return *the smallest **prime palindrome** greater than or equal to *`n`, the algorithm executes a single-pass linear scan through input elements. Key operations include bitwise operators (`&`, `|`, `^`, `<<`, `>>`) for fast bitmask state updates. Edge case handling: applies modulo arithmetic to prevent integer overflow.

## Complexity detail
- **Time Complexity**: $O(P\sqrt{A})$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
