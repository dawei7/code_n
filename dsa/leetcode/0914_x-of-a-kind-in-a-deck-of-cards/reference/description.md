## Description

You are given an integer array `deck` where `deck[i]` represents the number written on the `i^th` card.

Partition the cards into **one or more groups** such that:

<ul>
	<li>Each group has **exactly** `x` cards where `x > 1`, and</li>
	<li>All the cards in one group have the same integer written on them.</li>
</ul>

Return `true`* if such partition is possible, or *`false`* otherwise*.
