## General
Given an integer array `deck` where $\text{deck}[i]$ represents the number written on the $$i^{\text{th}}$$ card, the algorithm solves **X of a Kind in a Deck of Cards** directly. It utilizes a hash map (`dict`) to store element values and their indices/frequencies for $O(1)$ fast access.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
