## Description

Given an integer array `nums` and an integer `k`, split the entire array into exactly `k` non-empty subarrays.
For each possible split, consider the largest sum among its subarrays.

Return the minimum value that this largest subarray sum can have over every valid split. A subarray is a contiguous
part of the array, so each group must preserve the original order and every input element must belong to one group.
