## General
Given an integer array `nums` and an integer `k`, split `nums` into `k` non-empty subarrays such that the largest sum of any subarray is **minimized**, the algorithm executes binary search over the search space to achieve logarithmic reduction.

## Complexity detail
- **Time Complexity**: $O(n \log S)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
