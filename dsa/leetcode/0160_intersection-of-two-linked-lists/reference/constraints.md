## Constraints

- `m` is the number of nodes in `listA`.
- `n` is the number of nodes in `listB`.
- $1 \le m, n \le 3 \times 10^4$
- $1 \le \texttt{Node.val} \le 10^5$
- $0 \le \texttt{skipA} \le m$
- $0 \le \texttt{skipB} \le n$
- `intersectVal == 0` when `listA` and `listB` do not intersect.
- `intersectVal == listA[skipA] == listB[skipB]` when the lists intersect.
