## Examples

**Example 1**

- Input: `root = [1, 2, 2, 3, 4, 4, 3]`
- Output: `true`

```text
        1
      /   \
     2     2
    / \   / \
   3   4 4   3
```

**Example 2**

- Input: `root = [1, 2, 2, null, 3, null, 3]`
- Output: `false`

```text
        1
      /   \
     2     2
      \     \
       3     3
```
