## General
Given There are `n` employees in a company, numbered from `0` to $n - 1$. Each employee `i` has worked for $\text{hours}[i]$ hours in the company, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
