## Description

You are given an integer array `nums`.

Consider every nonempty contiguous subarray of `nums`. A subarray is **centered** when the sum of all its elements is equal to at least one element contained in that same subarray. The matching element may occur at any position between the subarray's endpoints; one occurrence is sufficient.

Count every qualifying choice of left and right endpoints, and return the total number of centered subarrays of `nums`.
