## Description

You are given an integer `n`.

A number is called **special** if:

<ul>
	<li>It is a **<span data-keyword="palindrome-integer">palindrome</span>**.</li>
	<li>Every digit `k` in the number appears **exactly** `k` times.</li>
</ul>

Return the **smallest** special number **strictly **greater than `n`.
