## Examples

**Example 1**

- **Input:** `s = "aabbaba"`
- **Output:** `21`
- **Explanation:** The 21 distinct substrings are `"a"`, `"b"`, `"aa"`, `"ab"`, `"ba"`, `"bb"`, `"aab"`, `"abb"`, `"bab"`, `"bba"`, `"aba"`, `"aabb"`, `"abba"`, `"bbab"`, `"baba"`, `"aabba"`, `"abbab"`, `"bbaba"`, `"aabbab"`, `"abbaba"`, and `"aabbaba"`.

**Example 2**

- **Input:** `s = "abcdefg"`
- **Output:** `28`
- **Explanation:** Every substring of `s` is unique, so the total count is $\frac{7 \cdot 8}{2} = 28$.
