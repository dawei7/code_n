## General
Given There is only one character `'A'` on the screen of a notepad. You can perform one of two operations on this notepad for each step:, the algorithm solves **2 Keys Keyboard** directly. Edge case handling: applies modulo arithmetic to prevent integer overflow.

## Complexity detail
- **Time Complexity**: $O(\sqrt{N})$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
