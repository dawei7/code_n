## Examples

**Example 1**

- Input: `["NumArray","sumRange","sumRange","sumRange"], [[[-2,0,3,-5,2,-1]],[0,2],[2,5],[0,5]]`
- Output: `[null,1,-1,-3]`
- Explanation: Construct `NumArray` from `[-2,0,3,-5,2,-1]`. `sumRange(0,2)` returns `-2 + 0 + 3 = 1`; `sumRange(2,5)` returns `3 + (-5) + 2 + (-1) = -1`; and `sumRange(0,5)` returns the full-array sum `-3`.
