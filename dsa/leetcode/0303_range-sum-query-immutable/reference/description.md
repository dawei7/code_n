## Description

Given an integer array `nums`, support repeated queries that ask for the sum of all elements from index `left` through index `right`, including both endpoints, where `left <= right`.

Implement the `NumArray` class:

- `NumArray(int[] nums)` initializes the object with `nums`.
- `int sumRange(int left, int right)` returns `nums[left] + nums[left + 1] + ... + nums[right]`.
