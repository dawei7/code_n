## Description

Given a binary string `s`, call it **coherent** when neither `"011"` nor `"110"` occurs as a subsequence. A subsequence keeps the chosen characters in their original order but does not require them to be adjacent.

One operation flips any single character, changing `'0'` to `'1'` or `'1'` to `'0'`. Determine the minimum number of such flips needed to make `s` coherent.
