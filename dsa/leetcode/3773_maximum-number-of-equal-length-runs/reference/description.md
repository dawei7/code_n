## Description

You are given a string `s` containing only lowercase English letters.

A **run** is a maximal substring made from one repeated letter: it cannot be extended one position left or right while keeping that same letter. For instance, the runs of `"hello"` are `"h"`, `"e"`, `"ll"`, and `"o"`.

You may select runs only when they all have an equal length. Return the greatest number of runs that can be selected from `s` under this rule.
