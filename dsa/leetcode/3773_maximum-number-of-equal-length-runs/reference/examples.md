## Examples

**Example 1**

- Input: `s = "hello"`
- Output: `3`
- Explanation: The runs are `"h"`, `"e"`, `"ll"`, and `"o"`. Select `"h"`, `"e"`, and `"o"`; all three have length `1`.

**Example 2**

- Input: `s = "aaabaaa"`
- Output: `2`
- Explanation: The runs are `"aaa"`, `"b"`, and `"aaa"`. The two `"aaa"` runs can be selected together because both have length `3`.
