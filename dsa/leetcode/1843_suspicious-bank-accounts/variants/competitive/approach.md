## General
Executes a SQL query for **Suspicious Bank Accounts** using Common Table Expressions (CTEs), relational JOINs, window ranking functions, GROUP BY aggregations. Edge cases: filters aggregated group boundaries using `HAVING` clause.

## Complexity detail
- **Time Complexity**: $O(r\log r)$ — Operation count bound.
- **Space Complexity**: $O(r)$ — Auxiliary memory allocation bound.
