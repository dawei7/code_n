## Constraints

- `1 <= inorder.length <= 3000`
- `postorder.length == inorder.length`
- Each value in `inorder` and `postorder` is between `-3000` and `3000`, inclusive.
- Both arrays contain only unique values.
- Every value in `postorder` also occurs in `inorder`.
- `inorder` is guaranteed to be the tree's inorder traversal.
- `postorder` is guaranteed to be the tree's postorder traversal.
