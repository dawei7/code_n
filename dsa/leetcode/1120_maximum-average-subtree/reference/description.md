## Description

Given the `root` of a binary tree, consider every subtree that can be formed by choosing a node together with all of that node's descendants. The average of such a subtree is its node-value sum divided by its number of nodes.

Return the largest average among all of these rooted subtrees. A leaf is itself a valid subtree, as is the entire tree, and every internal node defines one additional candidate. The returned floating-point value is accepted when it differs from the exact answer by at most $10^{-5}$.
