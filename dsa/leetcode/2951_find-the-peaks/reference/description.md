## Description

You are given a **0-indexed** array `mountain`. Your task is to find all the **peaks** in the `mountain` array.

Return *an array that consists of *indices<!-- notionvc: c9879de8-88bd-43b0-8224-40c4bee71cd6 -->* of **peaks** in the given array in **any order**.*

**Notes:**

<ul>
	<li>A **peak** is defined as an element that is **strictly greater** than its neighboring elements.</li>
	<li>The first and last elements of the array are **not** a peak.</li>
</ul>
