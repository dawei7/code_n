## Description

You are given the `head` of a **doubly linked list**, which contains nodes that have a next pointer and a previous pointer.

Return an integer array which contains the elements of the linked list **in order**.

**Example 1:**

<div class="example-block">
**Input:** <span class="example-io">head = [1,2,3,4,3,2,1]</span>

**Output:** <span class="example-io">[1,2,3,4,3,2,1]</span>

</div>

**Example 2:**

<div class="example-block">
**Input:** <span class="example-io">head = [2,2,2,2,2]</span>

**Output:** <span class="example-io">[2,2,2,2,2]</span>

</div>

**Example 3:**

<div class="example-block">
**Input:** <span class="example-io">head = [3,2,3,2,3,2]</span>

**Output:** <span class="example-io">[3,2,3,2,3,2]</span>

</div>

**Constraints:**

	- The number of nodes in the given list is in the range `[1, 50]`.

	- `1 <= Node.val <= 50`
