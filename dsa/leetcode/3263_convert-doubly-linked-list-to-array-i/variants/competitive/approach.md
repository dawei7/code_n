## General
Given the `head` of a **doubly linked list**, which contains nodes that have a next pointer and a previous pointer, the algorithm solves **Convert Doubly Linked List to Array I** directly. It utilizes a hash map (`dict`) to store element values and their indices/frequencies for $O(1)$ fast access.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
