## General
Given an undirected connected graph with `n` nodes labeled from 0 to $n - 1$ and a 2D integer array `edges` where $\text{edges}[i] = [u_{i}, v_{i}, w_{i}]$ denotes an undirected edge between node $u_{i}$ and node $v_{i}$ wi..., the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(m log m + (n + m) alpha(n))$ — Operation count bound.
- **Space Complexity**: $O(n + m)$ — Auxiliary memory allocation bound.
