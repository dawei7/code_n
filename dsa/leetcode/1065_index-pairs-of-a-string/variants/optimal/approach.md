## General
Given a string `text` and an array of strings `words`, return *an array of all index pairs *`[i, j]`* so that the substring *`text[i...j]`* is in `words`*, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(S+NL)$ — Operation count bound.
- **Space Complexity**: $O(S)$ — Auxiliary memory allocation bound.
