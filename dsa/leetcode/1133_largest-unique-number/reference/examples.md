## Examples

**Example 1**

- **Input:** `nums = [5,7,3,9,4,9,8,3,1]`
- **Output:** `8`
- **Explanation:** Although `9` is the maximum value in the array, it is repeated. The value `8` appears exactly once and is therefore the answer.

**Example 2**

- **Input:** `nums = [9,9,8,8]`
- **Output:** `-1`
- **Explanation:** No value in the array occurs exactly once.
