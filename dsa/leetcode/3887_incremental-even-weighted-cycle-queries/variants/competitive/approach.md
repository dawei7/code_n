## General
Given a positive integer `n`, the algorithm executes a single-pass linear scan through input elements. Key operations include bitwise operators (`&`, `|`, `^`, `<<`, `>>`) for fast bitmask state updates.

## Complexity detail
- **Time Complexity**: $O((N+M) alpha(N))$ — Operation count bound.
- **Space Complexity**: $O(N)$ — Auxiliary memory allocation bound.
