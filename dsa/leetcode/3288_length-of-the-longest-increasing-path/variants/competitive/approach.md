## General
Given a 2D array of integers `coordinates` of length `n` and an integer `k`, where $0 \le k < n$, the algorithm executes binary search over the search space to achieve logarithmic reduction.

## Complexity detail
- **Time Complexity**: $O(n log n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
