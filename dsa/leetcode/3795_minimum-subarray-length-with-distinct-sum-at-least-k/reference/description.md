## Description

You are given an integer array `nums` and an integer `k`.

For any nonempty contiguous subarray, form the set of values that appear in it. Its **distinct-value sum** is the sum of that set: every different value contributes once, regardless of how many times it occurs inside the subarray.

Find the minimum length among all subarrays whose distinct-value sum is at least `k`. Return that length, or return `-1` when no qualifying subarray exists.
