## General
Given the `head` of a linked list containing unique integer values and an integer array `nums` that is a subset of the linked list values, the algorithm solves **Linked List Components** directly. It utilizes linked list node pointers (`val`, `next`) to process sequential node chains.

## Complexity detail
- **Time Complexity**: $O(n + m)$ — Operation count bound.
- **Space Complexity**: $O(m)$ — Auxiliary memory allocation bound.
