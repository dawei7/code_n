## Examples

**Example 1**

- Input: `k = 3`
- Output: `3`
- Explanation:
  - The number is `n = 111`: it is divisible by `3`, while `1` and `11` are not.
  - Since `111` contains three digits, return `3`.

**Example 2**

- Input: `k = 7`
- Output: `6`
- Explanation:
  - The smallest valid number is `n = 111111`.
  - Its decimal representation contains six digits, so return `6`.

**Example 3**

- Input: `k = 2`
- Output: `-1`
- Explanation:
  - Every all-ones number is odd, so none can be a multiple of `2`.
