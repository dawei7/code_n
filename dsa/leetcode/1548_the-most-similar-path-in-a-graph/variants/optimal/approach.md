## General
Given We have `n` cities and `m` bi-directional `roads` where $\text{roads}[i] = [a_{i}, b_{i}]$ connects city $a_{i}$ with city $b_{i}$. Each city has a name consisting of exactly three upper-case English letters given in ..., the algorithm executes a single-pass linear scan through input elements. Key operations include the walrus operator (`:=`) for inline assignment and evaluation.

## Complexity detail
- **Time Complexity**: $O(m(n+e))$ — Operation count bound.
- **Space Complexity**: $O(mn+n+e)$ — Auxiliary memory allocation bound.
