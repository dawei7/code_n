## Examples

**Example 1**

- **Input:** `n = 153`
- **Output:** `true`
- **Explanation:** The number `153` has three digits, and $1^3 + 5^3 + 3^3 = 153$.

**Example 2**

- **Input:** `n = 123`
- **Output:** `false`
- **Explanation:** The number `123` has three digits, but $1^3 + 2^3 + 3^3 = 36 \ne 123$.
