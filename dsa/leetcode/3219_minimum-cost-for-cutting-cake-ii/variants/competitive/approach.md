## General
Given There is an `m x n` cake that needs to be cut into `1 x 1` pieces, the algorithm solves **Minimum Cost for Cutting Cake II** directly. Edge case handling: guards against empty/null inputs via early returns.

## Complexity detail
- **Time Complexity**: $O(m log m + n log n)$ — Operation count bound.
- **Space Complexity**: $O(m + n)$ — Auxiliary memory allocation bound.
