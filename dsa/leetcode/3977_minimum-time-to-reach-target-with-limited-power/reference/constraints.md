## Constraints

- $1 \le n \le 1000$
- $0 \le \texttt{edges.length} \le 1000$
- Every edge has the form `edges[i] = [u_i, v_i, t_i]`.
- $0 \le u_i, v_i \le n - 1$
- $1 \le t_i \le 10^9$
- $1 \le \texttt{power} \le 1000$
- `cost.length == n`
- $1 \le \texttt{cost[i]} \le 2000$
- $0 \le \texttt{source}, \texttt{target} \le n - 1$
