## Examples

**Example 1**

- Input: `candidates = [2, 3, 6, 7], target = 7`
- Output: `[[2, 2, 3], [7]]`
- Explanation: Candidates `2` and `3` form `2 + 2 + 3 = 7`, with `2` reused. Candidate `7` also reaches the target by itself. No other unique combination works.

**Example 2**

- Input: `candidates = [2, 3, 5], target = 8`
- Output: `[[2, 2, 2, 2], [2, 3, 3], [3, 5]]`

**Example 3**

- Input: `candidates = [2], target = 1`
- Output: `[]`
