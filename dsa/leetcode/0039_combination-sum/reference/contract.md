## Function Contract

**Inputs**

- `candidates`: An array of distinct positive integers available for selection.
- `target`: The required sum.

Let $n = \lvert\texttt{candidates}\rvert$, $m = \min(\texttt{candidates})$, and $T = \texttt{target}$.

**Return value**

Return all unique target-sum combinations in any order. Values inside a combination may repeat because each candidate can be reused without limit.
