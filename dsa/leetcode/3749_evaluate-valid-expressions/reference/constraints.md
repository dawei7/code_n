## Constraints

- $1 \leq \texttt{expression.length} \leq 10^5$
- `expression` is valid and contains only digits, commas, parentheses, the minus sign `'-'`, and the lowercase operation names `"add"`, `"sub"`, `"mul"`, and `"div"`.
- Every intermediate result fits within the range of a signed long integer.
- Every division produces an integer result.
