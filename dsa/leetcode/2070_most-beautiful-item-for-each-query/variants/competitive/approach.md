## General
Given a 2D integer array `items` where $\text{items}[i] = [\text{price}_{i}, \text{beauty}_{i}]$ denotes the **price** and **beauty** of an item respectively, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n\log n+q\log n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
