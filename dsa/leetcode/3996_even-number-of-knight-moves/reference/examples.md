## Examples

**Example 1**

- Input: `start = [1,1], target = [2,2]`
- Output: `true`
- **Explanation:** One possible route is `(1,1) -> (3,2) -> (2,4) -> (4,3) -> (2,2)`. It reaches the target in four moves, and four is even.

**Example 2**

- Input: `start = [4,5], target = [6,6]`
- Output: `false`
- **Explanation:** No route from `[4,5]` to `[6,6]` can use an even number of knight moves.
