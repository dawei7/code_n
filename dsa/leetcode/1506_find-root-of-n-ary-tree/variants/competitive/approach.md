## General
Given all the nodes of an **<a href="https://leetcode.com/explore/learn/card/n-ary-tree/">N-ary tree</a>** as an array of `Node` objects, where each node has a **unique value**, the algorithm executes a single-pass linear scan through input elements. Key operations include bitwise operators (`&`, `|`, `^`, `<<`, `>>`) for fast bitmask state updates.

## Complexity detail
- **Time Complexity**: $O(N)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
