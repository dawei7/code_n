## Examples

**Example 1**

- Input: `num = "1432219", k = 3`
- Output: `"1219"`
- Explanation: Removing the digits `4`, `3`, and one `2` produces `1219`, the smallest possible result.

**Example 2**

- Input: `num = "10200", k = 1`
- Output: `"200"`
- Explanation: Removing the initial `1` leaves `0200`, which is returned without leading zeroes as `"200"`.

**Example 3**

- Input: `num = "10", k = 2`
- Output: `"0"`
- Explanation: Removing both digits leaves no digits, which is represented as zero.
