## Description

A **trie**, pronounced "try" and also called a **prefix tree**, is a tree-shaped data structure for efficiently storing and retrieving string keys. Autocomplete and spellchecking are two common applications.

Implement the `Trie` class with these operations:

- `Trie()` creates an empty trie.
- `insert(word)` stores `word` in the trie.
- `search(word)` returns `true` if that complete word was inserted previously and `false` otherwise.
- `startsWith(prefix)` returns `true` if any previously inserted word begins with `prefix` and `false` otherwise.
