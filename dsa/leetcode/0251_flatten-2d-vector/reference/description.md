## Description

Design an iterator that traverses a two-dimensional vector as one row-major sequence. It must support `next` and `hasNext`.

Implement the `Vector2D` class with these operations:

- `Vector2D(int[][] vec)` initializes the iterator with `vec`.
- `next()` returns the next value and advances the iterator by one element. Every call to `next` is guaranteed to be valid.
- `hasNext()` returns `true` while at least one element remains and `false` after traversal is complete.
