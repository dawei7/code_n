## General
Given an integer `numberOfUsers` representing the total number of users and an array `events` of size `n x 3`, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(E log E + E log U + M + U)$ — Operation count bound.
- **Space Complexity**: $O(E + U)$ — Auxiliary memory allocation bound.
