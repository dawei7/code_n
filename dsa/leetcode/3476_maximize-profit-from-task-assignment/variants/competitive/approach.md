## General
Given an integer array `workers`, where $\text{workers}[i]$ represents the skill level of the $$i^{\text{th}}$$ worker. You are also given a 2D integer array `tasks`, where:, the algorithm executes a single-pass linear scan through input elements. It utilizes a hash map (`dict`) to store element values and their indices/frequencies for $O(1)$ fast access.

## Complexity detail
- **Time Complexity**: $O(w + t + a log t)$ — Operation count bound.
- **Space Complexity**: $O(w + t)$ — Auxiliary memory allocation bound.
