## Description

You are given an integer array `workers`, where `workers[i]` represents the skill level of the `i^th` worker. You are also given a 2D integer array `tasks`, where `tasks[j] = [skill_j, profit_j]` represents the required skill level and profit of the `j^th` task.

Each worker can be assigned **at most one** task, and a worker with skill level `s` can only perform a task with required skill level `skill_j <= s`. Multiple workers can be assigned to the **same** task.

Return the **maximum** total profit that can be obtained.
