## General
Given The **distance of a pair** of integers `a` and `b` is defined as the absolute difference between `a` and `b`, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n \log n + n \log W)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
