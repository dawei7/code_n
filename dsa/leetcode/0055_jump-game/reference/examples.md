## Examples

**Example 1**

- Input: `nums = [2, 3, 1, 1, 4]`
- Output: `true`
- Explanation: Jump one position from index `0` to index `1`, then jump three positions to the final index.

**Example 2**

- Input: `nums = [3, 2, 1, 0, 4]`
- Output: `false`
- Explanation: Every possible route becomes stuck at index `3`, whose maximum jump length is `0`, so the last index cannot be reached.
