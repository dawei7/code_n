## Examples

**Example 1**

- Input: `nums = [0,1,2,4,5,7]`
- Output: `["0->2","4->5","7"]`
- Explanation: The ranges are `[0,2]`, written `"0->2"`; `[4,5]`, written `"4->5"`; and `[7,7]`, written `"7"`.

**Example 2**

- Input: `nums = [0,2,3,4,6,8,9]`
- Output: `["0","2->4","6","8->9"]`
- Explanation: The ranges are `[0,0] -> "0"`, `[2,4] -> "2->4"`, `[6,6] -> "6"`, and `[8,9] -> "8->9"`.
