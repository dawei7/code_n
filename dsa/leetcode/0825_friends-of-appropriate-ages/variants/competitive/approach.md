## General
Given There are `n` persons on a social media website. You are given an integer array `ages` where $\text{ages}[i]$ is the age of the $$i^{\text{th}}$$ person, the algorithm executes a single-pass linear scan through input elements. It utilizes a hash map (`dict`) to store element values and their indices/frequencies for $O(1)$ fast access. Key operations include bitwise operators (`&`, `|`, `^`, `<<`, `>>`) for fast bitmask state updates.

## Complexity detail
- **Time Complexity**: $O(n + A)$ — Operation count bound.
- **Space Complexity**: $O(A)$ — Auxiliary memory allocation bound.
