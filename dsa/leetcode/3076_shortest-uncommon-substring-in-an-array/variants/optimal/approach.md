## General
Given an array `arr` of size `n` consisting of **non-empty** strings, the algorithm executes a single-pass linear scan through input elements. Edge case handling: guards against empty/null inputs via early returns.

## Complexity detail
- **Time Complexity**: $O(n L^3)$ — Operation count bound.
- **Space Complexity**: $O(n L^3)$ — Auxiliary memory allocation bound.
