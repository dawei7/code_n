## General
Given an array `people` where $\text{people}[i]$ is the weight of the $$i^{\text{th}}$$ person, and an **infinite number of boats** where each boat can carry a maximum weight of `limit`. Each boat carries at most two people..., the algorithm solves **Boats to Save People** directly.

## Complexity detail
- **Time Complexity**: $O(n\log n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
