## General
Given a 2D integer array `nums` where $\text{nums}[i]$ is a non-empty array of **distinct** positive integers, return *the list of integers that are present in **each array** of* `nums`* sorted in **ascending order***, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(T + r log r)$ — Operation count bound.
- **Space Complexity**: $O(T)$ — Auxiliary memory allocation bound.
