## General
Given You have an infinite number of stacks arranged in a row and numbered (left to right) from `0`, each of the stacks has the same maximum capacity, the algorithm solves **Dinner Plate Stacks** directly. Edge case handling: guards against empty/null inputs via early returns.

## Complexity detail
- **Time Complexity**: $O(m\log s)$ — Operation count bound.
- **Space Complexity**: $O(v+s)$ — Auxiliary memory allocation bound.
