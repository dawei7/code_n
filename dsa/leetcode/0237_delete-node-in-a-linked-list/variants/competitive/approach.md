## General
Given There is a singly-linked list `head` and we want to delete a node `node` in it, the algorithm solves **Delete Node in a Linked List** directly. It utilizes linked list node pointers (`val`, `next`) to process sequential node chains.

## Complexity detail
- **Time Complexity**: $O(1)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
