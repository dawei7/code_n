## Constraints

- $1 \le n \le 10^5$
- `edges.length == n - 1`
- `edges[i] == [u_i, v_i]`
- $0 \le u_i,v_i \le n-1$
- $u_i \ne v_i$
- `edges` represents a valid tree rooted at task `0`, with every pair directed from parent to child.
- `baseTime.length == n`
- $1 \le \texttt{baseTime[i]} \le 10^5$
- Every task's finish time is less than $2^{53}$.
