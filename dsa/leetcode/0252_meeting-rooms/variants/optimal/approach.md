## General
Given an array of meeting times `intervals` where $\text{intervals}[i] = [\text{start}_{i}, \text{end}_{i}]$, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n \log n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
