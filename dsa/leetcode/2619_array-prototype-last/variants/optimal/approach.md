## General
Given Write code that enhances all arrays such that you can call the `array.last()` method on any array and it will return the last element. If there are no elements in the array, it should return `-1`, the JavaScript algorithm implements the solution for **Array Prototype Last**. Edge case handling: guards against empty inputs using array/string length checks.

## Complexity detail
- **Time Complexity**: $O(1)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
