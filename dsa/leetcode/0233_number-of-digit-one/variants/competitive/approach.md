## General
Given an integer `n`, count *the total number of digit *`1`* appearing in all non-negative integers less than or equal to* `n`, the algorithm solves **Number of Digit One** directly. Edge case handling: applies modulo arithmetic to prevent integer overflow.

## Complexity detail
- **Time Complexity**: $O(\log n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
