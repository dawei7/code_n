## General
Uses depth-first search / backtracking recursion. Maintains hash set (`set`) for $O(1)$ existence checks, dynamic programming memoization store. Applies bitwise operations (`&`, `|`, `^`, `<<`, `>>`).

## Complexity detail
- **Time Complexity**: $O(R^2 + hE)$ — Operation count bound.
- **Space Complexity**: $O(R^2)$ — Auxiliary memory allocation bound.
