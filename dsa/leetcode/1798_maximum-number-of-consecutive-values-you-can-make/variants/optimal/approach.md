## General
Given an integer array `coins` of length `n` which represents the `n` coins that you own. The value of the $$i^{\text{th}}$$ coin is $\text{coins}[i]$. You can **make** some value `x` if you can choose some of your `n` coin..., the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n \log n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
