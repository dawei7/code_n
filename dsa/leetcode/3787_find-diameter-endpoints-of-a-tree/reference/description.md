## Description

You are given an undirected tree with `n` nodes numbered from `0` through `n - 1`. Its `n - 1` undirected connections are listed in `edges`.

A tree's **diameter path** is any longest simple path between two nodes. More than one path may attain that maximum length. A node is **special** when it is the first or last node of at least one diameter path.

Return a binary string `s` of length `n`: set `s[i]` to `'1'` when node `i` is special and to `'0'` otherwise.
