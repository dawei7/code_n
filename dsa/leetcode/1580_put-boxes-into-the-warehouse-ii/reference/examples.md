## Examples

**Example 1**

- **Input:** `boxes = [1, 2, 2, 3, 4], warehouse = [3, 4, 1, 2]`
- **Output:** `4`
- **Explanation:** Place box 1 in room 2 (height 1), box 2 in room 3 (height 2), box 2 in room 0 (height 3), and box 3 in room 1 (height 4).

**Example 2**

- **Input:** `boxes = [3, 5, 5, 2], warehouse = [2, 1, 3, 4, 5]`
- **Output:** `3`
- **Explanation:** Place box 2 in room 0 (from left), box 3 in room 2 (from right), and box 5 in room 4 (from right).

**Example 3**

- **Input:** `boxes = [1, 2, 3], warehouse = [1, 2, 3, 4]`
- **Output:** `3`
- **Explanation:** All 3 boxes can be stored in the warehouse.
