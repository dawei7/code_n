## Description

Implement a first-in-first-out (**FIFO**) queue using only two stacks. The `MyQueue` class must support the usual queue operations:

- `push(x)` places `x` at the back of the queue.
- `pop()` removes and returns the element at the front.
- `peek()` returns the front element without removing it.
- `empty()` returns `true` when the queue contains no elements and `false` otherwise.
