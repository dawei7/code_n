## General
Executes a SQL query for **Countries You Can Safely Invest In** using relational JOINs, GROUP BY aggregations. Edge cases: filters aggregated group boundaries using `HAVING` clause.

## Complexity detail
- **Time Complexity**: $O((P + C + E) \log E)$ — Operation count bound.
- **Space Complexity**: $O(P + C + E)$ — Auxiliary memory allocation bound.
