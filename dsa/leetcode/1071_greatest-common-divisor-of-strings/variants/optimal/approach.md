## General
Given For two strings `s` and `t`, we say "`t` divides `s`" if and only if $s = t + t + t + ... + t + t$ (i.e., `t` is concatenated with itself one or more times), the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(N+M)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
