## General
Given a string `s` consisting only of lowercase English letters. We call a substring **special** if it contains no character which has occurred at least twice (in other words, it does not contain a repeating character). You..., the algorithm executes a single-pass linear scan through input elements. It utilizes a hash map (`dict`) to store element values and their indices/frequencies for $O(1)$ fast access.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
