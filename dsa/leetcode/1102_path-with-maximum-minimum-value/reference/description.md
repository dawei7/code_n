## Description

Given an $m \times n$ integer matrix `grid`, begin at the top-left cell `(0, 0)` and reach the bottom-right cell `(m - 1, n - 1)`. Each step must move one cell in a cardinal direction: up, down, left, or right.

The score of a path is the minimum cell value appearing anywhere along that path. For example, the path with values `8 → 4 → 5 → 9` has score 4. Return the maximum score achievable among all valid paths between the two corners.
