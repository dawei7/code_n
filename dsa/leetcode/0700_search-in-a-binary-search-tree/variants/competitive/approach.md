## General
Given the `root` of a binary search tree (BST) and an integer `val`, the algorithm solves **Search in a Binary Search Tree** directly. It utilizes binary tree node references (`val`, `left`, `right`) to traverse structural hierarchies.

## Complexity detail
- **Time Complexity**: $O(h)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
