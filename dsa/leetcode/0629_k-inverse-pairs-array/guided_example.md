# Guided Example: K Inverse Pairs Array

We trace the step-by-step permutation element insertion dynamics ($i \in [1, n]$), incremental inversion contribution range ($p \in [0, i - 1]$), 2D dynamic programming recurrence ($dp[i][j] = \sum dp[i-1][j-p]$), prefix sum range-query acceleration ($O(1)$ transitions), sliding window windowing, and modulo $10^9 + 7$ normalization on representative permutation sizes:

- **Input:** $n = 3, \quad k = 1$
- **Required output:** `2`
  - Problem definitions:
    - An **inverse pair** in an array $A$ is an index pair $(i, j)$ such that $i < j$ and $A[i] > A[j]$.
    - A permutation of $1 \dots n$ has $k$ inverse pairs.
    - Count the total number of distinct permutations of $\{1, \dots, n\}$ having **exactly $k$ inverse pairs**, modulo $10^9 + 7$.
  - Explicit verification for $n = 3$ (all $3! = 6$ permutations):
    - `[1, 2, 3]`: $0$ inverse pairs.
    - `[1, 3, 2]`: $1$ inverse pair: $(3, 2) \implies \mathbf{Valid!}$
    - `[2, 1, 3]`: $1$ inverse pair: $(2, 1) \implies \mathbf{Valid!}$
    - `[2, 3, 1]`: $2$ inverse pairs: $(2, 1), (3, 1)$.
    - `[3, 1, 2]`: $2$ inverse pairs: $(3, 1), (3, 2)$.
    - `[3, 2, 1]`: $3$ inverse pairs: $(3, 2), (3, 1), (2, 1)$.
  - Total permutations with $k = 1$ inverse pair: **`2`**.
- **Inductive Permutation Insertion Principle:**
  - Suppose we have a valid permutation of the first $i - 1$ numbers $\{1, 2, \dots, i - 1\}$.
  - We now insert the new maximum number $i$ into this permutation.
  - Since $i$ is strictly greater than all $i - 1$ existing numbers:
    - Placing $i$ at the **far right** (end) creates $0$ new inversions.
    - Placing $i$ one slot to the left creates $1$ new inversion (with the element to its right).
    - Placing $i$ two slots from the right creates $2$ new inversions.
    - ...
    - Placing $i$ at the **far left** (beginning) creates $i - 1$ new inversions (it precedes all other $i - 1$ elements).
  - Therefore, inserting $i$ can contribute any number of new inversions $p \in [0, \; i - 1]$.
- **Dynamic Programming Recurrence & Prefix Sum Acceleration:**
  - Let $dp[i][j]$ be the number of permutations of length $i$ with exactly $j$ inverse pairs:
    $$
    dp[i][j] = \sum_{p=0}^{i-1} dp[i-1][j - p] = \sum_{m = \max(0, j - (i - 1))}^{j} dp[i-1][m]
    $$
  - **The Prefix Sum Optimization:**
    - Computing the sum of $i$ terms directly takes $\mathcal{O}(i)$ per cell, yielding $\mathcal{O}(n^2 k)$ total time (too slow).
    - Notice that $dp[i][j]$ is simply the sum of a contiguous window of length at most $i$ in row $i - 1$.
    - Let $s$ be the prefix sum array of row $i - 1$:
      $$
      s[m] = \sum_{t=0}^{m-1} dp[i-1][t]
      $$
    - Any window sum computes in $\mathcal{O}(1)$ time:
      $$
      dp[i][j] = \left( s[j + 1] - s[\max(0, \; j - (i - 1))] \right) \pmod{10^9 + 7}
      $$
- **Step-by-Step Worked Execution Trace ($n = 3, k = 1$):**
  - Initialize DP array $f$ for $i = 0$:
    - $f[0] = 1$ (empty permutation has 0 inversions).
    - $f[j] = 0$ for $j > 0$.
    - $f = [1, 0]$.
    - Prefix sum array $s = [0, 1, 1]$.
  - **Iteration $i = 1$ (Permutations of $\{1\}$):**
    - Window length $i = 1 \implies$ can add $p \in [0, 0] = 0$ inversions.
    - $j = 0$: $f[0] = 1$.
    - $j = 1$: $f[1] = (s[2] - s[\max(0, 1)]) = 1 - 1 = \mathbf{0}$.
    - State $f = [1, 0]$.
    - Updated prefix sums: $s = [0, 1, 1]$.
  - **Iteration $i = 2$ (Permutations of $\{1, 2\}$):**
    - Can add $p \in [0, 1]$ inversions.
    - $j = 0$: $f[0] = 1$ (`[1, 2]`).
    - $j = 1$: $p \in [0, 1]$ from $j = 1$:
      $$
      f[1] = s[2] - s[\max(0, 1 - 1)] = s[2] - s[0] = 1 - 0 = \mathbf{1} \quad (\text{permutation } [2, 1])
      $$
    - State $f = [1, 1]$.
    - Updated prefix sums: $s = [0, 1, 2]$.
  - **Iteration $i = 3$ (Permutations of $\{1, 2, 3\}$):**
    - Can add $p \in [0, 2]$ inversions.
    - $j = 0$: $f[0] = 1$ (`[1, 2, 3]`).
    - $j = 1$:
      - Window range: $m \in [\max(0, 1 - 2), \; 1] = [0, 1]$.
      - Query prefix sum:
        $$
        f[1] = s[1 + 1] - s[0] = s[2] - s[0] = 2 - 0 = \mathbf{2}
        $$
      - The two permutations are generated by:
        - Inserting 3 at end of `[2, 1]` ($+0$ inversions) $\implies \mathbf{[2, 1, 3]}$
        - Inserting 3 at second slot of `[1, 2]` ($+1$ inversion) $\implies \mathbf{[1, 3, 2]}$
    - State $f = [1, 2]$.
  - **Final Output:**
    $$
    f[k] = f[1] = \mathbf{2}
    $$
- **Zero Inversions ($k = 0$):**
  - Only the strictly increasing sorted permutation $[1, 2, \dots, n]$ has 0 inversions $\implies \mathbf{1}$ for any $n$.
- **Max Inversions ($k = \binom{n}{2}$):**
  - Only the reversed permutation $[n, n-1, \dots, 1]$ achieves maximum inversions $\implies \mathbf{1}$.
- **Excessive Inversions ($k > \binom{n}{2}$):**
  - Impossible $\implies \mathbf{0}$.

This instance demonstrates generating function coefficients for Mahonian numbers over the symmetric group $S_n$, mathematically proves why incremental insertion reduces inversion counting to moving-window convolutions, and derives $O(N \cdot K)$ runtime and $O(K)$ space bounds.

## 1. Instance & Teaching Goal

Given $n$ and $k$:
Find the number of permutations of $1 \dots n$ that have **exactly $k$ inverse pairs** (modulo $10^9 + 7$).

```text
n = 3, k = 1

All 6 permutations of [1, 2, 3]:
  [1, 2, 3] -> 0 inverse pairs
  [1, 3, 2] -> 1 inverse pair (3, 2)  <-- MATCH!
  [2, 1, 3] -> 1 inverse pair (2, 1)  <-- MATCH!
  [2, 3, 1] -> 2 inverse pairs
  [3, 1, 2] -> 2 inverse pairs
  [3, 2, 1] -> 3 inverse pairs

Count = 2
```

### The Invariant of the Expanding Element
- When inserting element $i$ into a permutation of size $i - 1$:
  - $i$ is larger than everything currently in the array.
  - Putting $i$ at index $i - 1$ (end) adds 0 inversions.
  - Putting $i$ at index $i - 2$ adds 1 inversion.
  - Putting $i$ at index 0 (start) adds $i - 1$ inversions.
- Therefore, each transition convolves the previous row with a uniform window of length $i$.

---

## 2. Conceptual Foundation & Invariants

### 1. Recurrence Relation:
$$
dp[i][j] = \sum_{p=0}^{i-1} dp[i-1][j-p]
$$

### 2. Prefix Sum Range Query:
With prefix sum $s[t] = \sum_{m=0}^{t-1} dp[i-1][m]$:
$$
dp[i][j] = \left( s[j+1] - s[\max(0, j - (i - 1))] \right) \pmod{10^9 + 7}
$$

> **Mahonian Convolution Invariant.** The generating function for the distribution of inversions in $S_n$ factorizes as $I_n(q) = \prod_{i=1}^n (1 + q + q^2 + \dots + q^{i-1}) = \prod_{i=1}^n \frac{1 - q^i}{1 - q}$, where $dp[n][k]$ is the coefficient of $q^k$.

---

## 3. Step-by-Step Worked Execution

We trace $n = 3, k = 1$:

---

### Step 1: Base State $i = 1$
- $f = [1, 0]$ (only 1 permutation of length 1, with 0 inversions).
- $s = [0, 1, 1]$.

---

### Step 2: Transition to $i = 2$
- $j = 0$: $f[0] = 1$.
- $j = 1$: $f[1] = s[2] - s[0] = 1 - 0 = 1$.
- $f = [1, 1]$.
- $s = [0, 1, 2]$.

---

### Step 3: Transition to $i = 3$
- $j = 0$: $f[0] = 1$.
- $j = 1$: $f[1] = s[2] - s[0] = 2 - 0 = \mathbf{2}$.
- Target reached! Return $f[1] = 2$.

## 4. Complete Execution Trace

| Level $i$ | Permutation Target | $f[0]$ ($k=0$) | $f[1]$ ($k=1$) | Prefix Array $s$ |
|:---:|:---:|:---:|:---:|:---:|
| $1$ | $\{1\}$ | $1$ | $0$ | $[0, 1, 1]$ |
| $2$ | $\{1, 2\}$ | $1$ | $1$ | $[0, 1, 2]$ |
| **$3$** | **$\{1, 2, 3\}$** | **$1$** | **`2`** | — |

## 5. Boundary Cases & Failure Modes

- **$k = 0$:** Always 1 (the single identity permutation).
- **$k > \frac{n(n-1)}{2}$:** Impossible $\implies$ returns 0.
- **$n = 1, k = 0$:** Returns 1.
- **Negative Modulo Subtraction:** In Python `(A - B) % MOD` is automatically non-negative; in C++/Java add `+ MOD` before modulo.

---

## 6. Traps & Common Anti-Patterns

- **$O(N \cdot K^2)$ Brute Force DP:** Summing the inner window element by element results in Time Limit Exceeded for $n, k \le 1000$. Prefix sum windowing is mandatory.
- **Full 2D Matrix Memory:** Allocating an $N \times K$ table of $1000 \times 1000$ integers uses unnecessary memory. Rolling 1D array $f$ and prefix array $s$ requires only $O(K)$ space.
- **Window Underflow:** The lower bound of the sliding window must be clamped at 0: $\max(0, j - (i - 1))$.

---

## 7. Complexity Derivation

- **Time Complexity:**
  - Outer loop runs $N$ times.
  - Inner loop for $j$ runs $K$ times.
  - Each cell computes in $\mathcal{O}(1)$ time via prefix sum subtraction.
  - Total Time: strictly $\mathcal{O}(N \cdot K)$. For $N, K \le 1000$, performs $10^6$ operations, completing in $< 40$ ms.
- **Auxiliary Space Complexity:**
  - $\mathcal{O}(K)$ auxiliary space for the rolling 1D state arrays $f$ and $s$.
