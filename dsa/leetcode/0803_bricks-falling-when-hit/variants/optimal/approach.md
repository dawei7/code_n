## General
Given an `m x n` binary `grid`, where each `1` represents a brick and `0` represents an empty space. A brick is **stable** if:, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O((r \cdot c + h) \cdot \alpha(r \cdot c))$ — Operation count bound.
- **Space Complexity**: $O(r \cdot c)$ — Auxiliary memory allocation bound.
