## General
Given an `m x n` grid of characters `board` and a string `word`, return `true` *if* `word` *exists in the grid*, the algorithm executes depth-first search (DFS) recursion to explore valid decision branches.

## Complexity detail
- **Time Complexity**: $O(mn \cdot 3^L)$ — Operation count bound.
- **Space Complexity**: $O(L)$ — Auxiliary memory allocation bound.
