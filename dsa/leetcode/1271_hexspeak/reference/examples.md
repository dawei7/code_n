## Examples

**Example 1**

- **Input:** `num = "257"`
- **Output:** `"IOI"`
- **Explanation:** The decimal value `257` is `101` in hexadecimal. Replacing its `1` digits with `I` and its `0` digit with `O` produces `"IOI"`.

**Example 2**

- **Input:** `num = "3"`
- **Output:** `"ERROR"`

**Additional Example**

- **Input:** `num = "2827"`
- **Output:** `"BOB"`

The hexadecimal representation is `B0B`, so replacing `0` with `O` produces a valid Hexspeak string.
