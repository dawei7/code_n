## Examples

**Example 1**

- Input: `g = [1,2,3], s = [1,1]`
- Output: `1`
- **Explanation:** There are three children with greed factors `1`, `2`, and `3`, but both available cookies have size `1`. Only the child with greed factor `1` can be made content, so the answer is `1`.

**Example 2**

- Input: `g = [1,2], s = [1,2,3]`
- Output: `2`
- **Explanation:** There are two children with greed factors `1` and `2`. Among the three cookies, there are adequate sizes for both children, so the answer is `2`.
