## Examples

**Example 1**

- Input: `nums = [2,1,3]`
- Output: `3`
- Explanation:

  To make all elements equal:

  - Increase `nums[0] = 2` by `1`, making it `3`.
  - Increase `nums[1] = 1` by `1`, making it `2`.
  - Increase `nums[1] = 2` by `1` again, making it `3`.

  Every element is now equal to `3`, and the minimum total is `3` moves.

**Example 2**

- Output: `2`
- Explanation:

  - Increase `nums[1] = 4` by `1`, making it `5`.
