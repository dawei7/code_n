## Description

Given an integer array `nums`, return every triplet `[nums[i], nums[j], nums[k]]` for which the three indices are pairwise distinct and

$$
\texttt{nums[i]} + \texttt{nums[j]} + \texttt{nums[k]} = 0.
$$

The result must not contain duplicate value triplets. The order of the triplets and the order of values inside each triplet do not matter.
