## General
Given an integer array `nums` and an integer `goal`, the algorithm executes a single-pass linear scan through input elements. Key operations include bitwise operators (`&`, `|`, `^`, `<<`, `>>`) for fast bitmask state updates.

## Complexity detail
- **Time Complexity**: $O(n2^{n/2})$ — Operation count bound.
- **Space Complexity**: $O(2^{n/2})$ — Auxiliary memory allocation bound.
