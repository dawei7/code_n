## Description

You are given a 2D integer array `students` where `students[i] = [student_id, bench_id]` represents a student with `student_id` sitting on a bench with `bench_id`.

Note that multiple entries can exist for the same student, but each student should be counted **only once** per bench.

Return the **maximum** number of unique students sitting on any single bench. If no students are present, return `0`.
