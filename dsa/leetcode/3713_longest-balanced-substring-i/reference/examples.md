## Examples

**Example 1**

- Input: `s = "abbac"`
- Output: `4`
- Explanation: The longest balanced substring is `"abba"`. Its two distinct characters, `a` and `b`, each occur exactly twice.

**Example 2**

- Input: `s = "zzabccy"`
- Output: `4`
- Explanation: The substring `"zabc"` is longest. Its four distinct characters `z`, `a`, `b`, and `c` each occur exactly once.

**Example 3**

- Input: `s = "aba"`
- Output: `2`
- Explanation: `"ab"` is balanced because `a` and `b` each occur once. The other length-two substring, `"ba"`, is another longest balanced choice.
