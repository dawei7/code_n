## General
Given There is a hotel with `n` rooms. The rooms are represented by a 2D integer array `rooms` where $\text{rooms}[i] = [\text{roomId}_{i}, \text{size}_{i}]$ denotes that there is a room with room number $\text{roomId}_{i}$..., the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O((r+q)\log r)$ — Operation count bound.
- **Space Complexity**: $O(r+q)$ — Auxiliary memory allocation bound.
