## General
Uses single-pass sequential iteration. Maintains double-ended queue (`deque`) for $O(1)$ operations, tree traversal nodes (`val`, `left`, `right`). Applies bitwise operations (`&`, `|`, `^`, `<<`, `>>`).

## Complexity detail
- **Time Complexity**: $O(n C_n)$ — Operation count bound.
- **Space Complexity**: $O(n C_n)$ — Auxiliary memory allocation bound.
