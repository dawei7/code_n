## Examples

**Example 1**

- Input: `l1 = [2, 4, 3], l2 = [5, 6, 4]`
- Output: `[7, 0, 8]`
- Explanation: The lists represent 342 and 465. Their sum is 807, whose reversed digit sequence is `[7, 0, 8]`.

**Example 2**

- Input: `l1 = [0], l2 = [0]`
- Output: `[0]`

**Example 3**

- Input: `l1 = [9, 9, 9, 9, 9, 9, 9], l2 = [9, 9, 9, 9]`
- Output: `[8, 9, 9, 9, 0, 0, 0, 1]`
