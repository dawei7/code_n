## General
Given two **non-empty** linked lists representing two non-negative integers. The digits are stored in **reverse order**, and each of their nodes contains a single digit. Add the two numbers and return the sum as a linked list, the algorithm executes a single-pass linear scan through input elements. It utilizes linked list node pointers (`val`, `next`) to process sequential node chains.

## Complexity detail
- **Time Complexity**: $O(\max(n, m))$ — Operation count bound.
- **Space Complexity**: $O(\max(n, m))$ — Auxiliary memory allocation bound.
