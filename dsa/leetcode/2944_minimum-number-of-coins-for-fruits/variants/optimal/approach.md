## General
Given an **0-indexed** integer array `prices` where $\text{prices}[i]$ denotes the number of coins needed to purchase the $(i + 1)^th$ fruit, the algorithm executes depth-first search (DFS) recursion to explore valid decision branches.

## Complexity detail
- **Time Complexity**: $O(N)$ — Operation count bound.
- **Space Complexity**: $O(N)$ — Auxiliary memory allocation bound.
