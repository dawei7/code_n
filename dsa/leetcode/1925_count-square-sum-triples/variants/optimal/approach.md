## General
Given A **square triple** `(a,b,c)` is a triple where `a`, `b`, and `c` are **integers** and $a^{2} + b^{2} = c^{2}$, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n^2)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
