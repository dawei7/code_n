## General
Given a **0-indexed** string `s` and a dictionary of words `dictionary`. You have to break `s` into one or more **non-overlapping** substrings such that each substring is present in `dictionary`. There may be some **extra c..., the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n^2 + W)$ — Operation count bound.
- **Space Complexity**: $O(n + W)$ — Auxiliary memory allocation bound.
