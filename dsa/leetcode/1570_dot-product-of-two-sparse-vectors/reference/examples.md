## Examples

**Example 1**

- **Input:** `nums1 = [1,0,0,2,3], nums2 = [0,3,0,4,0]`
- **Output:** `8`
- **Explanation:** $1 \times 0 + 0 \times 3 + 0 \times 0 + 2 \times 4 + 3 \times 0 = 8$.

**Example 2**

- **Input:** `nums1 = [0,1,0,0,0], nums2 = [0,0,0,0,2]`
- **Output:** `0`
- **Explanation:** $1 \times 0 + 0 \times 2 = 0$.

**Example 3**

- **Input:** `nums1 = [0,1,0,0,2,0,0], nums2 = [1,0,0,0,3,0,4]`
- **Output:** `6`
- **Explanation:** $1 \times 0 + 2 \times 3 = 6$.
