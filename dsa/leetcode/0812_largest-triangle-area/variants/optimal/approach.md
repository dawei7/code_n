## General
Given an array of points on the **X-Y** plane `points` where $\text{points}[i] = [x_{i}, y_{i}]$, return *the area of the largest triangle that can be formed by any three different points*. Answers within $10^{-5}$ of the a..., the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n^3)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
