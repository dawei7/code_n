## Test Case Format

For the test representation, a node's value equals its one-based index: the first node has `val == 1`, the second has `val == 2`, and so on. An adjacency list represents the graph, with each row giving the unordered set of neighbors of one node.

The supplied reference is always the first node, whose value is `1`. Return a reference to the cloned copy of this node, which serves as the entry point to the cloned graph.
