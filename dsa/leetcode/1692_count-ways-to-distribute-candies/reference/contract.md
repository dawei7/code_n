## Function Contract

**Inputs**

- `n`: An integer representing the number of unique candies ($1 \le n \le 1000$).
- `k`: An integer representing the number of bags ($1 \le k \le n \le 1000$).

**Return value**

Return an integer representing the number of ways to distribute `n` candies into `k` bags modulo $10^9 + 7$.
