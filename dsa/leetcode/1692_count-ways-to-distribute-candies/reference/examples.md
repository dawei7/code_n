## Examples

**Example 1**

- **Input:** `n = 3, k = 2`
- **Output:** `3`
- **Explanation:** You have 3 candies labeled 1, 2, and 3, and 2 bags.
  The 3 ways to distribute them are:
  - `[1, 2], [3]`
  - `[1, 3], [2]`
  - `[2, 3], [1]`

**Example 2**

- **Input:** `n = 4, k = 2`
- **Output:** `7`
- **Explanation:** You have 4 candies labeled 1, 2, 3, and 4, and 2 bags.
  The 7 ways to distribute them are:
  - `[1, 2, 3], [4]`
  - `[1, 2, 4], [3]`
  - `[1, 3, 4], [2]`
  - `[2, 3, 4], [1]`
  - `[1, 2], [3, 4]`
  - `[1, 3], [2, 4]`
  - `[1, 4], [2, 3]`

**Example 3**

- **Input:** `n = 20, k = 5`
- **Output:** `206085257`
