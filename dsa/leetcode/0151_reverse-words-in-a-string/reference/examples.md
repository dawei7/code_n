## Examples

**Example 1**

- Input: `s = "the sky is blue"`
- Output: `"blue is sky the"`

**Example 2**

- Input: `s = "  hello world  "`
- Output: `"world hello"`
- Explanation: The reversed string has neither leading nor trailing spaces.

**Example 3**

- Input: `s = "a good   example"`
- Output: `"example good a"`
- Explanation: The run of spaces between two words is reduced to a single separator in the result.
