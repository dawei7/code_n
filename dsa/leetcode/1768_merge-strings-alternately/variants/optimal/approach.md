## General
Given two strings `word1` and `word2`. Merge the strings by adding letters in alternating order, starting with `word1`. If a string is longer than the other, append the additional letters onto the end of the merged string, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(A+B)$ — Operation count bound.
- **Space Complexity**: $O(A+B)$ — Auxiliary memory allocation bound.
