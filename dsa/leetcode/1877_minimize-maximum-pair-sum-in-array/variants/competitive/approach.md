## General
Given The **pair sum** of a pair `(a,b)` is equal to $a + b$. The **maximum pair sum** is the largest **pair sum** in a list of pairs, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(N\log N)$ — Operation count bound.
- **Space Complexity**: $O(N)$ — Auxiliary memory allocation bound.
