## General
Given a **0-indexed** array of positive integers `w` where $w[i]$ describes the **weight** of the $$i^{\text{th}}$$ index, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n + q \log n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
