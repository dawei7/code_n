## Problem Description
### Goal
You are given an $m\times n$ 0-indexed matrix `mat` whose entries are decimal digits. Starting from any cell, choose one of eight directions: east, south-east, south, south-west, west, north-west, north, or north-east. Travel in that fixed direction and append each visited digit to the number being formed.

Every nonempty prefix of such a path produces a number. For example, visiting the digits `1`, `9`, and `1` in order generates `1`, then `19`, then `191`. A path stops when its next cell would be outside the matrix, and its direction may never change.

Among all generated numbers that are prime and strictly greater than `10`, return the one with the greatest frequency. If several qualifying primes have the same maximum frequency, return the largest of them. Return `-1` when no qualifying prime is generated.

### Function Contract
Let $m=\lvert\texttt{mat}\rvert$, $n=\lvert\texttt{mat[0]}\rvert$, and $\ell=\max(m,n)$. Let $V$ be the greatest number generated by any path; then $V<10^\ell$.

**Inputs**

- `mat`: A rectangular matrix with $1\le m,n\le6$ whose entries are integers from `1` through `9`.

**Return value**

Return the most frequent generated prime strictly greater than `10`, using the larger prime to break a frequency tie, or `-1` if none exists.

### Examples
**Example 1**

- Input: `mat = [[1,1],[9,9],[1,1]]`
- Output: `19`
- Explanation: Straight paths generate `19` repeatedly, as well as values such as `11`, `91`, `99`, and `191`. Among qualifying primes, `19` has the greatest frequency.

**Example 2**

- Input: `mat = [[7]]`
- Output: `-1`
- Explanation: The only generated number is the prime `7`, but it is not greater than `10`.

**Example 3**

- Input: `mat = [[9,7,8],[4,6,5],[2,8,6]]`
- Output: `97`
- Explanation: Enumerating every straight path produces several primes, and `97` wins under the required frequency and larger-value tie rules.
