## General
Given the `root` of a binary tree, return *the average value of the nodes on each level in the form of an array*. Answers within $10^{-5}$ of the actual answer will be accepted, the algorithm executes a single-pass linear scan through input elements. It utilizes binary tree node references (`val`, `left`, `right`) to traverse structural hierarchies.

## Complexity detail
- **Time Complexity**: $O(N)$ — Operation count bound.
- **Space Complexity**: $O(W)$ — Auxiliary memory allocation bound.
