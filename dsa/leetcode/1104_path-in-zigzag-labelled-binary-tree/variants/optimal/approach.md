## General
Given In an infinite binary tree where every node has two children, the nodes are labelled in row order, the algorithm solves **Path In Zigzag Labelled Binary Tree** directly. Key operations include bitwise operators (`&`, `|`, `^`, `<<`, `>>`) for fast bitmask state updates.

## Complexity detail
- **Time Complexity**: $O(\log L)$ — Operation count bound.
- **Space Complexity**: $O(\log L)$ — Auxiliary memory allocation bound.
