## Description

You are given an integer array `transactions`; `transactions[i]` is the amount of transaction $i$.

- A positive amount means that money is received.
- A negative amount means that money is sent.

The account begins with balance `0`, and its balance may never become negative. Consider transactions in their given order, choosing to perform or skip each one.

Return the maximum number of transactions that can be performed while respecting the non-negative-balance rule at every point.
