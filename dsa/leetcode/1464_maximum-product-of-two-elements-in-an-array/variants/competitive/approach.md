## General
Given the array of integers `nums`, you will choose two different indices `i` and `j` of that array. *Return the maximum value of* $(\text{nums}[i]-1)*(\text{nums}[j]-1)$, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
