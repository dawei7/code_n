## Description

Implement a calculator for a valid arithmetic expression. The expression contains non-negative integer literals, the binary operators `+`, `-`, `*`, and `/`, and opening and closing parentheses.

Evaluate parentheses and the usual arithmetic precedence, applying operators of equal precedence from left to right. Integer division truncates toward zero. Every intermediate result is guaranteed to remain within the signed 32-bit range from $-2^{31}$ through $2^{31}-1$.
