## Description

Given a non-empty array `arr` of distinct integers sorted in **ascending order**, a fixed point is a zero-based index `i` whose stored value equals that index: `arr[i] == i`. The array may contain more than one fixed point, even though every value is distinct, because different values can equal their respective positions.

Return the smallest fixed-point index. Finding a later equality is not sufficient when an earlier one also exists. If no index satisfies the equality, return `-1`.
