## Examples

**Example 1**

- Input: `nums = [1,0,0,2,0,1]`
- Output: `2`
- Explanation: There are exactly two valid pairs:

  - `(0, 3)` has distance `abs(0 - 3) = 3`.
  - `(5, 3)` has distance `abs(5 - 3) = 2`.

  The smaller distance is `2`.

**Example 2**

- Input: `nums = [1,0,1,0]`
- Output: `-1`
- Explanation: The array contains no `2`, so no valid pair exists and the required result is `-1`.
