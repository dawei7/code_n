## Examples

**Example 1**

- **Input:** `nums = [4, 2, 0, 3, 1]`
- **Output:** `3`
- **Explanation:** Moving items `2`, `1`, and `4` into the successive empty positions produces `[0, 1, 2, 3, 4]`, using 3 operations.

**Example 2**

- **Input:** `nums = [1, 2, 3, 4, 0]`
- **Output:** `0`
- **Explanation:** The array is already in the valid layout `[1, 2, 3, 4, 0]`, requiring 0 operations.

**Example 3**

- **Input:** `nums = [1, 0, 2, 4, 3]`
- **Output:** `2`
- **Explanation:** Moving items to produce `[1, 2, 3, 4, 0]` takes 2 operations.
