## General
Given an integer array `jobs`, where $\text{jobs}[i]$ is the amount of time it takes to complete the $$i^{\text{th}}$$ job, the algorithm executes depth-first search (DFS) recursion to explore valid decision branches.

## Complexity detail
- **Time Complexity**: $O(k^n)$ — Operation count bound.
- **Space Complexity**: $O(k+n)$ — Auxiliary memory allocation bound.
