## Description

You are given a *positive* number `n`.

Return the **smallest** number `x` **greater than** or **equal to** `n`, such that the binary representation of `x` contains only <span data-keyword="set-bit">set bits</span>

**Example 1:**

<div class="example-block">
**Input:** <span class="example-io">n = 5</span>

**Output:** <span class="example-io">7</span>

**Explanation:**

The binary representation of 7 is `"111"`.

</div>

**Example 2:**

<div class="example-block">
**Input:** <span class="example-io">n = 10</span>

**Output:** <span class="example-io">15</span>

**Explanation:**

The binary representation of 15 is `"1111"`.

</div>

**Example 3:**

<div class="example-block">
**Input:** <span class="example-io">n = 3</span>

**Output:** <span class="example-io">3</span>

**Explanation:**

The binary representation of 3 is `"11"`.

</div>

**Constraints:**

	- `1 <= n <= 1000`
