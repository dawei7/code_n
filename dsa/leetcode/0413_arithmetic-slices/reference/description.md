## Description

An integer array is arithmetic when it has at least three elements and the difference between every pair of
consecutive elements is the same. For example, `[1, 3, 5, 7, 9]`, `[7, 7, 7, 7]`, and `[3, -1, -5, -9]` are all
arithmetic sequences.

Given an integer array `nums`, return the number of its arithmetic subarrays. A subarray is a contiguous subsequence
of the array, and different start or end positions identify different subarrays.
