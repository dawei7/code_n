## General
Given the `head` of a linked list and an integer `val`, remove all the nodes of the linked list that has $\text{Node.val} = val$, and return *the new head*, the algorithm executes a single-pass linear scan through input elements. It utilizes linked list node pointers (`val`, `next`) to process sequential node chains.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
