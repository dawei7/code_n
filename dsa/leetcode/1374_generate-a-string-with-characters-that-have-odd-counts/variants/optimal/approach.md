## General
Given an integer `n`, *return a string with `n` characters such that each character in such string occurs **an odd number of times***, the algorithm solves **Generate a String With Characters That Have Odd Counts** directly. Key operations include bitwise operators (`&`, `|`, `^`, `<<`, `>>`) for fast bitmask state updates.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
