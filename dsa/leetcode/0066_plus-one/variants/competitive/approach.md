## General
Given a **large integer** represented as an integer array `digits`, where each $\text{digits}[i]$ is the $$i^{\text{th}}$$ digit of the integer. The digits are ordered from most significant to least significant in left-to-r..., the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
