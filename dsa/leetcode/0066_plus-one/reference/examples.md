## Examples

**Example 1**

- Input: `digits = [1, 2, 3]`
- Output: `[1, 2, 4]`
- Explanation: The input represents `123`; adding one produces `124`, represented by `[1, 2, 4]`.

**Example 2**

- Input: `digits = [4, 3, 2, 1]`
- Output: `[4, 3, 2, 2]`
- Explanation: The represented integer is `4321`, and `4321 + 1 = 4322`, so the result is `[4, 3, 2, 2]`.

**Example 3**

- Input: `digits = [9]`
- Output: `[1, 0]`
- Explanation: The single digit represents `9`; because `9 + 1 = 10`, the result requires two digits, `[1, 0]`.
