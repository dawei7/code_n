## Description

Evaluate every Boolean expression recorded in `Expressions`. Resolve `left_operand` and `right_operand` through `Variables`, then compare their stored integer values using the row's `operator`.

For each expression, preserve `left_operand`, `operator`, and `right_operand`, and append a `value` column containing the lowercase string `true` when the comparison holds or `false` otherwise. Result rows may be returned in any order.
