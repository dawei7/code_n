## General
Given ![](images/change.png), the algorithm executes a single-pass linear scan through input elements. Key operations include bitwise operators (`&`, `|`, `^`, `<<`, `>>`) for fast bitmask state updates.

## Complexity detail
- **Time Complexity**: $O(n\log M)$ — Operation count bound.
- **Space Complexity**: $O(\log M)$ — Auxiliary memory allocation bound.
