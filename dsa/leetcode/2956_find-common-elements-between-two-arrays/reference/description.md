## Description

You are given two integer arrays `nums1` and `nums2` of sizes `n` and `m`, respectively. Calculate the following values:

<ul>
	<li>`answer1` : the number of indices `i` such that `nums1[i]` exists in `nums2`.</li>
	<li>`answer2` : the number of indices `i` such that `nums2[i]` exists in `nums1`.</li>
</ul>

Return `[answer1,answer2]`.
