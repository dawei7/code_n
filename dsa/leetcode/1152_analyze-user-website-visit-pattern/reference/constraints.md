## Constraints

- $3 \le \texttt{username.length} \le 50$
- $1 \le \lvert\texttt{username[i]}\rvert \le 10$
- `timestamp.length == username.length`
- $1 \le \texttt{timestamp[i]} \le 10^9$
- `website.length == username.length`
- $1 \le \lvert\texttt{website[i]}\rvert \le 10$
- Every user name and website name contains only lowercase English letters.
- At least one user has visited at least three websites.
- Every tuple `[username[i], timestamp[i], website[i]]` is unique.
