## General
Given two values `o1` and `o2`, return a boolean value indicating whether two values, `o1` and `o2`, are **deeply equal**, the JavaScript algorithm implements the solution for **JSON Deep Equal**. Edge case handling: guards against empty inputs using array/string length checks.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
