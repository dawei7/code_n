## General
Given an integer array `nums` that may contain duplicates, return *all possible* *subsets** (the power set)*, the algorithm executes depth-first search (DFS) recursion to explore valid decision branches.

## Complexity detail
- **Time Complexity**: $O(n \cdot U)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
