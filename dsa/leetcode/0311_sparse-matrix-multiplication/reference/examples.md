## Examples

**Example 1**

- Input: `mat1 = [[1,0,0],[-1,0,3]], mat2 = [[7,0,0],[0,0,0],[0,0,1]]`
- Output: `[[7,0,0],[-7,0,3]]`

The source illustration writes the multiplication as three matrices:

```text
[ 1  0  0 ]   [ 7  0  0 ]   [ 7  0  0 ]
[-1  0  3 ] x [ 0  0  0 ] = [-7  0  3 ]
                [ 0  0  1 ]
```

**Example 2**

- Input: `mat1 = [[0]], mat2 = [[0]]`
- Output: `[[0]]`
