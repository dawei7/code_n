## General
Given an array `original` of length `n` and a 2D array `bounds` of length `n x 2`, where $\text{bounds}[i] = [u_{i}, v_{i}]$, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
