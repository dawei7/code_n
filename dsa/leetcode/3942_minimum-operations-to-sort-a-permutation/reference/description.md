## Description

You are given an integer array `nums` of length `n`, where `nums` is a <span data-keyword="permutation-array">permutation</span> of the integers from 0 to `n - 1`.

You may perform **only** the following operations:

<ul>
	<li>**Reverse** the entire array.</li>
	<li>**Rotate Left by One**: Move the first element to the end of the array, and rest elements to left by one position.</li>
</ul>

Return an integer denoting the **minimum** number of operations required to sort the array in **increasing** order. If it is **not possible** to sort the array using only the given operations, return -1.
