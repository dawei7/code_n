## General
Given an integer array `nums`. In one move, you can pick an index `i` where $0 \le i < \text{nums.length}$ and increment $\text{nums}[i]$ by `1`, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n+M)$ — Operation count bound.
- **Space Complexity**: $O(M)$ — Auxiliary memory allocation bound.
