## Description

Two integer arrays, `nums1` and `nums2`, contain the same elements with the same multiplicities, but possibly in different orders. In other words, `nums2` is an anagram of `nums1`; either array may contain duplicate values.

Construct an index mapping from `nums1` into `nums2`. For every position `i`, an output entry `mapping[i] = j` must identify a position `j` where `nums2[j]` equals `nums1[i]`. Duplicate values can make several mappings valid, and any valid mapping may be returned.
