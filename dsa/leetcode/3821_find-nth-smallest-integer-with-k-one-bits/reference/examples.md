## Examples

**Example 1**

- Input: `n = 4, k = 2`
- Output: `9`
- Explanation:

  The four smallest positive integers having exactly two one bits are:

  - $3=(11)_2$
  - $5=(101)_2$
  - $6=(110)_2$
  - $9=(1001)_2$

**Example 2**

- Input: `n = 3, k = 1`
- Output: `4`
- Explanation:

  The three smallest positive integers having exactly one one bit are:

  - $1=(1)_2$
  - $2=(10)_2$
  - $4=(100)_2$
