## Examples

**Example 1**

- **Input:** `nums = [2,4,5,5,5,5,5,6,6], target = 5`
- **Output:** `true`
- **Explanation:** The array has length $9$, and `5` occurs five times. Because $5 > 9/2$, the target is a majority element.

**Example 2**

- **Input:** `nums = [10,100,101,101], target = 101`
- **Output:** `false`
- **Explanation:** The array has length $4$, and `101` occurs twice. Because $2 > 4/2$ is false, the target is not a majority element.
