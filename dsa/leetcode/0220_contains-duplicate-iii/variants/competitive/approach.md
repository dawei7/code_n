## General
Given an integer array `nums` and two integers `indexDiff` and `valueDiff`, the algorithm executes a single-pass linear scan through input elements. Edge case handling: guards against empty/null inputs via early returns.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(\min(n,indexDiff))$ — Auxiliary memory allocation bound.
