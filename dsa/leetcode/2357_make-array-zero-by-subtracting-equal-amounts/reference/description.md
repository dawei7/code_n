## Description

You are given a non-negative integer array `nums`. In one operation, you must:

<ul>
	<li>Choose a positive integer `x` such that `x` is less than or equal to the **smallest non-zero** element in `nums`.</li>
	<li>Subtract `x` from every **positive** element in `nums`.</li>
</ul>

Return *the **minimum** number of operations to make every element in *`nums`* equal to *`0`.
