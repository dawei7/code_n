## General
Given There are `n` computers numbered from `0` to $n - 1$ connected by ethernet cables `connections` forming a network where $\text{connections}[i] = [a_{i}, b_{i}]$ represents a connection between computers $a_{i}$ and $b..., the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O((n+m)\alpha(n))$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
