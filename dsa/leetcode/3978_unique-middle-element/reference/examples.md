## Examples

**Example 1**

- Input: `nums = [1,2,3]`
- Output: `true`
- **Explanation:** The middle position contains `2`. That value occurs exactly once in the complete array, so the result is `true`.

**Example 2**

- Input: `nums = [1,2,2]`
- Output: `false`
- **Explanation:** The middle position also contains `2`, but this value occurs twice in the array. Its frequency is not exactly one, so the result is `false`.
