## Description

You receive an integer array `nums` whose length $n$ is odd. This guarantee gives the original array exactly one middle position, at index $\lfloor n / 2 \rfloor$. The middle element is the value stored at that position; it is not a median obtained by sorting or otherwise rearranging the values.

Determine whether that middle value occurs exactly once in the entire array. Return `true` only when no other position contains the same integer. Repetitions of values different from the middle value have no effect on the result; if the middle value appears anywhere else, return `false`.
