## Examples

**Example 1**

- **Input:** `Point2D = [[-1,-1],[0,0],[-1,-2]]`

| x | y |
|---:|---:|
| -1 | -1 |
| 0 | 0 |
| -1 | -2 |

- **Output:** `[[1.00]]`

| shortest |
|---:|
| 1.00 |

- **Explanation:** The points `(-1, -1)` and `(-1, -2)` are one unit apart, which is the minimum distance. The source explanation displays the second point as `(-1, 2)`, but that coordinate is not in its input table; the negative coordinate above follows the source input.
