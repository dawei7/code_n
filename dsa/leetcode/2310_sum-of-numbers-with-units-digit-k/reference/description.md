## Description

Given two integers `num` and `k`, consider a set of positive integers with the following properties:

<ul>
	<li>The units digit of each integer is `k`.</li>
	<li>The sum of the integers is `num`.</li>
</ul>

Return *the **minimum** possible size of such a set, or *`-1`* if no such set exists.*

Note:

<ul>
	<li>The set can contain multiple instances of the same integer, and the sum of an empty set is considered `0`.</li>
	<li>The **units digit** of a number is the rightmost digit of the number.</li>
</ul>
