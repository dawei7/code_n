## Description

You are given an array of strings `words` and an integer `k`.

Two words `a` and `b` at **distinct indices** are **prefix-connected** when their first `k` characters are identical: `a[0..k-1] == b[0..k-1]`.

A **connected group** is a set of words in which every pair of words is prefix-connected.

Return the **number of connected groups** formed from `words` that contain **at least** two words.
