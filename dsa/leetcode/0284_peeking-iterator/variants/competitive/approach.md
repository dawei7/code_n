## General
Given Design an iterator that supports the `peek` operation on an existing iterator in addition to the `hasNext` and the `next` operations, the algorithm solves **Peeking Iterator** directly. Edge case handling: guards against empty/null inputs via early returns.

## Complexity detail
- **Time Complexity**: $O(1)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
