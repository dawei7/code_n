## General
Given an `m x n` `grid`. Each cell of `grid` represents a street. The street of $\text{grid}[i][j]$ can be:, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(mn)$ — Operation count bound.
- **Space Complexity**: $O(mn)$ — Auxiliary memory allocation bound.
