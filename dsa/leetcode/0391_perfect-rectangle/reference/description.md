## Description

You are given axis-aligned rectangles, where `rectangles[i] = [x_i,y_i,a_i,b_i]` identifies bottom-left corner $(x_i,y_i)$ and top-right corner $(a_i,b_i)$.

Return `true` exactly when the union of all supplied rectangles forms an exact cover of one rectangular region, with neither gaps nor overlapping area.
