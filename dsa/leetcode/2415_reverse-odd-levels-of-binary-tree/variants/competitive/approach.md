## General
Uses two-pointer iteration. Maintains tree traversal nodes (`val`, `left`, `right`). Applies bitwise operations (`&`, `|`, `^`, `<<`, `>>`).

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(log n)$ — Auxiliary memory allocation bound.
