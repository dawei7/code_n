## General
Given an array `trees` where $\text{trees}[i] = [x_{i}, y_{i}]$ represents the location of a tree in the garden, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n \log n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
