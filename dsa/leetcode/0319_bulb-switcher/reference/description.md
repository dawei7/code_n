## Description

There are `n` bulbs, all initially off. In the first round, turn every bulb on. In the second round, turn every second bulb off. During round $i$, toggle every $i$th bulb: an off bulb becomes on and an on bulb becomes off. The $n$th and final round toggles only the last bulb.

Return how many bulbs are on after all `n` rounds.
