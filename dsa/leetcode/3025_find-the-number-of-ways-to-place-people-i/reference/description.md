## Description

You are given a 2D array `points` of size `n x 2` representing integer coordinates of some points on a 2D plane, where `points[i] = [x_i, y_i]`.

Count the number of pairs of points `(A, B)`, where

<ul>
	<li>`A` is on the **upper left** side of `B`, and</li>
	<li>there are no other points in the rectangle (or line) they make (**including the border**), except for the points `A` and `B`.</li>
</ul>

Return the count.
