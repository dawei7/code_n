## General
Given a large sample of integers in the range `[0, 255]`. Since the sample is so large, it is represented by an array `count` where $\text{count}[k]$ is the **number of times** that `k` appears in the sample, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(1)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
