## General
Given a **0-indexed** 2D integer array `transactions`, where $\text{transactions}[i] = [\text{cost}_{i}, \text{cashback}_{i}]$, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
