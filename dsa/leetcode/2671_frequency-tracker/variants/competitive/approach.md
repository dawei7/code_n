## General
Given Design a data structure that keeps track of the values in it and answers some queries regarding their frequencies, the algorithm solves **Frequency Tracker** directly. It utilizes a hash map (`dict`) to store element values and their indices/frequencies for $O(1)$ fast access.

## Complexity detail
- **Time Complexity**: $O(1)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
