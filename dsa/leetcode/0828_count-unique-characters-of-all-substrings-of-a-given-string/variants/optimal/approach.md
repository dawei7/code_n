## General
Given Let's define a function `countUniqueChars(s)` that returns the number of unique characters in `s`, the algorithm executes a single-pass linear scan through input elements. It utilizes a hash map (`dict`) to store element values and their indices/frequencies for $O(1)$ fast access.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(A)$ — Auxiliary memory allocation bound.
