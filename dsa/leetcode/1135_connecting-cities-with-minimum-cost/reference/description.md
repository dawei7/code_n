## Description

There are `n` cities labeled from `1` through `n`. Each entry `connections[i] = [x_i, y_i, cost_i]` offers a bidirectional connection between cities `x_i` and `y_i` whose use costs `cost_i`.

Choose connections so that every pair of cities has at least one path between them. The cost of a choice is the sum of all selected connection costs.

Return the minimum possible cost of connecting all `n` cities. If the available connections cannot make the entire set connected, return `-1`.
