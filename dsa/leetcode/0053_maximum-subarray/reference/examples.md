## Examples

**Example 1**

- Input: `nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]`
- Output: `6`
- Explanation: The subarray `[4, -1, 2, 1]` has sum `6`, which is the largest possible.

**Example 2**

- Input: `nums = [1]`
- Output: `1`
- Explanation: The only non-empty subarray is `[1]`, whose sum is `1`.

**Example 3**

- Input: `nums = [5, 4, -1, 7, 8]`
- Output: `23`
- Explanation: The entire subarray `[5, 4, -1, 7, 8]` has the maximum sum, `23`.
