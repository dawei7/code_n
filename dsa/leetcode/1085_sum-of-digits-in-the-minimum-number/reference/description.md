## Description

Given an integer array `nums`, identify its minimum value and add that value's decimal digits. Return `0` when this digit sum is odd; otherwise, return `1`.

Only the minimum integer contributes to the sum. Select the least value across the complete array, even when that value occurs more than once, then interpret its base-ten representation and add each of its digits exactly once. The minimum's position and all larger array values do not affect the result.
