## Examples

**Example 1**

- **Input:** `nums = [34,23,1,24,75,33,54,8]`
- **Output:** `0`
- **Explanation:** The minimum element is `1`. Its digit sum is `1`, which is odd, so the result is `0`.

**Example 2**

- **Input:** `nums = [99,77,33,66,55]`
- **Output:** `1`
- **Explanation:** The minimum element is `33`. Its digit sum is `3 + 3 = 6`, which is even, so the result is `1`.
