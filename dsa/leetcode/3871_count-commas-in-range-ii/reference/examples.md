## Examples

**Example 1**

- Input: `n = 1002`
- Output: `3`

- **Explanation:** Only `1000`, `1001`, and `1002` contain commas. Their formatted forms are `"1,000"`, `"1,001"`, and `"1,002"`, so their one-comma contributions sum to `3`.

**Example 2**

- Input: `n = 998`
- Output: `0`

- **Explanation:** Every value in the range has fewer than four digits, so standard formatting inserts no commas anywhere in the range.
