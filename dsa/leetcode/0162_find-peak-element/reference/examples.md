## Examples

**Example 1**

- Input: `nums = [1, 2, 3, 1]`
- Output: `2`
- Explanation: The value `3` is a peak, and its index is `2`.

**Example 2**

- Input: `nums = [1, 2, 1, 3, 5, 6, 4]`
- Output: `5`
- Explanation: Index `1`, whose value is `2`, and index `5`, whose value is `6`, are both peaks. Returning either index is valid.
