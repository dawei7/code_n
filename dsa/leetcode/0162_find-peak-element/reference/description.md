## Description

A peak element is strictly greater than each of its neighbors. Given a 0-indexed integer array `nums`, return the index of any peak; when several peaks exist, any one of their indices is valid.

Imagine that `nums[-1] = nums[n] = -∞`. Thus, an endpoint is compared with negative infinity on its missing side and is strictly greater than that out-of-range neighbor.

Your algorithm must run in $O(\log n)$ time.
