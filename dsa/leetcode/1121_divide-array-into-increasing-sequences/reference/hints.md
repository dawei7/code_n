## Hints

1. Examine the frequencies of the values and how they constrain the number of required subsequences.
2. Use those frequencies to determine the minimum number of subsequences that must be formed.
3. Keeping the number of subsequences as small as possible makes their lengths as large as possible.
4. The necessary number of subsequences equals the greatest frequency of any one value.
5. Consider a greedy way to distribute all remaining elements among those subsequences.
