## General
Uses two-pointer iteration. Maintains hash map (`dict`) for $O(1)$ average lookup, hash set (`set`) for $O(1)$ existence checks, dynamic programming memoization store. Applies bitwise operations (`&`, `|`, `^`, `<<`, `>>`).

## Complexity detail
- **Time Complexity**: $O(M^3V^2+A)$ — Operation count bound.
- **Space Complexity**: $O(M^2V)$ — Auxiliary memory allocation bound.
