## General
Given two **0-indexed** integer arrays `nums1` and `nums2` of even length `n`, the algorithm solves **Maximum Size of a Set After Removals** directly. Key operations include bitwise operators (`&`, `|`, `^`, `<<`, `>>`) for fast bitmask state updates.

## Complexity detail
- **Time Complexity**: $O(N)$ — Operation count bound.
- **Space Complexity**: $O(N)$ — Auxiliary memory allocation bound.
