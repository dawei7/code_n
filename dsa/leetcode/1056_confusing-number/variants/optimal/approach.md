## General
Given A **confusing number** is a number that when rotated `180` degrees becomes a different number with **each digit valid**, the algorithm solves **Confusing Number** directly. It utilizes a hash map (`dict`) to store element values and their indices/frequencies for $O(1)$ fast access.

## Complexity detail
- **Time Complexity**: $O(D)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
