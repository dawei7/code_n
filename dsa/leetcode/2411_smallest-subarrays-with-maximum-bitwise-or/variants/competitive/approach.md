## General
Given a **0-indexed** array `nums` of length `n`, consisting of non-negative integers. For each index `i` from `0` to $n - 1$, you must determine the size of the **minimum sized** non-empty subarray of `nums` starting at `i..., the algorithm executes a single-pass linear scan through input elements. Key operations include bitwise operators (`&`, `|`, `^`, `<<`, `>>`) for fast bitmask state updates.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
