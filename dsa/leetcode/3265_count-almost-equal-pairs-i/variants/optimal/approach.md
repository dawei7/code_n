## General
Given an array `nums` consisting of positive integers, the algorithm executes a single-pass linear scan through input elements. It utilizes a hash map (`dict`) to store element values and their indices/frequencies for $O(1)$ fast access.

## Complexity detail
- **Time Complexity**: $O(n log n + n d^3)$ — Operation count bound.
- **Space Complexity**: $O(n + d^2)$ — Auxiliary memory allocation bound.
