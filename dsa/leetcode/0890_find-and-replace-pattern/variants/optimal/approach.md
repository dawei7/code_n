## General
Given a list of strings `words` and a string `pattern`, return *a list of* $\text{words}[i]$ *that match* `pattern`. You may return the answer in **any order**, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(NL)$ — Operation count bound.
- **Space Complexity**: $O(N+L)$ — Auxiliary memory allocation bound.
