## Description

You are given an $m \times n$ binary matrix `grid`. A cell containing `1` is land, and land cells belong to the same island when they are connected horizontally or vertically. Each island is a maximal four-directionally connected group of land cells. All four outer edges of the matrix may be treated as surrounded by water.

Two islands have the same shape if and only if translating one of them makes its land cells coincide exactly with the other. Rotation and reflection are not permitted when comparing shapes. Return the number of distinct island shapes present in the matrix.
