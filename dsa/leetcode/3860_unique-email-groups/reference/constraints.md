## Constraints

- $1 \le \lvert\texttt{emails}\rvert \le 1000$
- $1 \le \lvert\texttt{emails[i]}\rvert \le 100$
- Each `emails[i]` contains only lowercase and uppercase English letters,
  digits, `.`, `+`, and `@`.
- Every `emails[i]` contains exactly one `@` character.
- All local and domain names are nonempty, and no local name starts with `+`.
- Every domain name ends with the `.com` suffix and has at least one character
  before that suffix.
