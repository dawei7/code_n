## General
Given There are `n` types of units indexed from `0` to $n - 1$, the algorithm executes breadth-first search (BFS) level-order traversal using a queue. Edge case handling: applies modulo arithmetic to prevent integer overflow.

## Complexity detail
- **Time Complexity**: $O(n + Q)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
