## General
Given An integer divisible by the **sum** of its digits is said to be a **Harshad** number. You are given an integer `x`. Return* the sum of the digits *of* *`x`* *if* *`x`* *is a **Harshad** number, otherwise, return* *`-1..., the algorithm solves **Harshad Number** directly. Edge case handling: applies modulo arithmetic to prevent integer overflow.

## Complexity detail
- **Time Complexity**: $O(log x)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
