## General
Given Design a special dictionary that searches the words in it by a prefix and a suffix, the algorithm executes a single-pass linear scan through input elements. It utilizes a hash map (`dict`) to store element values and their indices/frequencies for $O(1)$ fast access.

## Complexity detail
- **Time Complexity**: $O(wL^2+q)$ — Operation count bound.
- **Space Complexity**: $O(wL^2)$ — Auxiliary memory allocation bound.
