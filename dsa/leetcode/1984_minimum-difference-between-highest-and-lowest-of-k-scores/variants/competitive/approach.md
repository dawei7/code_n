## General
Given a **0-indexed** integer array `nums`, where $\text{nums}[i]$ represents the score of the $$i^{\text{th}}$$ student. You are also given an integer `k`, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(N\log N)$ — Operation count bound.
- **Space Complexity**: $O(N)$ — Auxiliary memory allocation bound.
