## General
Given an integer `num`. You can swap two digits at most once to get the maximum valued number, the algorithm executes a single-pass linear scan through input elements. It utilizes a hash map (`dict`) to store element values and their indices/frequencies for $O(1)$ fast access.

## Complexity detail
- **Time Complexity**: $O(\log N)$ — Operation count bound.
- **Space Complexity**: $O(\log N)$ — Auxiliary memory allocation bound.
