## Function Contract

**Inputs**

- `nums`: A nonempty array of positive integers.

Let $N=\lvert\texttt{nums}\rvert$. Each operation is evaluated on the current array, and the leftmost eligible pair must be chosen when several pairs are equal at the same time. A merged value may exceed the original per-element bound.

**Return value**

Return the remaining values in their current order after every possible leftmost adjacent-equal merge has been applied.
