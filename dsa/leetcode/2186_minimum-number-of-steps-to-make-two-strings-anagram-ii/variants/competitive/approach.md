## General
Given two strings `s` and `t`. In one step, you can append **any character** to either `s` or `t`, the algorithm solves **Minimum Number of Steps to Make Two Strings Anagram II** directly. It utilizes a hash map (`dict`) to store element values and their indices/frequencies for $O(1)$ fast access.

## Complexity detail
- **Time Complexity**: $O(n + m)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
