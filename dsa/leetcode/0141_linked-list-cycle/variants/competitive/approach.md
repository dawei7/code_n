## General
Given `head`, the head of a linked list, determine if the linked list has a cycle in it, the algorithm solves **Linked List Cycle** directly. It utilizes linked list node pointers (`val`, `next`) to process sequential node chains.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
