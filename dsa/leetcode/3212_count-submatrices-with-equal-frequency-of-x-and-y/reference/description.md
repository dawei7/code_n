## Description

Given a 2D character matrix `grid`, where `grid[i][j]` is either `'X'`, `'Y'`, or `'.'`, return the number of <span data-keyword="submatrix">submatrices</span> that contain:

<ul>
	<li>`grid[0][0]`</li>
	<li>an **equal** frequency of `'X'` and `'Y'`.</li>
	<li>**at least** one `'X'`.</li>
</ul>
