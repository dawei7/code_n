## Description

Serialization converts a data structure or object into a sequence of bits that can be stored in memory or a file, sent over a connection, and later reconstructed in the same or another computing environment.

Design a binary-tree codec with a serialization operation and its inverse. A tree must be convertible to a string, and deserializing that string must recreate the original tree structure. The particular representation is unrestricted as long as every string produced by the serializer can be decoded unambiguously.
