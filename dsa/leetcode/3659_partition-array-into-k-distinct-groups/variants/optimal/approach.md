## General
Given an integer array `nums` and an integer `k`, the algorithm solves **Partition Array Into K-Distinct Groups** directly. It utilizes a hash map (`dict`) to store element values and their indices/frequencies for $O(1)$ fast access.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(d)$ — Auxiliary memory allocation bound.
