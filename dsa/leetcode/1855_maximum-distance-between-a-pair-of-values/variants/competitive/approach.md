## General
Given two **non-increasing 0-indexed **integer arrays `nums1`​​​​​​ and `nums2`​​​​​​, the algorithm solves **Maximum Distance Between a Pair of Values** directly.

## Complexity detail
- **Time Complexity**: $O(n+m)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
