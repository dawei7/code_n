## Examples

**Example 1**

- Input: `nums = [4, 14, 2]`
- Output: `6`
- Explanation: Using the four relevant bits, the values are `0100`, `1110`, and `0010`. The three pairwise distances
  are `HammingDistance(4, 14) = 2`, `HammingDistance(4, 2) = 2`, and `HammingDistance(14, 2) = 2`, whose sum is 6.

**Example 2**

- Input: `nums = [4, 14, 4]`
- Output: `4`
