## General
Given an integer `num`. You will apply the following steps to `num` **two** separate times:, the algorithm executes a single-pass linear scan through input elements. It utilizes a hash map (`dict`) to store element values and their indices/frequencies for $O(1)$ fast access. Edge case handling: applies modulo arithmetic to prevent integer overflow.

## Complexity detail
- **Time Complexity**: $O(d)$ — Operation count bound.
- **Space Complexity**: $O(d)$ — Auxiliary memory allocation bound.
