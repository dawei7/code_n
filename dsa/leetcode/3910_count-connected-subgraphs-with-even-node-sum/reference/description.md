## Description

An undirected graph has $n$ nodes numbered from $0$ through $n-1$. Each node carries the binary value stored at the same index in `nums`, and every pair `[u, v]` in `edges` joins nodes `u` and `v`.

Choose any non-empty subset of nodes. Its induced subgraph contains exactly those chosen nodes and exactly the original edges whose two endpoints were both chosen. Count the subsets for which this induced subgraph is connected and the sum of the chosen node values is even.
