## Description

You are given a lowercase English string `s` of length `n`.

You must perform exactly one operation. Choose an integer `k` with $1 \leq k \leq n$, then perform one of these actions:

- Reverse the first `k` characters of `s`.
- Reverse the last `k` characters of `s`.

Return the lexicographically smallest string obtainable after that one operation.
