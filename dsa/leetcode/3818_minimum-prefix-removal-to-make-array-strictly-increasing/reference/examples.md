## Examples

**Example 1**

- Input: `nums = [1,-1,2,3,3,4,5]`
- Output: `4`
- Explanation: Removing the prefix `[1, -1, 2, 3]` leaves `[3, 4, 5]`, which is strictly increasing.

**Example 2**

- Input: `nums = [4,3,-2,-5]`
- Output: `3`
- Explanation: Removing the prefix `[4, 3, -2]` leaves the one-element array `[-5]`, which is strictly increasing.

**Example 3**

- Input: `nums = [1,2,3,4]`
- Output: `0`
- Explanation: `nums` is already strictly increasing, so removing the empty prefix is sufficient.
