## Examples

**Example 1**

- Input: `board = [["X",".",".","X"],[".",".",".","X"],[".",".",".","X"]]`
- Output: `2`

The example board has this layout:

| | Column 0 | Column 1 | Column 2 | Column 3 |
|---|---|---|---|---|
| Row 0 | `X` | `.` | `.` | `X` |
| Row 1 | `.` | `.` | `.` | `X` |
| Row 2 | `.` | `.` | `.` | `X` |

**Example 2**

- Input: `board = [["."]]`
- Output: `0`
