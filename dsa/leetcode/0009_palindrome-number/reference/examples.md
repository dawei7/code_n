## Examples

**Example 1**

- Input: `x = 121`
- Output: `true`
- Explanation: Reading 121 in either direction produces the same sequence of digits.

**Example 2**

- Input: `x = -121`
- Output: `false`
- Explanation: Left to right the representation is `-121`, while reversing it would place the minus sign at the end as `121-`; the two representations differ.

**Example 3**

- Input: `x = 10`
- Output: `false`
- Explanation: Reading the representation backward gives `01`, which is not the same as `10`.
