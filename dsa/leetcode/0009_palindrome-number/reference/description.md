## Description

Given an integer `x`, determine whether its usual decimal representation is a palindrome. A palindromic value presents exactly the same ordered digits from left to right as it does from right to left, so every digit must match the digit at the corresponding distance from the opposite end.

Consider the complete conventional representation of the integer, including a minus sign when `x` is negative. Do not discard, rearrange, or add any symbols before making the comparison. Return `true` when the full representation is palindromic and `false` otherwise.
