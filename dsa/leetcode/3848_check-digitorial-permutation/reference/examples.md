## Examples

**Example 1**

- Input: `n = 145`
- Output: `true`
- Explanation: The original arrangement is digitorial because `1! + 4! + 5! = 1 + 24 + 120 = 145`. Therefore, a qualifying permutation exists.

**Example 2**

- Input: `n = 10`
- Output: `false`
- Explanation: The original number is not digitorial because `1! + 0! = 2`, which differs from `10`. Its other arrangement, `"01"`, begins with zero and is invalid.
