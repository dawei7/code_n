## General
Given an array of **unique** integers `salary` where $\text{salary}[i]$ is the salary of the $$i^{\text{th}}$$ employee, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(N)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
