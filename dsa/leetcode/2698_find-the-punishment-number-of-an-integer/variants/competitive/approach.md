## General
Given a positive integer `n`, return *the **punishment number*** of `n`, the algorithm executes depth-first search (DFS) recursion to explore valid decision branches. Key operations include bitwise operators (`&`, `|`, `^`, `<<`, `>>`) for fast bitmask state updates.

## Complexity detail
- **Time Complexity**: $O(n d 2^d)$ — Operation count bound.
- **Space Complexity**: $O(d)$ — Auxiliary memory allocation bound.
