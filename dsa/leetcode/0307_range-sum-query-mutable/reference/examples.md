## Examples

**Example 1**

- Input: `["NumArray","sumRange","update","sumRange"], [[[1,3,5]],[0,2],[1,2],[0,2]]`
- Output: `[null,9,null,8]`
- Explanation: Construct `NumArray` from `[1,3,5]`. The first `sumRange(0,2)` returns `9`. After `update(1,2)`, the array is `[1,2,5]`, so the final `sumRange(0,2)` returns `8`.
