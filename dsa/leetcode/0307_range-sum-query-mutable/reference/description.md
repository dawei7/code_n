## Description

Given an integer array `nums`, support both point updates and inclusive range-sum queries.

Implement the `NumArray` class:

- `NumArray(int[] nums)` initializes the object with `nums`.
- `void update(int index, int val)` assigns `val` to `nums[index]`.
- `int sumRange(int left, int right)` returns `nums[left] + nums[left + 1] + ... + nums[right]`, including both endpoints.
