## General
Given a binary array `nums` and an integer `goal`, return *the number of non-empty **subarrays** with a sum* `goal`, the algorithm executes a two-pointer approach to shrink boundaries or maintain a sliding window.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
