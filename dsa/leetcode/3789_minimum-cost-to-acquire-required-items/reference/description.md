## Description

You are given five integers: `cost1`, `cost2`, `costBoth`, `need1`, and `need2`.

Three item types are available:

- A type-1 item costs `cost1` and supplies one unit only toward requirement 1.
- A type-2 item costs `cost2` and supplies one unit only toward requirement 2.
- A type-3 item costs `costBoth` and supplies one unit toward each requirement.

Acquire items whose total contribution is at least `need1` for type 1 and at least `need2` for type 2. Return the minimum possible total cost.
