## Examples

**Example 1**

- **Input:** `Sales = [["2020-05-01","apples",10],["2020-05-01","oranges",8],["2020-05-02","apples",15],["2020-05-02","oranges",15],["2020-05-03","apples",20],["2020-05-03","oranges",0],["2020-05-04","apples",15],["2020-05-04","oranges",16]]`

| sale_date | fruit | sold_num |
|---|---|---:|
| `2020-05-01` | `apples` | 10 |
| `2020-05-01` | `oranges` | 8 |
| `2020-05-02` | `apples` | 15 |
| `2020-05-02` | `oranges` | 15 |
| `2020-05-03` | `apples` | 20 |
| `2020-05-03` | `oranges` | 0 |
| `2020-05-04` | `apples` | 15 |
| `2020-05-04` | `oranges` | 16 |

- **Output:** `[["2020-05-01",2],["2020-05-02",0],["2020-05-03",20],["2020-05-04",-1]]`

| sale_date | diff |
|---|---:|
| `2020-05-01` | 2 |
| `2020-05-02` | 0 |
| `2020-05-03` | 20 |
| `2020-05-04` | -1 |

- **Explanation:** On `2020-05-01`, the difference is $10-8=2$. On `2020-05-02`, equal sales give $15-15=0$. On `2020-05-03`, subtracting zero oranges gives $20-0=20$. On `2020-05-04`, oranges exceed apples, so $15-16=-1$.
