## General
Given two positive integers `x` and `y`, the algorithm executes depth-first search (DFS) recursion to explore valid decision branches. Edge case handling: applies modulo arithmetic to prevent integer overflow.

## Complexity detail
- **Time Complexity**: $O(log^2 X)$ — Operation count bound.
- **Space Complexity**: $O(log^2 X)$ — Auxiliary memory allocation bound.
