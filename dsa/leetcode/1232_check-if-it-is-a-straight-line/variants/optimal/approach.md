## General
Given an integer array `coordinates`, $\text{coordinates}[i] = [x, y]$, where `[x, y]` represents the coordinate of a point. Check if these points make a straight line in the XY plane, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
