## General
Given an integer array `arr` and a filtering function `fn`, return a filtered array `filteredArr`, the JavaScript algorithm implements the solution for **Filter Elements from Array**. Edge case handling: guards against empty inputs using array/string length checks.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
