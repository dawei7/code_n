## General
Given a string `num` which represents an integer, return `true` *if* `num` *is a **strobogrammatic number***, the algorithm solves **Strobogrammatic Number** directly. It utilizes a hash map (`dict`) to store element values and their indices/frequencies for $O(1)$ fast access.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
