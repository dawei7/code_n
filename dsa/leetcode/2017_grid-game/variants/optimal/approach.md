## General
Given a **0-indexed** 2D array `grid` of size `2 x n`, where $\text{grid}[r][c]$ represents the number of points at position `(r, c)` on the matrix. Two robots are playing a game on this matrix, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(N)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
