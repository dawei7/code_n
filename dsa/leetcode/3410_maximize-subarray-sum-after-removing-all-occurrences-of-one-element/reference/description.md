## Description

You are given an integer array `nums`.

You can do the following operation on the array **at most** once:

<ul>
	<li>Choose **any** integer `x` such that `nums` remains **non-empty** on removing all occurrences of `x`.</li>
	<li>Remove **all** occurrences of `x` from the array.</li>
</ul>

Return the **maximum** <span data-keyword="subarray-nonempty">subarray</span> sum across **all** possible resulting arrays.
