## General
Given a string `s` of lowercase English letters and an array `widths` denoting **how many pixels wide** each lowercase English letter is. Specifically, $\text{widths}[0]$ is the width of `'a'`, $\text{widths}[1]$ is the wid..., the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
