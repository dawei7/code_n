## General
Given Design your implementation of the linked list. You can choose to use a singly or doubly linked list, the algorithm solves **Design Linked List** directly. It utilizes a hash map (`dict`) to store element values and their indices/frequencies for $O(1)$ fast access.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
