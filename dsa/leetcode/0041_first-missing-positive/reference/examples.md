## Examples

**Example 1**

- Input: `nums = [1, 2, 0]`
- Output: `3`
- Explanation: Both positive integers in the range $[1, 2]$ occur in the array.

**Example 2**

- Input: `nums = [3, 4, -1, 1]`
- Output: `2`
- Explanation: The array contains `1`, but it does not contain `2`.

**Example 3**

- Input: `nums = [7, 8, 9, 11, 12]`
- Output: `1`
- Explanation: The smallest positive integer, `1`, is absent.
