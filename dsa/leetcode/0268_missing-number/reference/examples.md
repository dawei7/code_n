## Examples

**Example 1**

- Input: `nums = [3,0,1]`
- Output: `2`
- Explanation: The array length is `3`, so the complete range is `[0,3]`. The only value from that range absent from `nums` is `2`.

**Example 2**

- Input: `nums = [0,1]`
- Output: `2`
- Explanation: Here `n = 2`, making `[0,2]` the expected range. The value `2` is the only one not present.

**Example 3**

- Input: `nums = [9,6,4,2,3,5,7,0,1]`
- Output: `8`
- Explanation: Because the array has length `9`, its values come from `[0,9]`. Every value in that range except `8` appears.
