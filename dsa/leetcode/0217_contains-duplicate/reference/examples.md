## Examples

**Example 1**

- Input: `nums = [1,2,3,1]`
- Output: `true`
- Explanation: The value `1` occurs at indices `0` and `3`.

**Example 2**

- Input: `nums = [1,2,3,4]`
- Output: `false`
- Explanation: Every element is distinct.

**Example 3**

- Input: `nums = [1,1,1,3,3,4,3,2,4,2]`
- Output: `true`
