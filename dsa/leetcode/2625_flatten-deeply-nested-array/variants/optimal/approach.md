## General
Given a **multi-dimensional** array `arr` and a depth `n`, return a **flattened** version of that array, the JavaScript algorithm implements the solution for **Flatten Deeply Nested Array**. Edge case handling: guards against empty inputs using array/string length checks.

## Complexity detail
- **Time Complexity**: $O(V)$ — Operation count bound.
- **Space Complexity**: $O(V + D)$ — Auxiliary memory allocation bound.
