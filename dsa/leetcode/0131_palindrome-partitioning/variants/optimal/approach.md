## General
Given a string `s`, partition `s` such that every substring of the partition is a **palindrome**. Return *all possible palindrome partitioning of *`s`, the algorithm executes depth-first search (DFS) recursion to explore valid decision branches.

## Complexity detail
- **Time Complexity**: $O(n^2 + L)$ — Operation count bound.
- **Space Complexity**: $O(n^2 + n)$ — Auxiliary memory allocation bound.
