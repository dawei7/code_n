## Description

Design the `CombinationIterator` class:

<ul>
	<li>`CombinationIterator(string characters, int combinationLength)` Initializes the object with a string `characters` of **sorted distinct** lowercase English letters and a number `combinationLength` as arguments.</li>
	<li>`next()` Returns the next combination of length `combinationLength` in **lexicographical order**.</li>
	<li>`hasNext()` Returns `true` if and only if there exists a next combination.</li>
</ul>
