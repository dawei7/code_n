## Examples

**Example 1**

- Input: `n = 8`
- Output: `3`
- Explanation: One optimal sequence is `8 -> 4 -> 2 -> 1`.

**Example 2**

- Input: `n = 7`
- Output: `4`
- Explanation: Both `7 -> 8 -> 4 -> 2 -> 1` and `7 -> 6 -> 3 -> 2 -> 1` use four operations.

**Example 3**

- Input: `n = 4`
- Output: `2`
