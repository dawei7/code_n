## General
Given an integer array `prices` where $\text{prices}[i]$ is the price of the $$i^{\text{th}}$$ item in a shop, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(N)$ — Operation count bound.
- **Space Complexity**: $O(N)$ — Auxiliary memory allocation bound.
