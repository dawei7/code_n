## General
Uses breadth-first search queue traversal. Maintains hash map (`dict`) for $O(1)$ average lookup, double-ended queue (`deque`) for $O(1)$ operations.

## Complexity detail
- **Time Complexity**: $O(n+E+S+Vlog V)$ — Operation count bound.
- **Space Complexity**: $O(n+V)$ — Auxiliary memory allocation bound.
