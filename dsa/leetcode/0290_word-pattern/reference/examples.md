## Examples

**Example 1**

- Input: `pattern = "abba", s = "dog cat cat dog"`
- Output: `true`
- Explanation: A valid bijection maps `a` to `"dog"` and `b` to `"cat"`.

**Example 2**

- Input: `pattern = "abba", s = "dog cat cat fish"`
- Output: `false`

**Example 3**

- Input: `pattern = "aaaa", s = "dog cat cat dog"`
- Output: `false`
