## Description

Given a signed 32-bit integer `x`, reverse the decimal digits of its magnitude while retaining its sign. Leading zeroes in the reversed digit sequence disappear under ordinary integer representation; for example, reversing `120` produces `21`.

Return the reversed value when it remains inside the signed 32-bit range $[-2^{31}, 2^{31}-1]$. Return `0` if reversal would leave that interval. Assume that neither signed nor unsigned 64-bit integers are available for intermediate storage.
