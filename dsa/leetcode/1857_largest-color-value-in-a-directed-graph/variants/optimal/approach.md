## General
Algorithm uses breadth-first search queue level traversal. Maintains hash map lookup (`dict`) for $O(1)$ average speed, double-ended queue (`deque`) for $O(1)$ window bounds, dynamic programming memoization array/table.

## Complexity detail
- **Time Complexity**: $O(26(n+m))$ — Operation count bound.
- **Space Complexity**: $O(26n+m)$ — Auxiliary memory allocation bound.
