## Examples

**Example 1**

- Input: `nums = [1,-1,5,-2,3], k = 3`
- Output: `4`
- Explanation: The longest qualifying subarray is `[1,-1,5,-2]`; its sum is `3` and its length is `4`.

**Example 2**

- Input: `nums = [-2,-1,2,1], k = 1`
- Output: `2`
- Explanation: The longest qualifying subarray is `[-1,2]`, which has sum `1` and length `2`.
