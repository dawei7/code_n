## General
Given A string can be **abbreviated** by replacing any number of **non-adjacent**, **non-empty** substrings with their lengths. The lengths **should not** have leading zeros, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(w + a)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
