## General
Given Alice and Bob each have a **lexicographically sorted** array of strings named `a` and `b` respectively, the algorithm solves **The Wording Game** directly. Key operations include bitwise operators (`&`, `|`, `^`, `<<`, `>>`) for fast bitmask state updates.

## Complexity detail
- **Time Complexity**: $O(S)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
