## Examples

**Example 1**

- Input: `num = "123", target = 6`
- Output: `["1*2*3","1+2+3"]`
- Explanation: Both `1*2*3` and `1+2+3` evaluate to `6`.

**Example 2**

- Input: `num = "232", target = 8`
- Output: `["2*3+2","2+3*2"]`
- Explanation: Both `2*3+2` and `2+3*2` evaluate to `8`.

**Example 3**

- Input: `num = "3456237490", target = 9191`
- Output: `[]`
- Explanation: No expression formed by inserting the allowed operators into `3456237490` evaluates to `9191`.
