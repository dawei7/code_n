## Description

You are given two binary strings, `s` and `t`, with the same length $n$. The bits of `s` remain at their original indices throughout the problem.

Before computing the bitwise XOR, you may rearrange the characters of `t` in any order. Every zero and one from `t` must still be used exactly once in the rearranged string.

Among all XOR results obtainable this way, return the length-$n$ binary string whose represented integer is greatest.
