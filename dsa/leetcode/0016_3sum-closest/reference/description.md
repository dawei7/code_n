## Description

Given an integer array `nums` of length $n$ and an integer `target`, choose values from exactly three pairwise distinct indices. Equal values may be selected when they occur at different positions. Add the three selected values to obtain a candidate sum.

Measure closeness by the absolute difference between a candidate sum and `target`. Consider every permitted choice of three positions and return the sum with the smallest such difference. Every input is guaranteed to have exactly one closest result, so no tie-breaking rule is needed.
