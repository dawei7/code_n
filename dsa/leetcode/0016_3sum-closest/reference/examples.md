## Examples

**Example 1**

- Input: `nums = [-1, 2, 1, -4], target = 1`
- Output: `2`
- Explanation: The closest obtainable sum is $-1+2+1=2$.

**Example 2**

- Input: `nums = [0, 0, 0], target = 1`
- Output: `0`
- Explanation: The only three-value sum is $0+0+0=0$, which is therefore closest to the target.
