## Constraints

- $1 \le n,m \le 10^5$
- $1 \le n\cdot m \le 10^5$
- $1 \le \lvert\texttt{sources}\rvert \le n\cdot m$
- Each entry has the form `sources[i] = [r_i, c_i, color_i]`.
- $0 \le r_i \le n-1$
- $0 \le c_i \le m-1$
- $1 \le color_i \le 10^6$
- All source coordinates $(r_i,c_i)$ are distinct.
