## Examples

**Example 1**

- Input: `s = "abbac"`
- Output: `4`
- Explanation: `"abba"` is the longest balanced substring because its distinct characters `a` and `b` each occur exactly twice.

**Example 2**

- Input: `s = "aabcc"`
- Output: `3`
- Explanation: The longest balanced substring is `"abc"`; `a`, `b`, and `c` each occur exactly once within it.

**Example 3**

- Input: `s = "aba"`
- Output: `2`
- Explanation: `"ab"` is balanced with one occurrence of each distinct character. `"ba"` is another longest balanced substring of the same length.
