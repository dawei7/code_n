## Examples

**Example 1**

- Input: `timer = 60`
- Output: `"Red"`
- Explanation: The value $60$ is strictly greater than $30$ and no greater than $90$, so it belongs to the red interval.

**Example 2**

- Input: `timer = 5`
- Output: `"Invalid"`
- Explanation: The value $5$ is neither $0$ nor $30$, and it does not lie in the interval $30 < \texttt{timer} \le 90$. None of the signal-state rules applies.
