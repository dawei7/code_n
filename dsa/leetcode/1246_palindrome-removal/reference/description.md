## Description

You are given an integer array `arr`.

In one move, choose indices $i$ and $j$ with $i \le j$ such that the contiguous subarray `arr[i], arr[i + 1], ..., arr[j]` is palindromic, and remove that entire subarray. The elements formerly to its left and right then close the gap and become adjacent.

Return the minimum number of moves required to remove every number from the array.
