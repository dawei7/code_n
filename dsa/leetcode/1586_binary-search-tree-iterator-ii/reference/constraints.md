## Constraints

- The number of nodes in the tree is $N$ where $1 \le N \le 10^5$.
- $0 \le \text{Node.val} \le 10^6$.
- At most $10^5$ calls will be made in total to `hasNext`, `next`, `hasPrev`, and `prev`.
- `next()` is called only when `hasNext()` is `true`.
- `prev()` is called only when `hasPrev()` is `true`.
