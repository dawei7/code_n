## General
Given an array `tasks` where $\text{tasks}[i] = [\text{actual}_{i}, \text{minimum}_{i}]$:, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n\log n)$ — Operation count bound.
- **Space Complexity**: $O(n)$ — Auxiliary memory allocation bound.
