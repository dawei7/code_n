## General
Given On a campus represented on the X-Y plane, there are `n` workers and `m` bikes, with $n \le m$, the algorithm executes a single-pass linear scan through input elements. Edge case handling: guards against empty/null inputs via early returns.

## Complexity detail
- **Time Complexity**: $O(WB+D)$ — Operation count bound.
- **Space Complexity**: $O(WB+D)$ — Auxiliary memory allocation bound.
