## Constraints

- $W = \lvert\texttt{workers}\rvert$
- $B = \lvert\texttt{bikes}\rvert$
- $1 \le W \le B \le 1000$
- `workers[i].length == bikes[j].length == 2`
- $0 \le x_i,y_i < 1000$ for every worker coordinate.
- $0 \le x_j,y_j < 1000$ for every bike coordinate.
- All worker and bike locations are unique.
