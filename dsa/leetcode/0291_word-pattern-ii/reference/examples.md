## Examples

**Example 1**

- Input: `pattern = "abab", s = "redblueredblue"`
- Output: `true`
- Explanation: One valid assignment is `a -> "red"` and `b -> "blue"`.

**Example 2**

- Input: `pattern = "aaaa", s = "asdasdasdasd"`
- Output: `true`
- Explanation: Assigning `a -> "asd"` reconstructs the entire target.

**Example 3**

- Input: `pattern = "aabb", s = "xyzabcxzyabc"`
- Output: `false`
