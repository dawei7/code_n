## Description

For each distinct `company`, order that company's employee rows by `salary` in ascending order. If two employees have the same salary, the employee with the smaller `id` comes first.

Return the original `id`, `company`, and `salary` columns for the row or rows occupying the median position in each company's ordered group. An odd-sized group contributes its one middle row; an even-sized group contributes both rows on either side of the middle. The result rows may be returned in any order.
