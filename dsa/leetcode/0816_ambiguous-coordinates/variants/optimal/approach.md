## General
Given We had some 2-dimensional coordinates, like `"(1, 3)"` or `"(2, 0.5)"`. Then, we removed all commas, decimal points, and spaces and ended up with the string s, the algorithm executes a two-pointer approach to shrink boundaries or maintain a sliding window.

## Complexity detail
- **Time Complexity**: $O(n^3 + nK)$ — Operation count bound.
- **Space Complexity**: $O(n^2 + nK)$ — Auxiliary memory allocation bound.
