## General
Given an array of points in the **X-Y** plane `points` where $\text{points}[i] = [x_{i}, y_{i}]$, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(P^3)$ — Operation count bound.
- **Space Complexity**: $O(P)$ — Auxiliary memory allocation bound.
