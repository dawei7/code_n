## General
Given `coordinates`, a string that represents the coordinates of a square of the chessboard. Below is a chessboard for your reference, the algorithm solves **Determine Color of a Chessboard Square** directly. Edge case handling: applies modulo arithmetic to prevent integer overflow.

## Complexity detail
- **Time Complexity**: $O(1)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
