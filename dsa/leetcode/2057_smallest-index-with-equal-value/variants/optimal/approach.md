## General
Given a **0-indexed** integer array `nums`, return *the **smallest** index *`i`* of *`nums`* such that *$i mod 10 = \text{nums}[i]$*, or *`-1`* if such index does not exist*, the algorithm executes a single-pass linear scan through input elements. Edge case handling: applies modulo arithmetic to prevent integer overflow.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
