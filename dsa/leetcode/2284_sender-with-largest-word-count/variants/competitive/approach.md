## General
Given You have a chat log of `n` messages. You are given two string arrays `messages` and `senders` where $\text{messages}[i]$ is a **message** sent by $\text{senders}[i]$, the algorithm executes a single-pass linear scan through input elements. It utilizes a hash map (`dict`) to store element values and their indices/frequencies for $O(1)$ fast access.

## Complexity detail
- **Time Complexity**: $O(L)$ — Operation count bound.
- **Space Complexity**: $O(s)$ — Auxiliary memory allocation bound.
