## Examples

**Example 1**

- Input: `nums = [4,3,2,6]`
- Output: `26`
- Explanation: The four scores are `F(0) = 0*4 + 1*3 + 2*2 + 3*6 = 25`, `F(1) = 0*6 + 1*4 + 2*3 + 3*2 = 16`, `F(2) = 0*2 + 1*6 + 2*4 + 3*3 = 23`, and `F(3) = 0*3 + 1*2 + 2*6 + 3*4 = 26`. Therefore the maximum is `F(3) = 26`.
