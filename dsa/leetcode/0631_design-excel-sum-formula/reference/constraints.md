## Constraints

- $1 \le \texttt{height} \le 26$
- `'A' <= width <= 'Z'`
- $1 \le \texttt{row} \le \texttt{height}$
- `'A' <= column <= width`
- $-100 \le \texttt{val} \le 100$
- $1 \le \texttt{numbers.length} \le 5$
- Each `numbers[i]` has format `"ColRow"` or `"ColRow1:ColRow2"`.
- At most `100` calls are made to `set`, `get`, and `sum` in total.
