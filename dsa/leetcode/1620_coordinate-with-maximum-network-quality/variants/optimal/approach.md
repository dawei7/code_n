## General
Given an array of network towers `towers`, where $\text{towers}[i] = [x_{i}, y_{i}, q_{i}]$ denotes the $$i^{\text{th}}$$ network tower with location $(x_{i}, y_{i})$ and quality factor $q_{i}$. It utilizes a hash map (`dict`) to store element values and their indices/frequencies for $O(1)$ fast access.

## Complexity detail
- **Time Complexity**: $O(T)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
