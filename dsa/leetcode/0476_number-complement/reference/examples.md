## Examples

**Example 1**

- Input: `num = 5`
- Output: `2`
- Explanation: Without leading zero bits, 5 is `101` in binary. Its complement is `010`, which represents 2.

**Example 2**

- Input: `num = 1`
- Output: `0`
- Explanation: The single-bit representation of 1 is `1`; flipping it gives `0`, so the result is 0.
