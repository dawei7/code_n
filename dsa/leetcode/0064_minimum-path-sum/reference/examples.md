## Examples

**Example 1**

- Input: `grid = [[1, 3, 1], [1, 5, 1], [4, 2, 1]]`
- Output: `7`
- Explanation: The path with values `1 → 3 → 1 → 1 → 1` has the minimum sum, `7`.

The independently rendered arrows mark that route through the same grid:

```text
1 → 3 → 1
        ↓
1   5   1
        ↓
4   2   1
```

**Example 2**

- Input: `grid = [[1, 2, 3], [4, 5, 6]]`
- Output: `12`
