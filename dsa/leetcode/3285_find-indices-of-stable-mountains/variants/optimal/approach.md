## General
Given There are `n` mountains in a row, and each mountain has a height. You are given an integer array `height` where $\text{height}[i]$ represents the height of mountain `i`, and an integer `threshold`, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(n)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
