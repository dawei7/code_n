## Examples

**Example 1**

- Input: `num = 16`
- Output: `true`
- Explanation: Since `4 * 4 = 16` and `4` is an integer, `16` is a perfect square.

**Example 2**

- Input: `num = 14`
- Output: `false`
- Explanation: The square root of `14` is approximately `3.742`, which is not an integer, so `14` is not a perfect square.
