## General
Given an integer array `nums`. You have an integer array `arr` of the same length with all values set to `0` initially. You also have the following `modify` function:, the algorithm executes a single-pass linear scan through input elements.

## Complexity detail
- **Time Complexity**: $O(NB)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
