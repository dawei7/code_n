## Description

A robot starts in the top-left cell `grid[0][0]` of an $m \times n$ grid and wants to reach the bottom-right cell `grid[m - 1][n - 1]`. At every step, it may move exactly one cell either right or down.

Given `m` and `n`, return the number of distinct paths that can reach the destination. Every generated answer is at most $2 \times 10^9$.
