## Examples

**Example 1**

- Input: `nums = [3,4,2,5,4,6]`
- Output: `2`
- Explanation: The even values `2` and `6` each occur once, whereas `4` occurs twice. The unique value `2` appears before `6`, so `2` is returned.

**Example 2**

- Input: `nums = [4,4]`
- Output: `-1`
- Explanation: The only even value occurs twice. Because no even integer has frequency one, the result is `-1`.
