## Constraints

- $2 \leq n \leq 100$
- $1 \leq \texttt{logs.length} \leq 10^4$
- `logs[i].length == 3`
- $0 \leq \texttt{timestamp_i} \leq 10^9$
- $0 \leq \texttt{x_i}, \texttt{y_i} \leq n - 1$
- $\texttt{x_i} \neq \texttt{y_i}$
- All `timestamp_i` values are unique.
- Every listed pair (`x_i`, `y_i`) occurs at most once in the input.
