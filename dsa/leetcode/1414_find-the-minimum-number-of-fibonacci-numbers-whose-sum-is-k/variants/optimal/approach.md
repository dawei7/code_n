## General
Given an integer `k`, *return the minimum number of Fibonacci numbers whose sum is equal to *`k`. The same Fibonacci number can be used multiple times, the algorithm solves **Find the Minimum Number of Fibonacci Numbers Whose Sum Is K** directly.

## Complexity detail
- **Time Complexity**: $O(\log k)$ — Operation count bound.
- **Space Complexity**: $O(\log k)$ — Auxiliary memory allocation bound.
