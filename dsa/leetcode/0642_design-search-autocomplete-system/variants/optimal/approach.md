## General
Given Design a search autocomplete system for a search engine. Users may input a sentence (at least one word and end with a special character `'#'`), the algorithm executes depth-first search (DFS) recursion to explore valid decision branches.

## Complexity detail
- **Time Complexity**: $O(C + Q)$ — Operation count bound.
- **Space Complexity**: $O(C + Q)$ — Auxiliary memory allocation bound.
