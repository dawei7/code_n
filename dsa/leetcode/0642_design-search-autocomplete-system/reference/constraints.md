## Constraints

- `n == sentences.length`
- `n == times.length`
- $1 \le n \le 100$
- $1 \le \lvert\texttt{sentences[i]}\rvert \le 100$
- $1 \le \texttt{times[i]} \le 50$
- `c` is a lowercase English letter, `'#'`, or a space `' '`.
- Every tested sentence is supplied as a sequence of `c` values ending with `'#'`.
- Each tested sentence has length in the range $[1, 200]$.
- Words within an input sentence are separated by single spaces.
- At most `5000` calls are made to `input`.
