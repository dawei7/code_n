## General
Given a 2D array `queries`, where $\text{queries}[i]$ is of the form `[l, r]`. Each $\text{queries}[i]$ defines an array of integers `nums` consisting of elements ranging from `l` to `r`, both **inclusive**, the algorithm executes a two-pointer approach to shrink boundaries or maintain a sliding window.

## Complexity detail
- **Time Complexity**: $O(q\log R)$ — Operation count bound.
- **Space Complexity**: $O(1)$ — Auxiliary memory allocation bound.
