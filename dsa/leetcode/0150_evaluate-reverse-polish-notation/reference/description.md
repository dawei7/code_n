## Description

You are given an array of strings `tokens` that represents an arithmetic expression in a <a href="http://en.wikipedia.org/wiki/Reverse_Polish_notation" target="_blank">Reverse Polish Notation</a>.

Evaluate the expression. Return *an integer that represents the value of the expression*.

**Note** that:

<ul>
	<li>The valid operators are `'+'`, `'-'`, `'*'`, and `'/'`.</li>
	<li>Each operand may be an integer or another expression.</li>
	<li>The division between two integers always **truncates toward zero**.</li>
	<li>There will not be any division by zero.</li>
	<li>The input represents a valid arithmetic expression in a reverse polish notation.</li>
	<li>The answer and all the intermediate calculations can be represented in a **32-bit** integer.</li>
</ul>
