## General
Given You have a queue of integers, you need to retrieve the first unique integer in the queue, the algorithm executes a single-pass linear scan through input elements. It utilizes a hash set (`set`) to track unique elements and prevent duplicate processing in $O(1)$ time.

## Complexity detail
- **Time Complexity**: $O(n+q)$ — Operation count bound.
- **Space Complexity**: $O(n+q)$ — Auxiliary memory allocation bound.
