# 60-Degree Triangle Inscribed Circles - Optimal Approach

## 1. Problem Essence & Formal Mathematical Formulation

Let an integer sided triangle with **exactly one angle of $60$ degrees** be called a $60$-degree triangle.
Let $a, b, c$ be the side lengths where $c$ is the side opposite the $60^\circ$ angle.
By the Law of Cosines:
$$c^2 = a^2 + b^2 - ab \quad (a \neq b)$$

The inradius $r$ of this triangle is given by:
$$r = \frac{\text{Area}}{s} = \frac{\frac{\sqrt{3}}{4} ab}{\frac{a + b + c}{2}} = \frac{\sqrt{3}}{6} (a + b - c)$$

Let $T(n)$ denote the number of $60$-degree integer triangles for which $r \le n$:
- $T(100) = 1234$
- $T(1000) = 22\,767$
- $T(10000) = 359\,912$

The objective is to find **$T(1053779)$**:
$$T(1053779) = \text{number of } 60^\circ \text{ triangles with inradius } r \le 1053779$$

### Eisenstein Integer Parameterization of Primitive Triangles
1. **Primitive Parameterization:**
   Every primitive integer solution to $c^2 = a^2 - ab + b^2$ with $a \neq b$ and $\gcd(a, b) = 1$ is generated by coprime integers $u, v$:
   $$a = u^2 - v^2, \quad b = 2uv - v^2, \quad c = u^2 - uv + v^2$$
   (divided by 3 if $u + v \equiv 0 \pmod 3$).
2. **Involution Symmetry Breaking ($u > 2v$):**
   The mapping $v \mapsto u - v$ preserves the triangle sides. Restricting to **$u > 2v > 0$** generates every primitive triangle **exactly once**.
3. **Primitive Inradius Closed Form:**
   $$a + b - c = 3v(u - v)$$
   - If $(u + v) \not\equiv 0 \pmod 3$:
     $$r_0 = \frac{\sqrt{3}}{6} \cdot 3v(u - v) = \mathbf{\frac{\sqrt{3}}{2} v(u - v)}$$
   - If $(u + v) \equiv 0 \pmod 3$:
     $$r_0 = \frac{\sqrt{3}}{6} \cdot \frac{3v(u - v)}{3} = \mathbf{\frac{\sqrt{3}}{6} v(u - v)}$$
4. For each primitive pair $(u, v)$, the number of integer scaling multiples with inradius $\le N$ is $\lfloor N / r_0 \rfloor$.
5. Hyperbolic lattice summation evaluates $T(1053779)$ in $\approx 1.5$ seconds.
