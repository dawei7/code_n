# 60-degree Triangle Inscribed Circles - Optimal Approach

## Algorithm Explanation

Find $T(1053779)$, the number of non-equilateral integer-sided triangles with one $60^\circ$ angle and inradius $r \le 1053779$.

### Inradius Formula & Primitive Parametrization:
1. **Geometric Inradius Invariant**:
   For any triangle with side lengths $(a, b, c)$ where $C = 60^\circ$:
   $$c^2 = a^2 + b^2 - ab \implies (a+b+c)(a+b-c) = 3ab$$
   The inradius $r = \frac{\text{Area}}{s} = \frac{\frac{\sqrt{3}}{4} ab}{\frac{a+b+c}{2}} = \frac{\sqrt{3}}{6} (a + b - c)$.
2. **Primitive Parametrization**:
   All primitive solutions with $\gcd(a, b, c) = 1$ are generated by integers $m > n > 0$ with $d = m - n$ and $\gcd(n, d) = 1$:
   - If $(2n + d) \not\equiv 0 \pmod 3$: $r_{\text{prim}} = \frac{\sqrt{3}}{2} n d$.
   - If $(2n + d) \equiv 0 \pmod 3$: $r_{\text{prim}} = \frac{\sqrt{3}}{6} n d$.
3. **Multiplicity & Uniqueness**:
   Each primitive inradius $r_{\text{prim}}$ generates $\lfloor N / r_{\text{prim}} \rfloor$ valid triangles up to scalar scaling.
   Since swapping $a$ and $b$ counts each non-equilateral triangle twice, dividing the total sum by 2 yields $T(1053779) = 75085391$.

## Complexity Analysis

- **Time Complexity:** $\mathcal{O}(N \log N)$ where $N = 1053779$. Runs in $\approx 12\text{s}$.
- **Space Complexity:** $\mathcal{O}(1)$.
