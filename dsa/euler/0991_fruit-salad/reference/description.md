## Description

Find the sum of $🍎 + 🍌 + 🍍$ for all triples of positive integers $🍎, 🍌, 🍍$ which satisfy

$$
\frac {🍎} {🍌 + 🍍} +
\frac {🍌} {🍍 + 🍎} +
\frac {🍍} {🍎 + 🍍} = 4
$$

and $🍎 + 🍌 + 🍍 \le 10^7$.
