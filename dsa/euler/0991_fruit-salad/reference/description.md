## Description

Find the sum of $\text{🍎} + \text{🍌} + \text{🍍}$ for all triples of positive integers $\text{🍎}, \text{🍌}, \text{🍍}$ which satisfy:

$$
\frac{\text{🍎}}{\text{🍌} + \text{🍍}} + \frac{\text{🍌}}{\text{🍍} + \text{🍎}} + \frac{\text{🍍}}{\text{🍎} + \text{🍌}} = 4
$$

and $\text{🍎} + \text{🍌} + \text{🍍} \le 10^7$.
