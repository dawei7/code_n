# Pandigital Multiples - Optimal Approach

## 1. Problem Essence & Formal Mathematical Formulation

For an integer $x \in \mathbb{N}$ and an integer tuple $(1, 2, \dots, n)$ with $n > 1$, define the concatenated product string:
$$\mathbf{P}(x, n) = \operatorname{str}(x \cdot 1) \mathbin{\Vert} \operatorname{str}(x \cdot 2) \mathbin{\Vert} \dots \mathbin{\Vert} \operatorname{str}(x \cdot n)$$

We say $\mathbf{P}(x, n)$ is a **1 to 9 pandigital 9-digit number** if $|\mathbf{P}(x, n)| = 9$ and it contains each digit $1, 2, \dots, 9$ exactly once.

The objective is to find the largest 1 to 9 pandigital 9-digit number formed this way:
$$P_{\text{max}} = \max \{ \operatorname{int}(\mathbf{P}(x, n)) \mid x \in \mathbb{N}, \, n > 1, \, \mathbf{P}(x, n) \text{ is 1..9 pandigital} \}$$

### Search Domain Pruning Theorem
1. **Base Value $918\,273\,645$**: For $x = 9$ and $n = 5$, $\mathbf{P}(9, 5) = \text{"918273645"}$.
   Any larger pandigital number must begin with digit $9$, which forces $x$ itself to start with $9$.
2. **Length Analysis for $x$ starting with $9$**:
   - $x$ is 2-digit ($9\dots$): $n=3 \implies 2+3+3 = 8$ digits; $n=4 \implies 2+3+3+3 = 11$ digits (never 9).
   - $x$ is 3-digit ($9\dots$): $n=2 \implies 3+4 = 7$ digits; $n=3 \implies 3+4+4 = 11$ digits (never 9).
   - $x$ is 4-digit ($9\dots$): $n=2 \implies 4+5 = \mathbf{9}$ digits!
3. **Theorem:** Any candidate beating $918\,273\,645$ MUST be generated by a **4-digit integer $x \in [9214, 9876]$ with $n = 2$**.
   This limits the search to just $663$ candidates ($\approx 0.0001$ seconds).

## 4. Rigorous Mathematical Breakthrough & Derivations

### Descending Scan Optimization
1. Initialize $P_{\text{max}} = 918\,273\,645$.
2. Iterate $x$ in descending order from $9876$ down to $9214$:
   - Compute $\mathbf{s} = \operatorname{str}(x) \mathbin{\Vert} \operatorname{str}(2x)$.
   - If $|\mathbf{s}| = 9$ and $\operatorname{set}(\mathbf{s}) = \{1, 2, 3, 4, 5, 6, 7, 8, 9\}$:
     - The first matching number is guaranteed to be the global maximum!
     - Break loop immediately.
3. The first match found is $x = 9327 \implies 932718654$.
