# Crossed Lines - Optimal Approach

## 1. Problem Essence & Formal Mathematical Formulation

Given $n$ pseudo-random points $(T_{2k-1}, T_{2k})$ generated by the Blum Blum Shub pseudo-random generator, let $L_n$ be the set of all distinct infinite lines formed by pairs of points.
Let $M(L_n) = |L_n|$ be the number of unique lines.
Let $S(L_n)$ be the sum over all lines $\ell \in L_n$ of the number of other lines in $L_n$ that cross $\ell$.

We are given:
- $M(L_3) = 3, S(L_3) = 6$
- $M(L_{100}) = 4948, S(L_{100}) = 24477690$

We seek to evaluate:

$$
S(L_{2500})
$$

---

## 2. The Naive Approach & Fundamental Bottlenecks

### Pairwise Geometric Intersection Testing
With $M \approx 3 \times 10^6$ lines, testing all $\approx \frac{M^2}{2} \approx 4.5 \times 10^{12}$ line pairs for intersection points is computationally infeasible.

---

## 3. Core Intuition & Mathematical Structure

### Slope Equivalence Classes & Parallelism Partitions
1. **Parallelism Invariant**:
   In Euclidean geometry, two lines cross if and only if they are not parallel (i.e. they have distinct slopes).
2. **Equivalence Class Decomposition**:
   Partition the set of unique lines $L_n$ into $K$ slope classes $C_1, \dots, C_K$ with sizes $c_1, \dots, c_K$ ($\sum c_i = M$).
3. **Exact Crossing Formula**:
   A line in class $i$ is crossed by every line not in class $i$, which is exactly $M - c_i$ lines.
   Summing across all lines in class $i$ and over all $K$ classes:

$$
S(L) = \sum_{i=1}^K c_i (M - c_i) = M^2 - \sum_{i=1}^K c_i^2
$$

---

## 4. Rigorous Mathematical Breakthrough & Derivations

### Canonical Line Sorting & Streamed Aggregation ($O(N^2 \log N)$)
1. **Point Generation**:
   Generate $N = 2500$ points in $O(N)$.
2. **Canonical Line Normalization**:
   For each of the $\binom{N}{2} = 3,123,750$ pairs $(P_i, P_j)$:
   - Compute reduced direction vector $(\Delta x, \Delta y)$ with $\gcd(\Delta x, \Delta y) = 1$ and $\Delta x \ge 0$.
   - Normal form equation: $a x + b y + c = 0$ with $a = -\Delta y, b = \Delta x, c = -(a x_1 + b y_1)$.
3. **Sort & Deduplicate**:
   Sort line tuples $(\Delta x, \Delta y, c)$ in $O(N^2 \log N)$ to count distinct lines and extract class sizes $c_i$.
4. **Evaluate Total Crossings**:

$$
S(L) = \sum_{i=1}^K c_i (M - c_i)
$$

This evaluates $S(L_{2500})$ in **$\approx 0.49$ seconds**!
