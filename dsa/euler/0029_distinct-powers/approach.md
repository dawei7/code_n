# Distinct Powers - Optimal Approach

## 1. Problem Essence & Formal Mathematical Formulation

For an upper bound $N \in \mathbb{N}$ ($N = 100$), consider the set of integer powers generated by base $a$ and exponent $b$:
$$\mathcal{S}_N = \{ a^b \mid 2 \le a \le N, \, 2 \le b \le N \}$$

The objective is to compute the number of distinct terms (set cardinality):
$$K(N) = |\mathcal{S}_N|$$

---

## 2. The Naive Approach & Fundamental Bottlenecks

### Total Pairs vs Unique Values
There are $(N - 1)^2$ total Cartesian pairs $(a, b)$.
For $N = 100$, $(100 - 1)^2 = 99 \times 99 = 9801$ total power terms.

However, duplicate values arise whenever bases share a common power root:
$$a_1^{b_1} = a_2^{b_2} \iff (c^{k_1})^{b_1} = (c^{k_2})^{b_2} \iff k_1 b_1 = k_2 b_2$$

---

## 3. Core Intuition & Mathematical Structure

### Power Collision Breakdown for Small Bases

| Root Base $c$ | Base Forms $a = c^k \le 100$ | Exponent Range $k \cdot b$ | Sample Collisions |
| :---: | :--- | :--- | :--- |
| **$2$** | $2^1, 2^2=4, 2^3=8, 2^4=16, 2^5=32, 2^6=64$ | $k \in [1, 6], \, b \in [2, 100]$ | $2^4 = 4^2 = 16, \quad 2^6 = 4^3 = 8^2 = 64$ |
| **$3$** | $3^1, 3^2=9, 3^3=27, 3^4=81$ | $k \in [1, 4], \, b \in [2, 100]$ | $3^4 = 9^2 = 81, \quad 3^6 = 9^3 = 27^2 = 729$ |
| **$5$** | $5^1, 5^2=25$ | $k \in [1, 2], \, b \in [2, 100]$ | $5^4 = 25^2 = 625$ |
| **$6, 7, 10$** | $c^1, c^2$ | $k \in [1, 2], \, b \in [2, 100]$ | $6^4 = 36^2, \quad 10^4 = 100^2$ |

---

## 4. Rigorous Mathematical Breakthrough & Derivations

### Arbitrary-Precision Set Deduplication
Because Python natively supports exact BigInt arithmetic up to $100^{100} = 10^{200}$:
1. A set comprehension `{a**b for a in range(2, N+1) for b in range(2, N+1)}` computes and inserts all 9,801 exact integers into a hash set $\mathcal{H}$.
2. Hash table insertion automatically collapses all mathematical duplicate identities in $\mathcal{O}(1)$ average time per element.
3. The cardinality $|\mathcal{H}|$ gives the exact count of unique terms in $\approx 0.001$ seconds.

---

## 5. Concrete Step-by-Step Example Walkthrough

### Example 1: Evaluation for $N = 5$
- Total pairs: $(5 - 1)^2 = 4 \times 4 = 16$ terms.
- Terms for $a=2$: $2^2=4, 2^3=8, 2^4=16, 2^5=32$.
- Terms for $a=3$: $3^2=9, 3^3=27, 3^4=81, 3^5=243$.
- Terms for $a=4$: $4^2=\mathbf{16}, 4^3=64, 4^4=256, 4^5=1024$ (Note collision $4^2 = 2^4 = 16$).
- Terms for $a=5$: $5^2=25, 5^3=125, 5^4=625, 5^5=3125$.
- Distinct terms: $\{4, 8, 9, 16, 25, 27, 32, 64, 81, 125, 243, 256, 625, 1024, 3125\}$ ($15$ unique terms). Matches sample! $\checkmark$

### Example 2: Target Evaluation for $N = 100$
- Total pairs: $9801$.
- Total unique terms:
  $$K(100) = \mathbf{9183}$$
- Number of eliminated duplicate collisions: $9801 - 9183 = 618$ duplicates.

## 6. Implementation Architecture & Algorithmic Blueprint

### Algorithmic Execution Pipeline

| Stage | Operation | Code / Formula Action | Complexity |
| :---: | :--- | :--- | :---: |
| **Stage 1** | **Cartesian Generator** | Generate $a^b$ for $a \in [2, 100], b \in [2, 100]$ | $9801$ terms |
| **Stage 2** | **Hash Set Insertion** | `distinct_set = {a**b for a in ... for b in ...}` | $\mathcal{O}(N^2)$ |
| **Stage 3** | **Cardinality Query** | `len(distinct_set)` | $\mathcal{O}(1)$ |
| **Stage 4** | **Return Value** | Return scalar integer $9183$ | $\mathcal{O}(1)$ |

## 7. Mathematical Complexity & Edge Case Invariants

| Dimension | Complexity | Performance / Resource Bounds |
| :--- | :--- | :--- |
| **Time Complexity** | $\mathcal{O}(N^2)$ | $\approx 0.001$ seconds for $N = 100$ |
| **Space Complexity** | $\mathcal{O}(N^2)$ | Hash set storage $\approx 500$ KB |
| **Dynamic Execution** | $100\%$ Inline | Exact BigInt set deduplication |

### Critical Invariants & Edge Cases Handled:
1. **Full Range $[2, N]$**: Both bases and exponents strictly include the boundary value $N = 100$.
2. **Exact Equality Guarantee**: Exact integer exponentiation avoids floating-point roundoff collisions between distinct large powers.
