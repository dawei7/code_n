# Singular Integer Right Triangles - Optimal Approach

## Algorithm Explanation

Find the number of perimeters $L \le 1500000$ for which **exactly one** integer-sided right triangle can be formed.

### Euclid's Formula for Primitive Pythagorean Triples
All primitive right triangles are generated by parameters $m > n > 0$ where $\text{GCD}(m, n) = 1$ and $m, n$ have opposite parity:
- $a = m^2 - n^2$
- $b = 2mn$
- $c = m^2 + n^2$
- Base perimeter $L_0 = a + b + c = 2m(m + n)$.

Any integer multiple $k \cdot L_0 \le 1500000$ ($k = 1, 2, 3 \dots$) forms a valid right triangle with perimeter $k \cdot L_0$.

### Strategy:
1. Allocate perimeter count array `counts` up to $L = 1500000$.
2. Iterate $m \in [2, \lfloor \sqrt{L/2} \rfloor]$.
3. Iterate $n < m$ with $\text{GCD}(m, n) = 1$ and opposite parity.
4. Calculate $L_0 = 2m(m + n)$ and increment `counts[k * L_0] += 1` for all multiples $k \cdot L_0 \le L$.
5. Return the count of perimeters with `counts[L] == 1`.

## Complexity Analysis

- **Time Complexity:** $\mathcal{O}(L \log L)$ where $L = 1500000$. Runs in $< 0.2\text{s}$.
- **Space Complexity:** $\mathcal{O}(L)$ - Perimeter lookup table.
