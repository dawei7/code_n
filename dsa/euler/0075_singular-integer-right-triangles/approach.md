# Singular Integer Right Triangles - Optimal Approach

## 1. Problem Essence & Formal Mathematical Formulation

Let $L \in \mathbb{N}$ denote the perimeter (wire length) of an integer right-angled triangle ($L \le 1\,500\,000$).
Let $\mathcal{T}(L)$ denote the set of integer right triangles with perimeter $L$:
$$\mathcal{T}(L) = \{ (a, b, c) \in \mathbb{N}^3 \mid a < b < c, \, a^2 + b^2 = c^2, \, a + b + c = L \}$$

Examples:
- $L = 12 \implies (3, 4, 5)$ (singular: $|\mathcal{T}(12)| = 1$).
- $L = 120 \implies \{(30, 40, 50), (20, 48, 52), (24, 45, 51)\}$ (not singular: $|\mathcal{T}(120)| = 3$).

The objective is to find how many values of $L \le 1\,500\,000$ can form **exactly one integer right-angled triangle**:
$$N_{\text{singular}} = \sum_{L=1}^{1500000} \mathbb{I}\left( |\mathcal{T}(L)| = 1 \right)$$

### Euclid's Formula & Sieve Multiplicity Array
1. **Primitive Parameterization:** Every primitive Pythagorean triple $(a, b, c)$ with $\gcd(a, b, c) = 1$ is generated by coprime integers $m > n > 0$ of opposite parity ($m \not\equiv n \pmod 2$):
   $$a = m^2 - n^2, \quad b = 2mn, \quad c = m^2 + n^2$$
2. **Primitive Perimeter:**
   $$L_0 = a + b + c = (m^2 - n^2) + 2mn + (m^2 + n^2) = 2m(m + n)$$
3. **Multiple Extension:** All right triangles (primitive and non-primitive) have perimeters that are integer multiples $k \cdot L_0$ for $k \ge 1$.
4. Storing counts in an array $\text{counts}[L]$ and incrementing $\text{counts}[k \cdot L_0] += 1$ evaluates all perimeters up to $1\,500\,000$ in $\mathcal{O}(N \log N)$ time in $\approx 0.25$ seconds.

## 4. Rigorous Mathematical Breakthrough & Derivations

### Generator Parameter Bounds
1. Since $L_0 = 2m(m + n) > 2m^2$, we have $m < \sqrt{L / 2}$.
2. For $L \le 1\,500\,000$:
   $$m \le \lfloor \sqrt{1\,500\,000 / 2} \rfloor = \lfloor \sqrt{750\,000} \rfloor = 866$$
3. For each $m \in [2, 866]$:
   - For $n \in [1 + (m \bmod 2), m-1]$ step $2$:
     - If $\gcd(m, n) == 1$:
       - $L_0 = 2m(m + n)$.
       - For $\text{perim} = L_0, 2L_0, 3L_0, \dots \le 1\,500\,000$:
         $$\text{counts}[\text{perim}] += 1$$
4. Count instances where $\text{counts}[L] == 1$.

### Critical Invariants & Edge Cases Handled:
1. **Opposite Parity & Coprimality**: Strictly enforces $m \not\equiv n \pmod 2$ and $\gcd(m, n) = 1$ to avoid double-counting primitive triples.
2. **Exact Singularity ($== 1$)**: Counts only entries with frequency exactly 1, correctly rejecting perimeters with 0 or $\ge 2$ triangles.
