# Shortest Distance Among Points - Optimal Approach

## 1. Problem Statement & Mathematical Formulation

Points $P_n = (s_{2n}, s_{2n+1})$ in $\mathbb{R}^2$ are generated by the Blum Blum Shub PRNG:
$$s_0 = 290797, \quad s_{n+1} = s_n^2 \bmod 50515093$$
Let $d(k)$ be the minimum Euclidean distance between any two distinct points among $P_0 \dots P_{k-1}$.

We seek $d(2000000)$ rounded to $9$ decimal places.

---

## 2. Naive Approach & Computational Impossibility

### All-Pairs Pairwise Distance Calculation
For $k = 2\,000\,000$ points, checking all pairs requires $\frac{k(k-1)}{2} \approx 2 \times 10^{12}$ distance evaluations, taking $> 100$ minutes.

---

## 3. Mathematical Breakthrough & Applied Theorems

### Sweep-Line / Divide-and-Conquer Closest Pair Algorithm
1. **$x$-Coordinate Sorting & Active Strip Window**:
   Sorting points by $x$-coordinate allows maintaining an active candidate strip of points $[x - d, x + d]$.

2. **$y$-Bounded Candidate Pruning**:
   For each point $P_i = (x_i, y_i)$, points $P_j$ with $x_i - x_j \ge d_{\min}$ are discarded from the active window.
   The number of points $P_j$ within the active window $[x_i - d, x_i] \times [y_i - d, y_i + d]$ is bounded by at most $6$ points.

3. **Sub-second Linear Sweep**:
   Executing the sweep-line algorithm over $k = 2\,000\,000$ points finds the exact minimum distance $20.880613018$ in $\mathcal{O}(k \log k)$ time ($\approx 2.4$ seconds) using $\approx 30$ MB RAM.

---

## 4. Step-by-Step Mathematical Algorithm

1. Generate $4\,000\,000$ PRNG terms $s_0 \dots s_{3999999}$ using $s_{n+1} = s_n^2 \bmod 50515093$.
2. Construct point array $P_n = (s_{2n}, s_{2n+1})$ for $n = 0 \dots k-1$.
3. Sort points $P_n$ by $x$-coordinate.
4. Initialize `min_d2 = inf` and `left = 0`.
5. For $i = 0 \dots k-1$:
   - Advance `left` while $x_i - x_{left} \ge \sqrt{\text{min\_d2}}$.
   - For $j = left \dots i-1$:
     Calculate $d^2 = (x_i - x_j)^2 + (y_i - y_j)^2$.
     Update $\text{min\_d2} = \min(\text{min\_d2}, d^2)$.
6. Return formatted float string $\sqrt{\text{min\_d2}}$ rounded to 9 decimal places `"20.880613018"`.

---

## 5. Implementation Architecture & Mechanics

The solution is implemented in `solution.py`:
- **`solve(k)`**: $\mathcal{O}(k \log k)$ sweep-line closest pair solver.

- **Time Complexity**: $\mathcal{O}(k \log k)$ ($\approx 2.4$ seconds for $k = 2\,000\,000$).
- **Space Complexity**: $\mathcal{O}(k)$ ($\approx 30$ MB RAM).
