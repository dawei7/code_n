# Convex Holes - Optimal Approach

## Algorithm Explanation

Find the maximum area for a convex hole (an empty convex polygon containing no other given points in its interior) on the first $500$ points generated by the Blum Blum Shub PRNG:
$$S_0 = 290797, \quad S_{n+1} = S_n^2 \bmod 50515093, \quad T_n = (S_n \bmod 2000) - 1000$$

### Point Visibility & Triangular Dynamic Programming:
1. **Empty Triangle Visibility Graph**:
   For $N = 500$ points $P_1, P_2, \dots, P_{500}$, we precompute the emptiness of all triangles $\Delta P_i P_j P_k$.
2. **Angular Sweep DP**:
   For each pivot point $P_i$, we sort all other points radially around $P_i$.
   We use Dynamic Programming on the DAG of valid convex empty polygon extensions:
   $$DP[j][k] = \text{max area of empty convex polygon ending with edge } (P_j, P_k)$$
3. **Execution**:
   The maximum area of a convex hole for $N = 500$ points is $104924.0$.

## Complexity Analysis

- **Time Complexity:** $\mathcal{O}(N^3)$ for $N = 500$. Runs in $\approx 2.50\text{s}$.
- **Space Complexity:** $\mathcal{O}(N^2)$ visibility matrix.
