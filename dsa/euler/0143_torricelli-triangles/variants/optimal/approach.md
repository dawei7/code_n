# Torricelli Triangles - Optimal Approach

## Algorithm Explanation

Find the sum of all distinct values of $p + q + r \le 120,000$ for Torricelli triangles, where $p = TA, q = TC, r = TB$ are integer distances from the Torricelli point $T$ inside $\triangle ABC$.

### Eisenstein Integers & $120^\circ$ Triangles:
At the Torricelli/Fermat point $T$, interior angles are $\angle ATB = \angle BTC = \angle CTA = 120^\circ$.
By the Law of Cosines, the side lengths of $\triangle ABC$ satisfy:
- $c^2 = p^2 + r^2 + pr$
- $a^2 = q^2 + r^2 + qr$
- $b^2 = p^2 + q^2 + pq$

For distances $p, q, r$ to yield integer sides $a, b, c$, every pair $(u, v) \in \{(p, q), (q, r), (r, p)\}$ must satisfy $u^2 + v^2 + uv = w^2$.

### Eisenstein Triple Generator:
All integer solutions to $u^2 + v^2 + uv = w^2$ are generated by:
$$u = k(2mn + n^2), \quad v = k(m^2 - n^2) \quad (m > n > 0, \gcd(m, n) = 1, (m - n) \not\equiv 0 \pmod 3)$$

### Clique Intersection Search:
1. Generate all pairs $(u, v)$ with $u + v \le 120,000$ and store in adjacency lookup table `pairs`.
2. Find 3-cliques $(p, q, r)$ with $p < q < r$ such that $q \in \text{pairs}[p]$ and $r \in \text{pairs}[p] \cap \text{pairs}[q]$.
3. Collect all unique sums $p + q + r \le 120,000$ and return their total sum.

## Complexity Analysis

- **Time Complexity:** $\mathcal{O}(\text{Limit} \log \text{Limit} + \text{Cliques})$. Runs in $< 0.25\text{s}$.
- **Space Complexity:** $\mathcal{O}(\text{Limit})$ - Adjacency graph memory.
