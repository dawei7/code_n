# Maximum-sum Subsequence - Optimal Approach

## Algorithm Explanation

Find the maximum contiguous sequence sum in any direction (horizontal, vertical, diagonal, or anti-diagonal) within a $2000 \times 2000$ grid of $4,000,000$ numbers generated by a Lagged Fibonacci Generator.

### Pseudo-Random Generator:
- For $1 \le k \le 55$: $s_k = (100003 - 200003k + 300007k^3) \bmod 1000000 - 500000$.
- For $56 \le k \le 4000000$: $s_k = (s_{k-24} + s_{k-55} + 1000000) \bmod 1000000 - 500000$.

### Multi-Directional Kadane's Algorithm:
1. Populate $2000 \times 2000$ grid `grid[r][c] = s[r * 2000 + c + 1]`.
2. Apply **Kadane's Algorithm** for Maximum 1D Subarray Sum along:
   - All $2000$ horizontal rows.
   - All $2000$ vertical columns.
   - All $3999$ diagonal slices ($r - c = \text{const}$).
   - All $3999$ anti-diagonal slices ($r + c = \text{const}$).
3. Track and return the overall maximum contiguous subarray sum.

## Complexity Analysis

- **Time Complexity:** $\mathcal{O}(N^2)$ linear scan over grid cells ($N = 2000$). Runs in $\approx 2.5\text{s}$.
- **Space Complexity:** $\mathcal{O}(N^2)$ - $2000 \times 2000$ grid storage.
