# Maximum Sum Subsequence - Optimal Approach

## 1. Problem Essence & Formal Mathematical Formulation

Looking at the table below, it is easy to verify that the maximum possible sum of consecutive numbers in any direction (horizontal, vertical, diagonal or anti-diagonal) is $16$ ($= 3 + 4 + 9$ along the anti-diagonal):
$$\begin{pmatrix}
-2 & 5 & 3 & 2 \\
9 & -6 & 5 & 1 \\
3 & 2 & 7 & 3 \\
-1 & 8 & -4 & 8
\end{pmatrix}$$

Now, let us consider a much larger table with $2000$ rows and $2000$ columns filled with pseudo-random numbers generated by a **Subtractive Lagged Fibonacci Generator**:
- For $k = 1 \dots 55$:
  $$s_k = (100003 - 200003 k + 300007 k^3) \bmod 1\,000\,000 - 500\,000$$
- For $k = 56 \dots 4\,000\,000$:
  $$s_k = (s_{k-24} + s_{k-55} + 1\,000\,000) \bmod 1\,000\,000 - 500\,000$$

The grid is filled row by row: $\mathbf{M}_{r, c} = s_{2000r + c + 1}$.

The objective is to find the **greatest sum of (any number of) adjacent entries in any direction (horizontal, vertical, diagonal, or anti-diagonal)**:
$$S_{\text{max}} = \max_{\text{line } L} \operatorname{Kadane}(L)$$

### Linear Kadane's Dynamic Programming Algorithm
1. **Kadane's Subarray Optimization:**
   For any 1D array of values $[x_1, x_2, \dots, x_m]$, the maximum contiguous subarray sum ending at position $i$ satisfies:
   $$\text{curr\_max}_i = \max(x_i, \text{curr\_max}_{i-1} + x_i)$$
   $$\text{max\_so\_far} = \max_i \text{curr\_max}_i$$
   This finds the optimal slice in strictly **$\mathcal{O}(L)$ linear time**!
2. We extract all straight lines across the $2000 \times 2000$ grid:
   - $2000$ horizontal rows.
   - $2000$ vertical columns.
   - $3999$ main diagonals (slope $+1$).
   - $3999$ anti-diagonals (slope $-1$).
3. Running Kadane's algorithm on each slice scans all $4 \times 10^6$ elements in $\approx 2.5$ seconds.

## 4. Rigorous Mathematical Breakthrough & Derivations

### Generator & Sweep Pipeline
1. Generate $4\,000\,000$ numbers using the Lagged Fibonacci Generator $LFG(24, 55)$.
2. Fill 2D array `grid` of dimension $2000 \times 2000$.
3. Set `global_max = -infinity`.
4. Sweep all rows: `global_max = max(global_max, kadane(row))`.
5. Sweep all columns: `global_max = max(global_max, kadane(col))`.
6. Sweep all main diagonals: `global_max = max(global_max, kadane(diag))`.
7. Sweep all anti-diagonals: `global_max = max(global_max, kadane(antidiag))`.
8. Return `global_max = 52852124`.
