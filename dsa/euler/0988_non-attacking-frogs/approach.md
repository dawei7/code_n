# Problem 988: Non-attacking Frogs - Mathematical Approach & Analysis

## 1. Problem Formulation & Numerical Semigroup Poset

Let $(a, b)$ be coprime positive integers. Frogs jump in steps of size $a$ or $b$.
A frog at $m$ can reach $n > m$ if and only if:
$$
n - m \in \Lambda = \langle a, b \rangle = \{ u a + v b \mid u, v \in \mathbb{Z}_{\ge 0} \}
$$
where $\Lambda$ is the numerical semigroup generated by $a$ and $b$.

A subset $S \subseteq \mathbb{Z}_{\ge 0}$ is a **non-attacking configuration** if:
1. $0 \in S$,
2. For every pair $m, n \in S$ with $m < n$, $n - m \notin \Lambda$.

We define $F(a, b)$ to be the sum of all elements in all valid non-attacking configurations $S$:
$$
F(a, b) = \sum_{S} \sum_{x \in S} x
$$

---

## 2. Frobenius Number & Antichain Structure

By the Sylvester-Frobenius theorem:
- The Frobenius number (largest integer not in $\Lambda$) is:
$$
g(a, b) = a b - a - b
$$
- The number of gaps (integers not in $\Lambda$) is:
$$
|\mathbb{Z}_{\ge 0} \setminus \Lambda| = \frac{(a-1)(b-1)}{2}
$$
Because $0 \in S$, every element $x \in S \setminus \{0\}$ must be a gap of $\Lambda$ (since $x - 0 = x \notin \Lambda$).
Thus, all elements of $S$ are bounded above by $g(a, b) = 19 \times 53 - 19 - 53 = 935$.

---

## 3. Dynamic Programming Over Non-Attacking Configurations

We order the gap set $\mathcal{G} = \mathbb{Z}_{\ge 0} \setminus \Lambda$ in increasing order.
A gap $x \in \mathcal{G}$ can be added to an existing configuration $S$ if and only if $x - y \notin \Lambda$ for all $y \in S$.
Using profile dynamic programming across the residue classes modulo $a$:
$$
F(19, 53) = 2727531976556215755
$$

---

## 4. Complexity & Verification Analysis

- **Time Complexity**: $O(a \cdot b \cdot 2^a)$ bounded by the profile frontier.
- **Space Complexity**: $O(2^a)$ DP table.
- **Sample Verification**: $F(3, 5) = 23, F(5, 13) = 16336$.
