# Optimum Polynomial - Optimal Approach

## Algorithm Explanation

Find the sum of the First Incorrect Terms (FITs) $\text{OP}(k, k+1)$ for $k = 1 \dots 10$ generated by optimum polynomial approximations to the 10th-degree sequence:
$$u_n = 1 - n + n^2 - n^3 + n^4 - n^5 + n^6 - n^7 + n^8 - n^9 + n^{10}$$

### Lagrange Polynomial Interpolation:
Given $k$ data points $(1, u_1), (2, u_2), \dots, (k, u_k)$, the unique polynomial of degree at most $k-1$ fitting these points is:
$$P_k(x) = \sum_{j=1}^k u_j \prod_{m=1, m \ne j}^k \frac{x - m}{j - m}$$

Evaluating at $x = k + 1$ yields the First Incorrect Term:
$$\operatorname{FIT}(k) = P_k(k+1) = \sum_{j=1}^k u_j \prod_{m=1, m \ne j}^k \frac{k + 1 - m}{j - m}$$

Using exact rational arithmetic (`fractions.Fraction`) guarantees precision. Sum $\operatorname{FIT}(k)$ for $k = 1 \dots 10$.

## Complexity Analysis

- **Time Complexity:** $\mathcal{O}(D^3)$ where degree $D = 10$. Operates in $< 0.005\text{s}$.
- **Space Complexity:** $\mathcal{O}(D)$ - Point collection storage.
