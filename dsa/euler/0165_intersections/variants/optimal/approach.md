# Intersections - Optimal Approach

## Algorithm Explanation

Find the total number of **distinct true intersection points** among $5000$ line segments generated by the Blum Blum Shub pseudo-random number generator.

### Vector Cross-Product & Interior Point Condition:
For two line segments $L_1 = P_1 \to P_2$ and $L_2 = P_3 \to P_4$:
Let $\vec{D_1} = P_2 - P_1$ and $\vec{D_2} = P_4 - P_3$.

1. **Determinant & Parallelism**:
   $$D = D_{1x} D_{2y} - D_{1y} D_{2x}$$
   If $D = 0$, the lines are parallel or collinear (no unique interior intersection).
2. **Parametric Interior Boundaries**:
   $L_1(u) = P_1 + u \vec{D_1}$ and $L_2(v) = P_3 + v \vec{D_2}$.
   - $u \cdot D = (x_3 - x_1) D_{2y} - (y_3 - y_1) D_{2x}$
   - $v \cdot D = (x_3 - x_1) D_{1y} - (y_3 - y_1) D_{1x}$
   
   A **true intersection** requires $T$ to lie strictly inside both open segments: $0 < u < 1$ and $0 < v < 1$.
3. **Exact Canonical Rational Coordinates**:
   Compute exact intersection coordinates $(T_x, T_y)$ as irreducible fraction tuples $(n_x/d_x, n_y/d_y)$ using integer `math.gcd` reduction.
4. **Set Unification**:
   Store canonical rational tuples in a hash set to count unique intersection points across all $\binom{5000}{2} = 12,497,500$ pairs.

## Complexity Analysis

- **Time Complexity:** $\mathcal{O}(N^2)$ where $N = 5000$. Runs in $\approx 14.1\text{s}$.
- **Space Complexity:** $\mathcal{O}(\text{Distinct Points}) \approx 2.87 \times 10^6$ tuples stored in `set()`.
