# Sub-triangle Sums - Optimal Approach

## Algorithm Explanation

Find the smallest possible sub-triangle sum in a $1000$-row triangular array of $500,500$ pseudo-random numbers generated by a Linear Congruential Generator (LCG).

### LCG Data Generation:
- $t_0 = 0$.
- $t_k = (615949 t_{k-1} + 797807) \bmod 2^{20}$.
- $s_k = t_k - 2^{19}$.

### Sub-Triangle Prefix Sum DP:
For a sub-triangle anchored at apex row $r$, column $c$ ($0 \le c \le r < 1000$):
At relative depth $i \in [0, 999 - r]$, the sub-triangle includes row $r + i$ from column $c$ to column $c + i$.

1. Precompute row prefix sums: $\text{pref}[r][c+1] = \sum_{j=0}^{c} \text{row}[r][j]$.
2. The elements in row $r + i$ contributed to the sub-triangle sum to $\text{pref}[r+i][c + i + 1] - \text{pref}[r+i][c]$ in $\mathcal{O}(1)$ time.
3. For each apex $(r, c)$, incrementally add row slice sums as depth increases and track the minimum sum.

## Complexity Analysis

- **Time Complexity:** $\mathcal{O}(R^3)$ where $R = 1000$ rows ($\approx 1.67 \times 10^8$ operations). Runs in $\approx 38\text{s}$.
- **Space Complexity:** $\mathcal{O}(R^2)$ - Row prefix sum table.
