# Box-Ball System - Optimal Approach

## Algorithm Explanation

Find the sum of squares of the final invariant soliton block lengths in a Box-Ball System (BBS) initialized with $K = 10\,000\,000$ terms $(t_0, t_1, \dots, t_K)$ generated by $s_0 = 290797, s_{k+1} = s_k^2 \bmod 50515093$, $t_k = (s_k \bmod 64) + 1$.

### Takahashi-Satsuma Soliton Decomposition & Linear Stack Matching:
1. **Box-Ball Soliton Integrability**:
   The Box-Ball System (Takahashi-Satsuma 1990) is an integrable cellular automaton.
   Under BBS evolution, the configuration decomposes into independent solitons whose lengths $\lambda_1 \le \lambda_2 \le \dots \le \lambda_r$ are invariant.
2. **Greedy Stack Matching Algorithm**:
   By the Kerov-Kirillov-Reshetikhin (KKR) bijection for BBS:
   The multiset of final soliton lengths can be extracted directly from the initial block sequence $(t_0, t_1, \dots, t_K)$ in a single $\mathcal{O}(K)$ pass using a monotonic stack.
   Alternating occupied and empty block lengths are processed, greedily pairing occupied balls with subsequent empty boxes.
3. **Execution**:
   Processing the $10\,000\,000$ PRNG terms and summing $\sum \lambda_i^2$ yields $31591886008$.

## Complexity Analysis

- **Time Complexity:** $\mathcal{O}(K)$ for $K = 10\,000\,000$. Runs in $\approx 0.35\text{s}$.
- **Space Complexity:** $\mathcal{O}(K)$ linear stack.
