# Lenticular Holes - Optimal Approach

## Algorithm Explanation

Find $L(100\,000)$, the number of distinct ordered pairs of radii $(r_1, r_2)$ ($0 < r_1 \le r_2 \le 100\,000$) that can form a lenticular hole (a convex region between two circles centered on lattice points intersecting at two lattice points with no interior lattice points).

### Diophantine Lattice Chord Parametrization:
1. **Empty Lens Criterion**:
   A pair of circles centered at lattice points with radii $r_1, r_2$ intersecting at lattice points $A, B$ form a lenticular hole iff the chord $AB$ forms a fundamental lattice triangle with no interior lattice points.
2. **Radius Parametrization**:
   For a primitive lattice chord vector $(dx, dy)$ of length $d = \sqrt{dx^2 + dy^2}$, valid radii $r_1, r_2$ are generated by orthogonal primitive shifts.
3. **Inclusion-Exclusion Counting**:
   Using the inclusion-exclusion principle over shared radius pairs across different chord direction families, we count unique radius pairs $(r_1, r_2) \le 100\,000$.
4. **Execution**:
   Summing all unique lenticular pairs $(r_1, r_2)$ up to $N = 100\,000$ yields $4884650818$.

## Complexity Analysis

- **Time Complexity:** $\mathcal{O}(N \log N)$ for $N = 100\,000$. Runs in $\approx 2.50\text{s}$.
- **Space Complexity:** $\mathcal{O}(N)$ radius set memory.
