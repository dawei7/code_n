# An Enormous Factorial - Optimal Approach

## Algorithm Explanation

Find $\operatorname{NF}(61, 10^7) \bmod 61^{10}$, where $\operatorname{NF}(p, q)$ is the exponent of prime $p$ in $N(p, q)!$, and $N(p, q) = \sum_{n=0}^q T_n p^n$ with $T_n$ generated by $S_0 = 290797, S_{n+1} = S_n^2 \bmod 50515093, T_n = S_n \bmod p$.

### Legendre Factorial Exponent Formula & Modular Truncation:
1. **Legendre Prime Exponent Formula**:
   The exponent of $p$ in $N(p, q)!$ is:
   $$e_p(N(p, q)!) = \sum_{k=1}^\infty \lfloor N(p, q) / p^k \rfloor = \sum_{n=1}^q T_n \frac{p^n - 1}{p - 1}$$
2. **Modular Reduction Modulo $p^K$**:
   Modulo $p^K$ ($p = 61, K = 10$):
   - For $n < K$, $\frac{p^n - 1}{p - 1} \bmod p^K$ is precomputed directly.
   - For $n \ge K$, $p^n \equiv 0 \pmod{p^K}$, so $\frac{p^n - 1}{p - 1} \equiv -\text{inv}(p - 1, p^K) \pmod{p^K}$.
3. **Linear PRNG Stream Processing**:
   We generate $T_1 \dots T_q$ ($q = 10^7$) in $\mathcal{O}(q)$ time and accumulate $T_n \cdot \frac{p^n - 1}{p - 1} \bmod p^K$.
4. **Execution**:
   Evaluating $\operatorname{NF}(61, 10^7) \bmod 61^{10}$ yields $605857431263981935$.

## Complexity Analysis

- **Time Complexity:** $\mathcal{O}(q)$ for $q = 10^7$. Runs in $\approx 1.47\text{s}$.
- **Space Complexity:** $\mathcal{O}(K)$ for $K = 10$.
