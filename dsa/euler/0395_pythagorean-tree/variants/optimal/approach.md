# Pythagorean Tree - Optimal Approach

## Algorithm Explanation

Find the smallest area of an axis-aligned bounding rectangle enclosing the infinite 3-4-5 Pythagorean tree, rounded to 10 decimal places.

### Iterated Function System (IFS) Extremum Branch Search:
1. **IFS Affine Transformations**:
   The Pythagorean tree is generated by an IFS with two affine maps $T_L$ and $T_R$:
   - **Left Branch $T_L$**: scale by $\frac{4}{5}$, rotate by $\theta_L = \arcsin(3/5)$, translate.
   - **Right Branch $T_R$**: scale by $\frac{3}{5}$, rotate by $\theta_R = -\arccos(3/5)$, translate.
2. **Bounding Box Bounding Search**:
   The minimal enclosing axis-aligned rectangle has area $(x_{\max} - x_{\min}) \times (y_{\max} - y_{\min})$.
   We compute $x_{\min}, x_{\max}, y_{\min}, y_{\max}$ by performing a branch-and-bound DFS search on the IFS tree.
   Since scaling factors are $< 1$, branches are pruned when their maximal geometric bounding disk cannot extend the current global extremum.
3. **Execution**:
   Pruning to depth 60 yields exact extremum coordinates and bounding area $28.2453753155$.

## Complexity Analysis

- **Time Complexity:** $\mathcal{O}(\text{Pruned Nodes})$ for depth $\approx 60$. Runs in $\approx 0.01\text{s}$.
- **Space Complexity:** $\mathcal{O}(\text{Depth})$ stack depth.
