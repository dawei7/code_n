# Swapping Counters - Optimal Approach

## Algorithm Explanation

Find the sum of the first $40$ values of $n$ for which the minimum moves $M(n) = n(n + 2) = n^2 + 2n$ to swap $n$ red and $n$ blue counters is a triangular number $T_k = \frac{k(k+1)}{2}$.

### Generalized Pell Equation Transformation:
1. **Diophantine Quadratic Reduction**:
   Equating $M(n) = T_k$:
   $$n^2 + 2n = \frac{k(k+1)}{2} \implies 8n^2 + 16n = 4k^2 + 4k$$
   Completing the square on both sides:
   $$(2k + 1)^2 - 2(2n + 2)^2 = -7$$
2. **Pell Solution Generators**:
   Let $X = 2k + 1$ and $Y = 2n + 2$. The fundamental solution to $u^2 - 2v^2 = 1$ is $(3, 2)$.
   The base solution classes for $X^2 - 2Y^2 = -7$ are $(1, 2)$ and $(5, 4)$.
   Successive solutions are generated via multiplication by $(3 + 2\sqrt{2})$:
   $$X_{m+1} = 3X_m + 4Y_m, \quad Y_{m+1} = 2X_m + 3Y_m$$
   From $Y = 2n + 2$, valid integers $n = (Y - 2) / 2$ are extracted.
3. **Execution**:
   Summing the first $40$ positive terms $n$ generated by the two Pell solution families yields $2470433131948040$.

## Complexity Analysis

- **Time Complexity:** $\mathcal{O}(K)$ for $K = 40$ terms. Runs in $\approx 0.00\text{s}$.
- **Space Complexity:** $\mathcal{O}(K)$.
